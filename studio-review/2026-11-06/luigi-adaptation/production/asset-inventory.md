# 《拒赔》创作资产清单与准备顺序

适用版本：24集、223镜、16:9横屏、英语对白配中文对照。以下按已写剧本提取需求，不新增剧情。现有包已具备文字母稿、六张矢量视觉设计卡、分镜示意和字幕工作稿；角色与场景母图、实际声音和视频仍待制作。

**准备重点：先稳定人物身份、场景结构和证据内容，再制作镜头。223镜不需要223套互不相关的人物和场景资产。**

警员原始ID有合写/复用情况。制作时须区分抓捕警员A/B、押送警员、候庭解铐法警；E17作证的抓捕警员应承接E04的身份。不能因都叫OFFICER就用同一张脸替代所有职务。

## 四、证据文件与后期屏幕

这是悬疑反转的核心资产。现有46条overlay是已排定的时间化叠加事件，不是全部文件数量；其中E11新增待发配文的“治疗获批→优先复核”两种状态，均未发布。

- 医疗证据链：拒赔通知、加班申请、UPLOAD ACCEPTED回执、CLINICAL REPORT附件、Q-17质检记录、真实医生签名/登录记录、医生可见清单、缺陷报告及收悉回复。统一虚构日期、编号、文件名和签名；E21前不能把最终机制提前露出。
- 付款与和解：初稿、修订稿、已签副本、保密与作证/监管例外、银行到账、诊所付款回执、下一疗程通知。已付款不能被剪回未签状态，过渡款不能写成永久批准。
- 法律材料：现场执法记录静帧、警局财物登记、保全裁定与执行确认、排证清单、州/联邦裁定、完整通信授权、认罪权利说明、纽约身份事项协议、宾州独立处置、量刑通知、私人信。E17对照静帧与两份清单，不要求新增现场动态回放。
- 社媒与新闻：举报截图、骚扰评论、押送新闻、播放量/声明打开数、红毛衣商品卡、直播UI、公司公告、报道草稿/发布/更正/最终去身份调查稿。
- 识别系统：UnionCare Health虚构公司标识、纸件抬头、工牌、法院/诊所门牌、片名及跨月字卡。剧中界面和文件以英语呈现，中文放观众字幕。

原件/复印件、未签/已签、未遮盖/去身份、已发表/已撤下都分别编号。纸件内容、可见页序和镜内显示窗口关联到镜号。

## 五、声音与后期交付

已有712条英语对白cue；49种speaker标签含同人的电话/留言/直播别名，不能据此准备49个互不相关的新声线。

- 先固定8位核心角色及凯文、医生、布莱克、托马斯等贯穿角色声线；法官、检察官、警员分别选声。电话/免提/留言/直播由同一人物干声衍生。
- 沃德与瑞秋的12岁儿子按同一家庭角色连续；案发前不可辨电话底声不增写台词，E19使用既定准确对白。
- 另备客服等待、公共广播、母亲留言、前台、匿名患者、记者等必要声音。声音在电话内，不等于人物出现在房间。
- 环境床按场景复用：河风/旋翼、车流、餐厅设备、候诊与空调、编辑部、公司工位、咖啡机、法庭混响、会见室/监室声。
- 关键拟音：短链、解铐和皮套、车门踏板、背包拉链、卡片纸页、签字/蜡笔、门禁、手机振动/发送/等待、枪声与落杯。同次押送和同次枪响复用同一事件声底。
- 现稿223镜均无背景配乐；店内场内音乐单列，不预设整季配乐。
- 后期：英语干声、电话/屏幕声、环境、拟音分别留轨；中英字幕工作稿、准确贴屏、遮盖、字卡、调色基准及片头片尾另交。最终时码按实际录音与视频重对齐。

## 六、准备顺序与验收

1. **身份与规则**：8个核心身份、13套基础服装、关键道具归属、英语声线、统一文件数据；现有矢量卡用于沟通，再做实际肤色/红毛衣/橙衣/纸金属光材试样。
2. **母版**：8个高频场景及码头、餐厅；完整空间、反打、日夜态和门窗不变量。
3. **三个小样组**：E01/E06押送，E04抓捕，E09红毛衣出庭。每组先做相邻几镜，检查脸、衣、铐、包、轴线、英语说话人与声源及剪点。
4. **证据与群像**：补齐其余场景、配角、46个叠加实例及全部剧情纸件、画页和环境声。
5. **逐镜生产**：再按共享地点/造型分批制作223镜，按成片顺序试剪；223份起态提示词先选实际依赖的镜头生成，不必一次生成223张首图。

每个资产登记：资产ID、角色/地点、造型或内容状态、用途、适用集/镜、源文件、候选、采用版本、核对结果。当前没有已选媒体，采用文件一栏保持空白。只有实际样片能确认身份、光材、接触、口型及镜间拼接。
