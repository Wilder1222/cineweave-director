# 稳定制作来源与24集播出映射

用户明确保留24集短剧。这里的`E01–E24.json`保留场景与原镜号的稳定制作定位；虽然文件数同为24，文件名不直接等于当前播出集号。已完成的口语对白、完整交锋与镜头优化继续保留。

唯一播出顺序、集名和场次映射见[当前season-plan.json](../season-plan.json)，对应派生播出稿位于`../season/`。不要按本目录文件名直接串接；被合并退役的镜号由`sourceShotIds`追溯。新增或调整播出切点后，需要重检相邻场的时序、知情、持物和声源，再重新生成读页、字幕与提示词。

前轮六集播出方案是用户未采纳的历史候选。制作单元曾为该候选扩展并优化，不意味着这些内容必须按六集交付，也不要求撤销已经有效的场景和对白修订。当前节奏规范见[24集短剧节奏方案](../short-drama-rhythm-plan.md)。
