# 当前24集短剧审读入口

用户锁定24集短剧，当前播出映射见[season-plan.json](../season-plan.json)，执行依据见[short-drama-rhythm-plan.md](../short-drama-rhythm-plan.md)。先核对报告的版本、播出集数及源镜号范围，再判断其是否对应当前稿；具体镜数、cue数和时长只取当前构建与检查结果，不从旧报告复制。

当前验收须覆盖24集各自的争取与代价、自然集尾、跨集因果、证据披露和完整场景，以及每个成片镜与技术候选的区别。结构/对白/生成段检查、六视角逐镜覆盖及提示词审读只有与当前源版本和播出映射相符时，才支持当前范围的结论；文件存在本身不代表已完成这一轮复核。

`us-rhythm-review.md`、`us-rhythm-check.json`和以`us-rhythm`为前缀的分组审读形成于前轮六集候选。该六集整体编排未被用户采纳，不再作为当前24集集尾或总时长的验收证据；其中能以源镜号和摘要确认未变的对白、持物、身份及编译提示词检查可继续作为局部证据使用，不能外推为新播出映射已全部通过。旧`E01–E06-worksheet.json`若仍保留，先核对其覆盖和生成版本，不把六份表自动当成24集覆盖。

`colloquial`、`optimization`、`asset`等早轮审计同样按其记录的范围与版本使用。`sourceShotIds`保留制作编号追溯；原E01–E24仅定位源内容，当前播出集号由season-plan确定。全部媒体尚未生成，文字检查不证明表演、声音或试剪效果。
