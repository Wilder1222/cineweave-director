# 百灶疑兵

H005｜历史题材小说普通候选稿，本轮已独立审读并复核；未通过严格人物隔离排练，未经作者采纳，查重及权利审查待完成。

史料边界：据《[后汉书》卷五十八·虞诩传](https://zh.wikisource.org/wiki/後漢書/卷58)及[《后汉书》四库本卷八十八](https://zh.wikisource.org/wiki/後漢書_(四庫全書本)/卷088)，虞诩赴武都途中受阻，停军并宣言请兵待援；对方分散后，他日夜进道，命吏士作灶并逐日增加，用以示强，记载称追兵不敢迫近。不同整理文本有字形讹异，增灶文字以四库本对读。下文年轻军官韩简、山地向导阿岚、疑似泄路及烟灶的具体数目、对话和个人命运均为原创，不将其视为史料所载；故事停在行军途中，不提前写定全部人的结局。

韩简数到第十二口灶时，发现有人比他先来过。

那人没有留下脚印。昨夜一场雨，把山道上的印子都洗成了浅沟；只有营地边缘一块石头翻了面，背面压着一缕红布。布头细得像从衣角上撕下来，沾着泥，刚好露在石头外面。

韩简把布捏起来，回头看山坡。雾还没散，昨天走过的那条路藏在灰白色里。队伍已向前去，他奉命留下核看旧营的收尾，数清这一段灶，再沿路赶上。身旁只有一个带路的女子。

“这是你的？”他问。

阿岚把手里的木杖插进泥里：“是。”

“为什么留在我们扎营的地方？”

“不是给你们留的。”

韩简将红布摊开。布上有一个小小的结，结口系得松；她衣袖上也缺了一角，露出磨白的里布。

“昨天你说过，不认得那条岔路。”他说，“队伍改走以后，山上就有人跟着。现在你又在营边留记号，难道不是告诉他们我们从哪边走？”

“你看见谁拿这块布了吗？”

“没有。”

“那你怎么知道他们看的不是你们的脚印、火和马？”

阿岚声音不高。昨天她收了路费，却不肯认那条岔路；队伍改路后，山上便传来了马蹄声。韩简把红布攥得更紧。

“那这是给谁的？”他问。

“给我弟弟。”

她说弟弟前几日去山另一头找姑母，到现在没有回来。两人从前约定，若错过村口，就在常走的路边用布条做记号；系一个结是“我经过了”，两个结是“别等”。这块布是她前日留下的，昨晚雨大，她回来找，却见军队在此扎营，没敢靠近。

“前日？”韩简将布翻了个面，“这上面的泥很新。”

“雨把旧泥冲了，又溅上新的。”

“也可能是你昨晚才放。”

“也可能。”她抬眼，“你要写成昨晚放的，还是写成你不知道？”

韩简把布放回石上。他可以把她带到队伍里，请人审问；那样不必自己承担放错人的责任，却也意味着接下来没人能问清那条被雨冲坏的路。她说错一次，他会记在账上；如果他冤枉了她，别人也未必会替她记一笔。

“你的弟弟知道这块石头？”

“他带我来过。石头背面有一条白纹，翻过去就认得。”

韩简翻过石头，背面果然有道白纹。他把布压回去，又添了块小石头挡风。

阿岚看着他：“你为什么不拿走？”

“我要把它带走，你弟弟来的时候看什么？”

“你刚才还说我通风报信。”

“我还没查清。”

他把这一小片营地的灶数记在木牍上：十二。旁边另画一道短线，表示其中有两口靠水边，可能被下一场雨冲掉。十二口只是他受命查看的这一段，整支队伍有多少灶，他没有数过。

阿岚盯着那些灰坑：“昨晚烧饭的人没有这么多。”

“你倒数得清楚。”

“我听得见锅盖响。灶比锅多。”

韩简想起上面传下的命令：每名吏士不止留一口灶，往后的营地还要增加。这一路他们这支队伍并没有接到援兵；有人问为什么不把力气省下来赶路，得到的回答是照令做。韩简不知道其他方向的安排，只知道他们不能在旧营停太久。

“你们是要等援兵？”阿岚问。

“军中的事不能告诉你。”

“那这十二口灶也不能告诉我？”

“你已经看见了。”

她蹲在离灰坑两步远的地方。昨晚几个人分头添灶，真正煮饭的却只有几口。

“你们走了，他们可能会来数。”她说。

“你怎么知道？”

“我在山里见过人沿着别人留下的火灰找路，也见过他们什么都不找，直接去村里拿粮。”

“你以前给他们带过路？”

阿岚握紧木杖：“给来买羊的人带过。后来有人跟着那些人，进村拿走了粮。是不是同一拨，我不知道。”

“你没在来时说。”

“你们问我能不能走到山口，没问我认识谁。”

韩简想说军中不可能把所有事都问一遍，话到嘴边却停了。昨天她指着岔路说不敢保证的时候，他嫌她说得不干脆；现在她解释得太多，他又怀疑每一句都藏着别的意思。

“我会把红布的事报上去。”他说，“包括你说是给弟弟的，以及我没有看见谁拿它。”

“那我还能跟着走？”

“我不能一个人决定。”

阿岚看向石头：“让我再等一会儿。他知道我会留下布。”

“队伍已经出发。”

“我知道。”

韩简看了看日头。再晚一点，他就可能赶不上负责引路的人。留下来等她，会误了自己的时辰；强拉她走，也不一定能换来她把路说清楚。

他从包里拿出一小片没有写字的薄木，递给她：“你要留话，可以写在上面。我看过再放。”

“你识我的字？”

“不一定。”

“我也写得不好。”她接过木片，用炭在上面画了一条弯线，又画两个小点，“这是姑母住的那道沟。弟弟如果没找到她，会知道我去那里等。”

韩简看了半晌：“这不是往军队走的方向？”

“不是。你若不信，可以问前面替你们认路的人。”

他没有把木片压回石下。哪怕图画的真是另一条沟，他也无法确认它对跟踪的人有没有用。他请阿岚将地方说清楚，等追上队伍后，由负责的人决定能否留下。

阿岚伸手要木片：“我不留了。”

“你刚才不是要等他？”

“我留了，你要带走查；你们一查，他来了也找不到。我先去姑母那里。”她将木片折断，炭线从中间断成两截，“若他看见红布，只知道我经过，不知道我还在不在这儿。”

韩简看着她把两截木片收进袖中，没有阻止。石下只剩那块红布。

两人赶上队伍时，日头已偏。韩简向负责的人如实报告：发现红布，阿岚称前日留给家人，他没有看到别人取用，无法确认是否与跟随者有关。对方让他继续看住向导，查清后面的路，不准把未经核实的怀疑写成定罪。他原本争取到的前队察路差事已交给别人；他来不及跟上，只能留下陪阿岚，错过这一回在前队立功的机会。

他回来时，阿岚正在给磨破的鞋底缠布。她没有问他报了什么，只把木杖递给他看：杖头的铁箍松了，每走几步就会敲一下石头。

“你们怕被人听见？”她问。

“在这里不必把每一步都藏起来。”他说，“前面那一处，别人还得看见灶。”

“灶会告诉他们你们来过，也会告诉他们人多。”

“也可能有人不信。”

“那你们怎么办？”

“继续走。”

阿岚将铁箍重新压紧，没有让他替自己修。她在这条路上长大，知道雨后哪块石头会滑；可山里的人也会记错，尤其是树倒了、路被踩乱以后。她昨晚没有把岔路说死，并非为了等一个谁能跟上，而是三年前的山洪冲掉了一截旧坡，她没有在雨后走过。

“如果前面的人问你，你还是这样说？”韩简问。

“我会说我最后一次走是什么时候。走过，不等于今晚还一样。”

他将这句话记在木牍空处，写完又给她看。阿岚指着一个字，告诉他“雨后未走”比“路坏”更准；路也许坏了，也许没有。韩简改掉原来的判断，把牍收起来。

傍晚，队伍在更前面一处谷地短暂歇脚。韩简和阿岚站在坡边，望向下面。炊烟并不浓，一股一股从土色之间升起；他能辨认自己要查的那一段，新的灶位比上一处多。烟有的已经散了，有的刚冒头，不能用眼前看见的烟柱推算整支军队的人数。

“这里二十四。”他数了一遍，又从另一头数回来，“只算这段。”

“昨晚十二。”阿岚说。

“这一段是。”

山口外传来一阵动静，两人都停了。韩简抓住刀柄，没有拔。声音隔着坡，可能是石头滚落，也可能是有人赶路；他叫阿岚退到自己能看见的位置，随即向队伍所在处报告，没有声称看到了追兵。后来后哨带来消息：前一天的十二口旧灶旁，追在后面的人曾逐个查看；他们究竟怎么想，报信的人也不知道。

阿岚退了两步，却没有站到他背后：“我可以告诉你那边有什么，不等于我要跟你一起猜是谁。”

她指着坡下的干沟，说春天水大时沟里能走船，现在只剩泥；往南有一块突起的岩石，人能从岩后过去，但她不知道今晚有没有人在那里。韩简把“她见过的地形”和“此刻没有看见的人”分开记。他不能因为向导说得熟，就让自己的兵去赌一个她也看不见的位置。

远处的动静后来停了。队伍将要继续向前，负责的人从另一侧过来，问阿岚能不能认到下一处水源。她说自己能领到旧井附近，井里还有没有水得去看；如果要她带路，她想先确定姑母所住的沟有没有消息。

对方只说可以在安全时转告沿路遇见的人。韩简对阿岚说：“刚才你说没走过雨后的路，是我没报清楚。”

她没有立刻原谅他的怀疑。她从袖中摸出断开的两片木，炭线已经蹭花了。她拿出其中一片，在背面写了姑母那道沟的称呼，给韩简看：“这面可以说。另一面我不留，免得别人拿去当我的路图。”

韩简看完，把木片还给她。她自己将它交给负责传话的人，没有把弟弟的姓名写上；对方是否会遇到人、消息能否送到，都没有答案。

韩简将旧营的十二与新营这一段的二十四一并报上去，也写了红布和自己无法确认的部分。负责的人没有因为他坦白就说他一定做得对，只让他继续留意；若再发现异常，就把能看见的事实和猜测分开。

夜里队伍又要动身。阿岚背上包，朝留下炊烟的谷地望了一眼。那块白纹石已经在他们身后，红布仍压在那里；她弟弟是否会走到那里，她不知道。

“你以后还会翻那块石头吗？”韩简问。

“有机会才会。”

“现在可以跟着我们，也可以等负责的人安排。”

“我带你们到旧井。”她把木杖举起来，铁箍已不再响，“到了以后，我要去找我姑母。你不能因为我走，就说我泄路。”

“我不会替你写成已经证实的事。”

“也不能写成已经查清没有。”

韩简点头。两人沿着队伍留下的方向向前。次日天亮，后哨报来：追在后面的人又逐个查看了那一段二十四口旧灶。红布有没有被看见，消息上没写。

山谷里的余烟慢慢变淡，韩简收好两日的木牍。下一段路还要走，他没能参加前队察路，阿岚要找的人也还没有消息。

# 百灶疑兵｜短片剧本候选

H005｜历史题材｜目标 90 秒｜旧营外山坡、前方山坡两场｜两名出镜演员｜低特效

普通候选稿，本轮已独立审读并复核；未通过严格人物隔离排练，未经作者采纳；原创提案查重与权利审查待完成。时间、两处山坡、炊烟与道具动作待试拍试剪。

史料边界：据《[后汉书》卷五十八·虞诩传](https://zh.wikisource.org/wiki/後漢書/卷58)，虞诩赴武都受阻，先停军并宣言请兵待援；对方分散后，他日夜进道，令吏士作灶并逐日增加，以示兵多，记载称追兵不敢迫近。[四库本卷八十八](https://zh.wikisource.org/wiki/後漢書_(四庫全書本)/卷088)对读可见“灶”字；卷五十八在线整理文本有字形讹异。韩简、阿岚、红布及本片后哨报告均为虚构；两次查看只涉及两段虚构营地，不据此断定史书具体兵数、灶数或对方内心。

人物：韩简，东汉年轻军官，怀疑山地向导泄漏路线；阿岚，身份未明的向导，想留消息给与她失散的弟弟。后哨、负责军官与追兵只以简短文字消息或人物叙述呈现，不出镜、不发声。

空间与道具：两场相距一日行程，以时间跳切表达。旧营外山坡可见已撤营地的一段灶迹；第二处是更前方山坡，可望见前一夜营地的余烟。十二、二十四只指各营地中同一队受查的一小段，不表示全军人数。红布压在白纹石下，木牍由韩简持有；阿岚折断自带的留言木片，不折报告灶数的木牍。

## 场一｜旧营外山坡｜晨｜外（0—45 秒）

雾里，旧营一段露出十二个灶迹。韩简记在木牍上，翻开一块有白纹的石头，取出红布。

韩简：昨天你不肯认那条岔路，后面就有动静。这布是给谁看的？

阿岚：给我弟弟。我前日放的。他去找姑母，还没回来。

韩简：没人看见谁取布。我得把它报上去。

阿岚：脚印和烟也能给人带路。岔路下过雨，我不敢说还认得。

韩简把红布压回白纹石下，另以小石块挡风。

阿岚在木片上画姑母所在的沟。韩简伸手：这图得先交上去看。

阿岚抢先折断木片：再查下去，弟弟来了也找不到我。这图落到别人手里，还能给人带路。

韩简记下她的说法；阿岚望向石下的红布，跟他离开。

## 场二｜更前方山坡｜次日晨｜外（45—90 秒）

隔谷可见前一夜营地的淡淡余烟。虚构剧情中，这支队伍一路没有接到援兵。韩简展开两片木牍：“第一夜，这段十二口；第二夜，这段二十四口。”旁边一片虚构后哨传来的记录写：“追在后面的人分别查看过两处旧灶。”

阿岚：没有援兵来，他们却会以为人越来越多？

韩简：将军要他们这样想。至于信没信，我不知道。

阿岚回望旧营方向，握着折断的木片。

韩简：我把怀疑和不知道一起报上去了。前队察路换了别人，我留下看住你。

阿岚取出先前折断的一片木片，在空白背面写下姑母所住的沟，递给韩简看：这面可以请沿路的人转告，不写我弟弟的名字。

韩简看过，把木片还给她。

阿岚把木片收好：遇到传话的人，我自己交。我带你们到旧井，再去找姑母。你别把怀疑写成已经证实。

韩简收起两片记录灶数的木牍：我会照实写。

二人沿队伍方向离开。谷中余烟未散，弟弟去向与红布是否被取走均未知。切黑。
