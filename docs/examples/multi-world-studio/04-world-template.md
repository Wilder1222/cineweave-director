# 世界设计模板

这是一份可直接复制的新世界立项模板。它用于把创作意图整理成可审查、可版本化、可推演、可生产的世界档案；它不是一次性提示词，也不代表其中的草案已经进入正史。

使用原则：

- 只填写会影响创作、连续性或生产决策的内容；未知项写“未定义”，不要让 AI 自动补齐。
- 世界事实、当前状态、叙事安排、表现方式和生产执行分别管理。
- 所有锁定、正史变更、权利确认与对外发布都需要具名人类批准。
- 每个引用资产只承担声明过的角色；公开可见不等于拥有使用、改编或再分发权。
- 模板中的方括号内容均需替换。候选项在批准前一律保持 Draft。

故事引擎说明“为什么能持续发生故事”，不是首季剧情摘要。

> 一个具体人物想完成一件日常但重要的事；世界规则制造阻碍；人物在压力下选择；代价被结算；至少一个状态发生可记录变化。

## 12. Locks 与变更边界

| Lock | 含义 | AI 可做什么 | 何时可改变 |
| --- | --- | --- | --- |
| Hard | 正史、身份、地理、接触、连续性、权利等不可漂移事实 | 检查、引用、报告冲突 | 仅由具名人类批准新版本 |
| Soft | 倾向明确，可在边界内探索 | 提出有限候选并标注差异 | 责任人批准或在声明范围内调整 |
| Free | 已声明的自由探索空间 | 生成候选 | 不得反向覆盖 Hard / Soft |
| Undefined | 尚未作出决定 | 保持空缺、提出问题或候选 | 经过决策门后变为明确值 |

### 锁登记表

| Lock ID | 对象 / 字段 | 等级 | 原因 | 允许变化范围 | 依赖 | 决策人 | 最后批准 |

规则：

- Undefined 不等于 Free。
- 新生成图、热度数据或模型偏好不是解锁依据。
- 风格、镜头、服装和提示词不能覆盖 Canon 身份、地理或因果。
- 锁只绑定精确对象与版本；批准不会自动继承到新版本。

## 13. 人工审阅门

Gate 使用语义稳定 ID；显示顺序可以改变，ID 不随文档编号变化。

| Gate ID | 触发时机 | 必要输入 | 审阅重点 | 允许结果 | 必须批准者 |
| --- | --- | --- | --- | --- | --- |
| `gate.portfolio-fit` | 候选进入组合前 | 母题、独立性、资源角色与风险 | 是否符合母品牌且不依赖跨世界补强 | Approve / Revise / Reject | 母品牌负责人 |
| `gate.world-inception` | 进入正式孵化前 | 世界承诺、差异化、日常与风险 | 是否值得长期生产 | Approve / Revise / Reject | 创意负责人 |
| `gate.rules-canon` | 锁定基础世界前 | 规则、代价、例外、历史 | 因果可检验、无自我取消 | Approve / Revise | 世界负责人 |
| `gate.character-identity` | 可复用身份入库前 | 中性多视图、行为与权利 | 稳定身份、无参考污染 | Lock / Revise | 角色负责人 |
| `gate.scene-geography` | 可复用场景入库前 | 平面、锚点、交互测试 | 地理、尺度、物理一致 | Lock / Revise | 场景负责人 |
| `gate.style-activation` | StylePackage 启用前 | 验证集、参考与权利 | 不改 Canon、可重复 | Activate / Revise | 视觉负责人 |
| `gate.story-canon` | 不可逆事件写入前 | EventCard、分支、连续性审计 | 动机、代价、后果 | Promote / Revise / Reject | 叙事负责人 |
| `gate.cross-world` | 建立世界间事实前 | 参与世界的精确 Canon 与边界影响 | 双向影响、权利与长期成本 | Promote / Reject | 母品牌负责人 |
| `gate.production` | 调用媒体 Provider 前 | 权利、分级、资产、预算与控制 | 可执行、可追溯 | Execute / Block | 制作与权利责任人 |
| `gate.release` | 对外发布前 | 媒体、文案、连续性、权利与 QA | 可发布、可撤回、可追溯 | Release / Block | 制作、法务与发行责任人 |

任何 Gate 都必须保存：

- 决策对象的精确 ID、版本与内容哈希；
- 审阅人、角色与时间；
- 通过、修改、拒绝或阻断结果；
- 理由、条件与到期时间；
- 新版本是否需要重新审阅。
