# 世界组合与立项矩阵

状态：`draft v0.1`

## 1. 组合目的

首批世界不是为了覆盖所有题材，而是验证四种互补能力：

1. 小尺度人物与日常连续性；
2. 大尺度文明、生态和动作奇观；
3. 现代城市中的高频单元情感故事；
4. 明亮、年轻、适合动画与衍生的探索世界。

## 4. W03 候选卡：《雾城失物局》

观众承诺：

> 城市里某些失物会保留主人最后一次强烈却未说出口的情绪；失物管理员在归还物品时，也逐渐发现有人正被城市的共同记忆抹去。

候选规则：

1. 情绪回声是主观片段，不能证明客观真相。
2. 物品被真正接纳或归还后，回声会消失。
3. 长期接触回声的人会混淆他人与自己的记忆。

生产价值：现代地点复用率高，单件物品可形成短内容与单元剧。尚需确认能力边界、伦理处理和首季对手，故保持 `candidate/free`。

## 5. W04 候选卡：《潮生星港》

观众承诺：

> 海洋世界的岛屿会随天潮迁徙，所有地图都会过期；年轻制图师发现，千年潮汐正在偏离，整座星港必须决定迁徙、停留或改变与海洋生命的契约。

候选规则：

1. 航图有有效期，没有永久正确的地图。
2. 淡水、天气和安全航路是可储存但有损耗的资源。
3. 巨型海洋生物与城市基础设施共生，伤害一方会改变另一方。

生产价值：适合动画、物种设计、船舶、地图和年轻向衍生。尚需证明人物压力与制作可行性，故保持 `candidate/free`。

## 6. 世界立项评分

每项 1–5 分，任何阻断项低于 3 都不得进入重资产生产。

| 维度 | 评审问题 | 阻断？ |
| --- | --- | --- |
| 一句话差异 | 不提世界名，观众能否理解独特承诺？ | 是 |
| 规则与代价 | 规则能否迫使人物做艰难选择？ | 是 |
| 日常密度 | 没有主线危机时，世界是否仍可生活与观看？ | 是 |
| 人物入口 | 是否有一个具体而非全知的视角角色？ | 是 |
| 资产复用 | 五个英雄地点和四个角色能否产出多种内容？ | 否 |
| 视觉独立 | 色彩、材质、尺度和运动是否区别于现有世界？ | 是 |
| 内容续航 | 是否自然产生至少 30 个内容 Brief？ | 否 |
| 生产可行 | 当前团队能否用小规模样本验证？ | 是 |
| 权利可解 | 历史、参考、肖像与商业使用能否合规处理？ | 是 |

总分只用于排序，不能抵消阻断失败。

## 8. 升级与暂停条件

### W02 升级

- W01 已稳定运行至少三个发布/复盘周期；
- W02 的角色选择与生态机制通过故事评审；
- W02 风格能与 W01 明确区分；
- 巨构资产存在可复用结构，不依赖每次重建；
- 权利与能力要求可被当前生产系统满足。

### 候选世界升级

- 一句话差异和阻断项均通过；
- 能用一个核心角色、一个地点和一个事件做低成本验证；
- 新世界填补组合空缺，而不是复制现有受欢迎表面；
- 提升它不会破坏主世界交付。

### 暂停

- 只能产出概念图，无法形成角色选择；
- 视觉必须依赖不可解决的参考权利；
- 生产成本显著高于可验证价值；
- 与现有世界的观众承诺或视觉高度重叠；
- 连续两轮修复仍无法通过阻断项。

暂停不是删除。保留 World Card、证据与失败原因，等待外部状态变化或新版本提案。
