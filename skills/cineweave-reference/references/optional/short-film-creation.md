# 可选参考：完整短片创作与全套提示词

当请求完整短片、剧本到分镜、全套提示词或跨部门创作包时加载。目标是完成约定范围内的叙事、视觉、表演、摄影、声音与剪辑设计，并给出每项可直接使用的创作稿。参考片和平台未知不阻止原创通用方案；实际生成、录音和剪辑结果仍需外部工具及真实证据。

## 从单镜头设计升级为整场戏的导演工作流

当请求完整短片／短剧或多镜场次，先读取[场次级导演生产关卡](scene-directing-pipeline.md)，以 G0 戏剧／观察任务、G1 视觉与人物基线、G2 世界空间、G3 场面调度、G4 摄影语言和覆盖、G5 声画预演、G6 试片与试剪方案、G7 有证据的评审修复顺序组织交付。每关传递必要的权威切片，不复制第二份世界、角色和场景事实；场次级镜头剪辑可行性不能只靠单镜好看来证明。

角色日常生活、电影叙事和同一多角色 IP 可以使用同一世界 Canon 与不同场次意图。日常片允许无重大冲突的共享活动、等待、交谈和小发现，镜头变化围绕注意力／时间／情绪而不是强制反转。实例与证据边界见[《玄奘》双段导演案例](xuanzang-director-case-study.md)。

## 每阶段以实际产物交接而不是完成动作

完整短片／短剧必须执行[阶段结果产物清单 v1](scene-directing-pipeline.md)，按 G0–G7 交付真实可打开的结果文件或可独立定位的完整源码，不得只给「后续制作」的清单却将阶段标记完成。特别是 G1 风格卡、配色卡、材质卡、灯光卡、光位图及 LookDev 测试板必须实际存在；G2 还要有场景结构图，G3 要有调度卡，G4 要有分镜板，G5 要有时间线，G6 有可否定的试片单，G7 有有来源的审阅报告。

**严格区分** `missing`、`design_ready`、`pending_media` 与 `production_ready`。只有设计成果仍可继续写下游条件方案，但真实身份、视频、光学表现和可剪辑成片不能判为已完成。两案示例可参见开发包 `tests/evaluations/2026-10-16/stage-results-v1.md`；只有在仓库开发环境才运行 `npm run stage:check`，一般创作无需安装开发依赖。

## 交付规模

先继承用户已明确的故事、参考、时长、媒介、画幅、台词和创作授权。只要单项就完成单项；要“全套”则完成下表中所有适用产物。当前明确范围内不要只交前两镜或一个示范再要求继续；大项目按场次分文件或分批完整写出，并维护总清单，不把遗漏项标成已完成。

| 交付 | 必须形成的可用内容 |
| --- | --- |
| 故事与导演方案 | 戏剧任务形成核心问题、人物目标与选择、梗概、因果节拍和可表演剧本；观察／散文任务形成给定活动、感知或联想关系；两者都交代观众信息路径与视点 |
| 视觉开发 | 主方案与必要探索、人物／外观／表演母稿、场景结构与光色、必要道具、资产视图及对应提示词 |
| 分镜与摄影 | 镜号、节拍、时长、空间与轴线、景别构图、机位与焦点、动作表情、光线、声音和切点 |
| 图像与视频稿 | 按所选路径交付单镜／多镜视频稿，以及必要的资产、首帧、首尾帧、全能参考映射或分镜板生成稿；不要求每镜都有首帧图片 |
| 配音与声音 | 角色声线、准确台词、语气重音与停顿、同步窗口、环境／拟音／音乐设计与制作稿 |
| 剪辑与验收 | 成片窗口和源采用区间、转场理由、声画衔接、字幕、调色与输出意图、候选验收和返工范围 |

文字方案已经完成、素材待制作、平台控制待核验是不同状态。可以完整交付草稿，不得用缺少真实媒体为由少写已经能确定的提示词。

## 阶段交接

跨领域任务按下表识别已经完成的输入及缺口。阶段检查是本次授权内的内部检查，不是默认逐步询问用户的审批流程；只缺某项外部证据时，暂停依赖它的最终确认，其余草稿继续完成。已有合格分镜或资产可从相应阶段进入，不重做全部上游。

| 阶段与主要职责 | 输入 | 交给下游的内容 | 进入下游前检查 |
| --- | --- | --- | --- |
| 叙事与导演意图 | 创作请求、已有剧本或视觉线索 | 观众体验、信息变化、视点、节拍和交付范围 | 每个必要节拍有可见／可听表达；准确台词和用户限制保留 |
| 共享视觉设计 | 故事需求、参考职责与已有设定 | [表现媒介与基线](../core/visual-bible-and-continuity.md#表现媒介与共享设定)、人物场景道具母稿 | 稳定身份、当前外观、媒介规则及原创补全部分可区分 |
| 调度与镜头设计 | 节拍、共享空间和人物状态 | 位置关系、走位、机位、光源、表演、镜头表及声音事件 | 关键接触可达、注视有对象、取景可读、时长容纳动作 |
| 衔接与提示词编译 | 镜头设计及资产来源 | 成对边界、独立资产／静帧／视频／声音稿、必要适配稿 | 各任务有实际正文；起止状态与相邻镜头相容；平台未知不冒充支持 |
| 候选与剪辑交接 | 实际媒体或明确待制作稿、时间表 | 采用区间、发现的问题、保留项及返工范围 | 有媒体才判定媒体质量；只有文本时只报告设计完整性和一致性 |

优先使用当前阶段需要的路由和专项章节，不把全部电影资料一次读入。六层人物表演由细节规范维护，声音由声音指南维护；此表只管交接顺序和输入输出，不复制专业清单。

比较导演方案时携带同一简报与不变项，声明允许改变的视点、覆盖、时序或声音维度。选中决定进入实际稿件，排除理由和有效备选留在其外；备选不覆盖主方案或共同视觉。完整交接例见[镜头工作台](shot-design-workbench.md#同一场次的覆盖对照)，简单任务不扩成方法研究报告。

### 镜头之间的边界

在逐镜提示词定稿前，检查相邻镜头的出入点：人物和物件位置、接触／持有状态、动作相位、视线目标、摄影机轴线侧、光色以及对白与环境声。记录切点原因及连续、时间省略或主观跳接的设计。连续切镜要求状态可接，不要求两个画面逐字相同；人物开门、光源移动等有动机变化要保留。

区分一段生成视频内部的起止、两个独立镜头的剪切、以及后期转场。多镜头段落是剪辑组织，不自动等于一次模型调用；原生多镜模式未知时仍交付逐镜稿，再给分组建议。成片时长、生成候选长度与采用窗口分别记录，不默认固定秒数、分辨率或帧率。尾帧只在用途和能力需要时生成，切换机位也不强迫靠形变过渡。

### 长任务的接续

全套任务使用一份产物清单，按场次或段落分文件完成。阶段结束记录已完成稿件、尚缺项目、引用基线和下一项工作；达到长度边界时保留可恢复位置，不把尚未展开的镜头标为完成。已授权的后续场次继续编写，无须每场重新征求同意。

接续时携带当前范围、共享设定来源、已完成镜号、上一段出点、未决问题和剩余清单；具体状态与影响传播统一使用[恢复检查点](drafts-and-change-impact.md#修订工作表与恢复检查点)。不要复制整段对话作为第二套权威，也不将“文本定稿”升级为“素材可剪”。

## 叙事如何变成镜头

戏剧短片从一项可看见的核心变化组织：人物原先处于什么状态、发生了什么刺激、作出什么选择、付出或获得什么、结尾留下什么关系。开端和结尾可形成视觉呼应；不为追求反转强加秘密，也不把三幕固定比例当作所有时长的规定。观察、主观经验或散文影像可由持续活动、注意发现、记忆或联想组织，不要求每场都有价值翻转；混合形式说明当前段落承担的功能，不擅改已锁定因果。

节拍不是对白行、自然段或换机位。先写人物及观众各自知道什么，选择哪个行为或画外声揭示新信息，再决定镜头和切点。一镜可以承载连续动作中的多个小节拍；空间、时间或信息视点需要改变时再拆镜。对白能被动作清楚表达时不重复解释，但用户给定台词必须逐字保留。

导演方案用简短、明确的决定解释视点、视觉母题及其变化、关键空间关系、表演尺度和声画关系。技法服务本片，不能借大师名字自动更改色板、人物比例、音乐或画幅。保留全片一致基线，允许有原因的照明、场景或主观表现变化。

从导演意图进入分镜时，检查放映时长、叙事经过和观众发现窗口各自是否改变；重复、重演、记忆与联想不能互相代称。定义与例外统一见[剪辑与声音方法](editing-sound-craft.md#三种时间分别检查)，本流程只携带已选关系及需要保留的线索。实际观众解释尚未检验时仍是预期体验。

## 逐镜 Camera Language Selection

完整影视创作从人物场面 Blocking 到分镜／视频复制稿之间，必须对实际镜号逐一执行[镜头语言选择](../routes/shot-direction.md#镜头语言选择关卡)并继承景别、视点、构图、静止或运动、焦点、触发、切点及相邻连续性。所有输入路径（T2V、I2V、首尾帧、全能参考、分镜板）保留同一镜头母稿，平台兼容问题回流导演而非无声删除摄影设计。
## 视觉开发到分镜

按[视觉开发](visual-development.md)把人物、服化道、表情姿态、场景和风格收敛为可复用资产。主方案充分描述[细节规范](prompt-detail-standard.md)中的相关维度；探索只改变待决定内容，不让备选污染主方案。

多人物互动先给空间图或位置表，固定场景方向、人物朝向、视线目标、摄影机轴线侧、出入口、接触物和光源。逐镜说明相对位置、谁遮挡谁、什么时候显露、道具在哪里、人物与相机各自怎么动。无关的几何数值可以省略，关键触及和运动通道不能含混。

摄影和表演同时对齐：景别能否读到表情，机位能否看到关键接触，焦点转移是否恰好错过动作，光影是否吞掉必须识别的信息。把情绪转成眼睑、眉头、唇缝、下颌、眼神、肩颈、手势和动作速度；全部选择需符合角色目标与当前镜头尺度。

## 逐项编写提示词

提示词表以用途区分资产、首帧、尾帧、视频、配音、音效和音乐。每条有清晰名称与对应镜头，正文可独立复制；说明、依赖和参数放在正文外。普通正文是默认，用户要节点格式时才使用[类型化标签](tagged-video-nodes.md)。

先按[视频路径](video-platform-adaptation.md#模式选择与明确替代)选择输入条件与镜头组织：文字、单图、首尾图、全能参考或分镜板都可以服务完整短片。同片不同段落可以选不同路径，不默认先生成每镜首尾图。

首帧路径的图像稿只描述一个可见瞬间；文字／全能参考路径在视频稿中明确起始构图与状态，参考板路径明确画格映射。各视频稿均写准备、变化、接触、制动或持续运动、可用出点及相机与焦点行为。实际首帧或参考素材只在所选模式需要时绑定；素材名不等于已上传图片。提示词驱动多镜头要给共享设定、逐镜时间线、切点及声音归属，不能只把几段运镜描述拼在一起。

参考驱动稿明确每份图片／音视频负责身份、衣服、场景、动作或声音的哪一部分；首尾帧只有确有需要且模式支持时才增加。全套不是给每镜机械写所有模式。平台限制若要求拆镜或压缩，保留完整母稿并记录取舍，不能无声删除用户指定细节。

同一事实只维护一份权威母稿；生成逐项复制稿时展开其必要内容。更新母稿后同步消费它的稿件，避免“母稿已改而复制稿没改”。明确台词、字幕和标志文字独立保存；生成画面不能保证准确排字。

## 配音、声音与剪辑

角色声线描述语言与方言、感知年龄、音高范围、音色、共鸣、气息、咬字与常态节奏。逐句再写情境目标、重音、语速变化、停顿、起落与对话关系；声线身份、临场表演和空间混音分开。不能把“疲惫”固定成永久沙哑或把“重读”误写成方言。

台词正文不混入人物名、动作说明、时间码或控制标签。平台支持的语音标签及读音词典在适配时核验，不假设 SSML 或某家方括号标签通用。用实际音频测得时长再对齐口型和剪辑；估算窗口过短时调整可授权时序，不偷偷改字、截句或整体加速。

每镜给前景动作声、环境底声和必要画外声的声源、距离、方向、音色、开始与结束；音乐按叙事需要决定，有音乐时给器乐／音色、节奏感、进入与退出、动态及与对白的让位关系。无对白、无旁白、无音乐和成片完全静音分别说明，不混为一谈。收音与交付规则见[声音指南](video-sound-and-delivery.md)。

剪辑表使用同一时基：成片区间、源采用区间、剪切理由、相邻动作与视线匹配、声音先入／后出、字幕及调色基线。镜头可以在运动中切出，不强制每镜停稳；保留必要前后余量，未返回媒体时只称计划。最终拼接前复查实际镜头的边界状态和声音，而非只检查总秒数。

## 全套验收

逐行对照故事节拍、镜头表与提示词表：每个选中节拍有覆盖，每个计划镜头可定位到独立视频稿或多镜稿中的对应区间，并有适用声音稿；仅对所选路径需要的图片交付资产／首尾帧／分镜板稿。每条台词有准确文字与声音方案；已存在或不适用项说明依据，不因没有逐镜首帧而判全能参考或文字多镜方案不完整。

再查人物、服饰、空间、道具归属、光源方向、表演时序与声场是否跨稿一致；裁切与细节要求、动作与时间容量、台词与声音窗口、平台模式与真实附件是否冲突。没有实际媒体时验收文字完整性及一致性，不能宣称生成质量通过。

失败修订先定位一个责任根因与变量，保留其他已通过决定；修订所属母稿后同步实际复制稿，并复查受影响镜头及相邻出入点。若改变覆盖才能看清关键接触，不同时改人物动作、声音和调色来掩盖差别。完整创作草稿人工检查相关维度；综合设计／提示词评审、完整场次定稿或镜头组正式制作／规范交接沿[逐镜评审](ensemble-direction-and-review.md#覆盖范围内的每一镜)完成六视角覆盖，按指南实际运行工作表检查。结果不能代替声长测量、素材接点或观众效果，未返回媒体仍明确待验。

完整原创样例见[《留一盏灯》全套创作稿](short-film-example.md)，资产与镜头数量只属于该故事，不是其他项目的硬模板。
