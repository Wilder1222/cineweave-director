# 改编与验证样例：《图尽》

24 秒、16:9、24 fps 的历史记载改编，四镜截取献图到匕首显露的一刻。工作包 `TUJIN24@r1`。本页给出 G0–G7 正文；[阶段视觉卡板](../../assets/adaptation-example.html)提供实际可打开的设计图卡。卡板不是历史图像、生成样片或光学实测；人物、声音、动作、试剪和用户选择均待真实媒体验证。

## 来源、取舍与验证问题

来源：[《史记》卷八十六·刺客列传·荆轲](https://zh.wikisource.org/wiki/史記/卷086#荊軻)，本次读取日期 2026-10-21。定位到秦王命取地图、荆轲献图、秦王展图及匕首出现的段落。这是文献记载，不是所有细节均获独立考证的现场事实。

- **保留：**荆轲献图；所读文本写秦王展图；展开到尽头才显露同一匕首。不能因熟悉影视版本就换掉这个行动者。
- **节选：**从荆轲已接过地图开始，结束在秦王发现异常、尚未发生随后的冲突。秦舞阳、群臣及后续事件在本片段画外，不代表原文没有这些人物或事情。
- **原创改编：**案桌、人物服装与长相、卷图如何置案、光位、四镜时序、停顿及“请大王观图。”均为本样例设计；这句不是古籍引语。取景和服装不声称秦宫考据复原。
- **核心验证：**观众先看出礼仪中的控制权，再被一个逐渐露出的物件改变判断。测试展开者、纸卷结构、匕首首次可见时间、手与物的连续性、固定视点下的悬念，以及声音能否把注意引向卷尾。匕首只显露，不在本片段发动攻击。

## G0 导演意图、完整场次与节拍

导演视点：先观察献图者的克制，再把观看权交给展图者。恐惧来自刚才仍被信任的物件，不靠无来源闪光、惊吓音效或旁白解释。只让匕首在卷尾真的打开后可见。

**场次剧本：**内景，宫室，白昼。秦王在案北，荆轲在案南，双手捧着卷图。荆轲抬眼，低声而清楚：“请大王观图。”秦王将视线从荆轲移到卷图，没有回答。

荆轲把同一卷图放到案面，先让图接触桌面，再松手退回自己一侧。秦王左手按住已经露出的图边，右手推动卷筒。纸面逐渐展开，摩擦声在安静宫室里变得清楚。荆轲不伸手帮他。

卷到尽头，一柄原本被图覆盖的匕首露在纸上。秦王的手停住，视线先落在金属上，再抬向荆轲；肩颈微收。荆轲仍在原位置，双手空着，眼神没有躲开。纸卷的余动停下。切断画面，不续写抓袖、攻击或追逐。

| 节拍 | 前态→触发→行动→后态 | 镜头／观众所得 |
| --- | --- | --- |
| B01 | 图尚在荆轲手中→请求观看→秦王转移注意→观看获准 | S01；两人礼仪关系与危险的无声底色 |
| B02 | 卷图被捧持→案面已可放置→先落案再松手→荆轲双手空 | S02；把同一物件的控制权交到秦王面前 |
| B03 | 秦王尚未展图→主动接触→展开至卷尾→金属首次显露 | S03；日常动作带来不可逆的信息改变 |
| B04 | 发现异物→秦王停手抬眼→二人对视→礼仪平衡破裂 | S04；观众等待尚未发生的下一行动 |

## G1 视觉开发六件设计与资产

### G1-STYLE

低调、自然可信的宫廷悬疑摄影。人、纸和金属的体积清楚，景深按信息需要选择；不自动上大红、大金和浓雾。大部分画面为旧木、墨褐和中性衣料，卷图是较亮的信息平面。镜头不替演员制造夸张表情，不以“帝王气场”代替视线和距离。图卡使用抽象轮廓表示构图，不冒充历史人物肖像。

### G1-PALETTE

以下均为原创 sRGB 显示预览，不是古物取样、肤色目标、LUT 或实际照明参数。未选 CG／MU，不能靠近似风格猜编号。

| 色样 | 显示值 | 作用与保护 |
| --- | --- | --- |
| 旧木 | `#554438` | 案桌和柱，暗部仍有木纹 |
| 墨褐 | `#292A28` | 秦王深色袍、背景层次，不压成纯黑 |
| 麻灰 | `#8A8271` | 荆轲衣料，区别皮肤与纸 |
| 图纸 | `#CEC2A0` | 地图的纤维平面与既有折卷，非发光黄纸 |
| 钝银 | `#929999` | 唯一匕首的窄反光，显露后才出现 |

本场共用一个白昼基线。S03 金属显露只改变局部反光，不整场变冷、不突然熄灯。若另作夜景，需单独建立变体，不能偷偷污染本版。

### G1-MATERIAL

| 资产 | 结构与表面 | 在本场怎样可读 |
| --- | --- | --- |
| JING | 麻灰织料、深褐束带、自然皮肤与束发 | 织纹服从衣褶，汗意只在已设计的额角，不磨皮换脸 |
| KING | 墨褐织袍、暗色窄缘、平整袖口 | 袖口不能挡展图接触；黑衣、木案和背景可分 |
| MAP | 单一米黄色纤维卷图，褐线示意疆界，无需可读地名 | 纸有厚度和卷曲恢复，不能突然变竹简、布帛或第二卷 |
| DAGGER | 单柄暗色握柄、短直金属刃、旧而无装饰 | 窄反光随实际光源，不能提前透纸发光或变长剑 |
| HALL | 旧木案、深木柱、中性硬地 | 案面有接触阴影，地面不无故湿亮，无现代装置 |

### G1-LIGHT

世界源 `L-EAST` 为宫室东侧高窗的宽而柔日光；现有浅墙产生弱反射，`R-WALL` 是反射关系，不是新增灯具。东侧脸部与案面较亮，远窗面仍保留体积。金属高光来自同一窗光；卷图未打开前不得凭高光提前泄露藏物。没有照度或色温测量，不给伪精确参数。反打不把窗从东移到西。

### G1-PLOT 与 G2 空间图

北在上，东在右；案长约1.2米、南北深约0.65米为可撤销设计假设，具体触达与遮挡需预演。秦王在北面南，荆轲在南面北；镜头均在两人关系轴东侧。C1/C4 为东侧共享视点，C2 在东南侧读荆轲的手，C3 在东北侧略俯读秦王的手。主光窗也在东侧，机位不得挡住需要的光路。

```text
                北：秦王，面南
        西柱   ┌──已露图边，秦王左手按持──┐    东窗 L-EAST
               │  图纸的展开带与卷尾区域 │  ← 宽柔光
               └────────案南缘─────────┘
                南：荆轲，面北
                    C2 ↗  C1/C4 ←  ↖ C3
                 机位均在关系轴东侧（图中示意）
```

上图机位文字只作方位索引，配套卡板用真实二维坐标放置东南／东北机位。地图的卷筒沿南北方向展开，左右两手不互换；道具与手具体距离不由这张图证明。

### G1-TEST

卡板提供五格已绘制的测试设计；格内没有真实样片。固定人物、服饰、案桌、同一卷图、匕首形态、窗光和观看条件，再比较每项独立问题。

**T1 近景稿：**成年荆轲，长方脸、深棕眼、黑发束起、少量胡茬，麻灰交领衣和深褐束带，宫室案南，面向画外北侧秦王。胸口以上近景，眼神稳定、闭唇、下颌略紧，抬眼但不瞪眼。东窗柔日光保持自然肤色和衣料细纹，暗侧可读，背景旧木不抢眼，无额外人物、血污、烟雾和光效。判据：身份、衣纹和克制表演可读；样片未提供。

**T2 空间稿：**16:9 宫室空镜，从东侧平视看向旧木案和西柱，北侧为秦王座位区，南侧为使者停步区。案面只放一卷尚合拢的纤维地图，刀具完全被覆盖且不可见；东侧高窗形成宽柔日光，木案、硬地与墙面层次分明，没有红毯、现代器材、无来源背光或额外兵器。判据：方位、案边与机位区可定位；样片未提供。

**T3 材质稿：**同一窗光下的案面近景，旧木、麻灰衣袖、纤维地图及一柄单独用于资产研究的旧金属匕首并置，图中明确是脱离剧情的材质研究，不作 S01 首帧。四种表面尺度真实，纸不塑料化、衣料不金属化，金属只窄反光，无文字标签或多柄兵器。判据：材质有区别；研究图不得污染藏物未显露的剧情初态；样片未提供。

**T4 展开稿：**固定东北略俯的手部中近景，秦王墨褐袖口收整，左手按同一地图北边已露平面，右手缓慢推动南侧卷筒，纸逐步铺开，卷尾完全打开后原有匕首才首次可见。荆轲双手退在案南、全程不代为展开；匕首留纸上不动、不透纸显形，不增加第二次展开。东窗与木纹稳定，无对白，无音效夸张，只纸纤维摩擦。判据：行动者、首次显露和连续接触；视频未提供。

**T5 配对稿：**东侧共享中景中，荆轲在画面左、秦王在右，案面与卷图位于中间；切到东北略俯手部时仍从关系轴东侧看，地图北边、秦王左右手、南侧卷筒和东窗光向保留。先用同一静止半展开状态制作两镜，再比较世界锚点和握持；不把两镜同名当成已经一致。判据：机位改变但动作不倒带、不换手、不镜像地图；两张样片均未提供。

### JING

人物资产：约三十五岁成年男子，长方脸、较直眉、深棕眼、直鼻、自然薄唇，黑发束起，少量短胡茬；自然中等肤色与额角细微纹理，非演员肖像。麻灰交领长衣、深褐束带、深色朴素鞋，无甲胄与华丽刺绣。全身正面，双手空垂、站稳、闭唇、视线平稳，中性背景、柔侧前光，清楚脸部、袖口和衣纹。年龄、面貌与服装为本改编原创设计，不称出土复原。

### KING

人物资产：约三十八岁成年男子，宽额、方正下颌、较浓平眉、深棕眼、短须，黑发束起，素色冠，健康中等肤色。墨褐长袍与暗色窄缘、袖口平整，无夸张金龙或后世冕旒。全身中性站姿，双手空着，眉头舒展而神情审慎，视线正前；柔侧前光区分织物和皮肤。不使用影视演员脸，不宣称真实秦王外貌。

### HALL

16:9 宫室空间资产，无人物。南北关系明确的旧木案，北侧低座位、南侧使者区，西侧深木柱，东侧高窗，硬质地面干燥。东窗柔日光照亮案面，暗木、墙与地层次可分，无现代器材、浓雾、红毯和无来源火盆。此为戏剧空间设计，不考据某处宫殿遗址。

### MAP

单卷米黄色纤维地图资产，褐色疆界线，无需可读地名，边缘略旧而完整；只一卷，卷轴横向，展开方向沿南北，厚度和卷曲清楚。中性木面、柔侧光、俯视略斜，展示合拢状态，不同时摆展开副本，不透视显示卷内物。本资产不证明藏物实际已经绑定。

### DAGGER

单柄旧金属匕首资产，暗色朴素握柄、短直刃、清楚握柄与金属的交界，表面有克制窄反光，无铭文、宝石、血迹或流光。中性暗灰背景、四分之三静物视角，完整物件不裁切；只做电影道具外观，不提供制造、淬毒或伤害实施参数。

### S01-IMG

16:9 写实宫廷悬疑画面，东侧平视双人中景，自然约40毫米视角。左侧成年荆轲长方脸、深棕眼、黑发束起、短胡茬，麻灰交领衣和深褐束带，双手捧同一合拢米黄纤维地图；右侧秦王宽额方颌、短须、素冠和墨褐长袍，位于案北面南，双手尚未碰图。荆轲看秦王、闭唇，下颌微紧，秦王目光在荆轲脸上、审慎平静。旧木案在二人间，西柱在背景，东高窗宽柔日光保持自然肤色、暗袍与木纹层次；中等景深读两人和卷图，无可见兵器、额外人物、雾或文字。

### S01-VID

使用核对后的 S01 起图，6秒采用段，16:9，摄影机固定东侧双人中景，脸、捧图的双手与案面同时可读。麻灰交领衣的荆轲在案南画面左，墨褐袍素冠秦王在案北画面右，同一合拢米黄卷图由荆轲双手捧住、尚未落案；没有可见兵器。0–1秒二人保持审视，1–3秒荆轲抬眼，低而清楚说“请大王观图。”，唇与下颌自然随发音，双手不晃；3–5秒秦王听完才将目光从荆轲脸移向卷图，5–6秒保持观看许可后的停顿。无换手、落案、展开、额外对白或笑。东窗日光与旧木案不变，无推拉、变焦、拉焦或切镜；只保留真实空间底声、轻衣料声及准确对白，句尾完整。

### S02-IMG

16:9 同一宫室东南侧略俯中近景，约50毫米自然视角，荆轲麻灰双袖和双手捧唯一米黄卷图于案南边缘上方，卷图还未触桌。秦王墨褐袖口在画面北侧，双手离图；旧木案面清楚，东窗侧光不变。保留纸卷边缘与案面间隙、自然手指和清楚接触区，图合拢、不透纸见兵器，不把动作画成已经放好。

### S02-VID

6秒，16:9 东南略俯固定中近景，麻灰交领衣荆轲在案南，秦王墨褐袖口在北，东窗日光和旧木纹方向固定。初态唯一米黄卷图仍由荆轲双手捧在案南缘上方。0–1秒稳定，1–3秒双手将同一卷图平稳落到木案，纸卷先实际接触案面并承重；3–4秒手指再松开，4–5秒两手各自沿来路退回案南，5–6秒保持图在案面、双手已空的出态。秦王尚未代接或展开。合拢卷图不发光、不出现匕首、不变成竹简；一卷不增殖。保持接触区景深，无推近和拉焦。无对白、音乐或金属声，只有轻落案、衣料摩擦与连续宫室底声。

### S03-IMG

16:9 宫室东北侧略俯手部近景约70毫米，旧木案上同一米黄地图合拢、北侧仅露一小段纸边。秦王墨褐袖口收整，左手靠近北侧已露图边、右手靠近南侧卷筒，尚未接触；荆轲麻灰袖和空手在案南边缘，已退出图的工作区。东窗宽柔日光、自然木纹和纸纤维清楚，足够景深保护两手和卷尾；无兵器可见，无额外卷图或字幕。

### S03-VID

6秒采用段，16:9，东北略俯固定手部近景，秦王在案北的墨褐袖口平整，荆轲麻灰双袖与空手退在案南，不越回展开区。初态同一米黄卷图合拢，北侧有小段已露图边，秦王左右手尚未接触。0–1秒秦王左手按住北侧图边，右手触到卷筒；1–4.5秒由秦王右手缓慢推动卷筒向南，图纸连续铺开，左手维持平面不滑，荆轲不帮忙。4.5–5秒卷尾打开，原被图覆盖的唯一短金属匕首才首次显露在纸上；5–6秒秦王手停住，金属留在原位，纸余动自然停止。不能提前透纸显形、凭空飞刀、换成荆轲展开或重复回卷。固定中等景深读接触与首次显露，无镜头移动、变焦或遮挡转场。只连续纸纤维摩擦与宫室底声，停止时摩擦收住，无对白、拔刀声、惊吓音乐或攻击。

### S04-IMG

16:9 回宫室东侧约40毫米固定双人中景，荆轲在画面左的案南、秦王在右的案北。荆轲长方脸、束发短胡茬、麻灰交领衣深褐束带，双手空着退在自己一侧，闭唇直视秦王；秦王宽额方颌、短须素冠、墨褐袍，双手停在案面图边，视线仍落已显露的金属，眉间微紧、肩颈略收。唯一地图已铺开，一柄短金属匕首静置纸上，卷尾不再遮挡它；东窗、西柱与旧木案不镜像，不提前画成二人打斗或持刀。

### S04-VID

6秒，16:9，东侧固定双人中景，荆轲始终在案南画面左、秦王在案北画面右，人物面貌、麻灰衣与墨褐袍素冠承接前镜；东窗日光、西柱和旧木案不变。初态同一地图已完全展开，一柄短金属匕首静置图上，秦王手停在纸边、荆轲双手空且退在南侧。0–1.5秒秦王目光留金属，轻收肩颈；1.5–3秒他才抬眼看荆轲，眉间收紧但不夸张张口；3–6秒荆轲保持目光不躲，二人停在将变未变的对视中。没有重演展开、抓袖、持刀、攻击、后退追逐或额外人物。机位与焦点保持，脸和案面同时可读；无对白，纸摩擦已停，保留一处清楚吸气及连续室内底声。由剪辑切断画面，不要求模型自动黑场。

## G5 声音、准确台词与剪辑

### VOICE-JING

成年男性普通话原创声线，中低音区、自然共鸣、清楚咬字，短句压住紧张而非英雄演讲；气息克制，句尾完整。声线身份与这一句的策略分开；不模仿影视演员，不用低沉标签自动生成旁白感。

### D1-TEXT

请大王观图。

### S01-SND

采用段1–3秒为荆轲画内“请大王观图。”，较近、音量克制、无人工混响；其余保留低而稳定的宫室声场及轻衣料声。秦王不答话，无音乐、旁白、金属或开卷声。准确发声窗口待真实音轨测量，不让画外人物口型随对白乱动。

### S02-SND

同一宫室底声连续；卷图1–3秒落案产生轻纤维触木声，3–5秒衣袖撤回有低声摩擦。接触未发生前不响落案声，没有开卷、金属、脚步、对白或音乐。

### S03-SND

1–4.5秒连续纸纤维摩擦，随推动速度轻变；卷尾最后打开时声纹略疏，停止后收住。匕首原在图中未被举起或碰撞，不加拔刀铮鸣、飞刀声和惊吓音乐；宫室底声连续，无对白。

### S04-SND

纸已静止，摩擦不再重复。秦王停手后有一处受惊但压低的吸气，随后保持室内底声；没有新增台词、刀碰案或音乐。不得用声效掩盖视线早于发现的问题。

四镜各6秒连续硬切；S01→S02 从观看许可切到落案，S02→S03 从双手撤离切到秦王首次接触，S03→S04 金属已经显露才切回反应，不重放揭示。底声跨镜连续，本例没有 J-cut 对白或 L-cut 对白，不给无对应声音的术语。字幕后期独立排字，只显示这句改编对白，避开手和卷图。调色沿 G1 共同基线，异常由物件承担，不靠突然换滤镜。
