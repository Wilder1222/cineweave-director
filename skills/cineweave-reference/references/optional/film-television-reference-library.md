## 真人：12个方向

默认采用可拍摄、自然可信的实景摄影：肤色可读、衣料有重量、光源有来处、空间有使用痕迹。自然不等于不用灯、低反差或固定暖色。夜景、宫廷、悬疑和仙侠仍服从同一物理与身份基线；不用强青橙、霓虹、统一褪色、磨皮、巨大发饰或满屏特效作默认捷径。

以下恰好12个主检索方向；同类多部作品不另算类型。它们按**主场次任务**分配，并非宣称影视题材在学理上互斥。先继承世界／时代，再看主要行为；时代不明不擅定朝代。用下列顺序解决交叉：明确超自然叙事→12；军事作战与军队野外组织→7；宋／明→8–11；民国市井→6；其余现实场次按主要关系／任务归1–5。宋／明宫廷、官署礼制优先9／10，宋民间生活归8，明民间江湖行动归11；现代案件调查优先5、职业任务优先3，余下家庭协商归2、朋友与成长归1、乡镇旅居／地方生活归4。边界仍不适合时给中性方案，不硬塞；一场只选一个主方向，跨场可切换任务，整体视觉不随分类重置。

## 选择与交付

1. 继承已有角色身份、时代、服制、空间、视觉基线与明确排除项。用户指定作品时可以直接从该作品取有范围的研究线索，不强制套目录或重选题材；仅浏览、翻译、平台忠实投射时不改稿。
2. 从相关卡选一个主方向，最多补充一部作品的一个相容维度。作品名称不是结果；把美术、光线、服装和人物行为转成当前场次可见的具体方案。不能从作品名推断焦距、曝光、布光图或模型权重。
3. **文字研究与画面观察分开。**本目录本次未观看或逐帧抽样影片，也未审听音轨。作品简介只支持题材／基础身份；访谈与评论只支持其明确谈到的范围。没有实际素材就交付迁移提案和待查项，不写“该镜头可见”。需要精确造型／接触／镜头时通过[参考路由](../routes/reference-evidence.md)读取实际素材并保留观察选择器。
4. 交付一个完整可用的场景／人物／镜头稿，正文外简述“主方向、取用维度、排除维度、证据限度”。未提供媒体不阻止保守草稿；历史服制具体到年代、身份和场合时再核史料，不把古装剧当考古证明。
5. 场景承接物理光源与拓扑，人物承接身份和造型，风格承接表现响应，镜头导演承接构图与摄影机。不因参考切换自动改正式设定或生成媒体；取用片名也不取得人物肖像、剧照、服装图案或成片使用权。

示例：“宋代茶肆两位朋友归还账簿，轻松自然，不改已定衣服。”采用 `live-song-everyday`，提出木桌使用痕迹、窗侧散射日光、账簿交接的双人关系；衣服与身份保持锁定。不加宫廷排位、现代手机、神光、剧中角色脸，也不宣称复现《梦华录》某镜。
