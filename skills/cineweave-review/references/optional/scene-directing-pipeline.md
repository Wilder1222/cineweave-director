# 场次级导演生产关卡：从戏剧行动到可剪辑场面

此指南面向完整场次、连续分镜、短片／短剧及需要跨镜继承的 AIGC 影视任务；单图、白底资产、局部改写和精确平台投射无需走完此流程。属于 `cineweave-director` 的**非执行型导演方法**，不是新增 Skill、route、根契约、审批平台或自动生成循环。入口与各领域的所有权仍以 [统一入口](../../SKILL.md)、[权威维度](../core/visual-bible-and-continuity.md#权威维度) 为准。

## 原则：从一场戏的结果倒推镜头

先问：场次结束时，人物的选择、关系、观众所知或感知状态发生了什么；再倒推行动、空间、表演、摄影与切点。日常生活片可以由陪伴、观察、细节发现及时间体验构成场次，**不得为满足模板强加对抗或反转**。镜头不只是可独立欣赏的动图；整场戏必须可被连续观看和理解。

导演通案是紧凑的**决策与验收基线**，不是第二份世界设定：明确场次任务、观众视点、信息先后、表演尺度、允许与不允许的摄影语法、声音节奏、连续性锚点。摄像机技法必须逐镜选择，固定机位与不切焦都可合法通过。参考《玄奘》两段实践的[证据与迁移案例](xuanzang-director-case-study.md)。

## 八个关卡及责任人

按依赖推进；草稿可以带待验证项交付，**正式场次／镜头组交接**必须明确每关的完成、未决与证据层次。前关不成立，不靠后期蒙混；已有合格资产／镜头直接复用，不每次从头搭建。

| 关卡 | 导演必须决定的事 | 唯一归属／最小交接 | 不通过时 |
| --- | --- | --- | --- |
| G0 戏剧／观察任务 | 目标、阻碍或观察对象、人物策略、潜台词、观众获知顺序与视点；准确对白 | `story` 的节拍／场次＋导演通案的镜头语法 | 缺必要因果／体验则返回故事 |
| G1 视觉基线／角色 | 媒介、色材、历史／幻想规则、角色身份与当前造型、关键道具功能 | `style`、`character`、`scene` 分别保存；参考证据与权利由参考领域 | 不能用「电影感」「8K」替代可见规则 |
| G2 场景地理／世界光位 | 平面关系、门窗与通道、道具及接触位置、朝向／尺度、真实光源位置、可达机位；反打同一空间 | `SceneSpec/State/LightState/Binding`；世界方位与屏幕方位分离 | 空间／接触不可达则先修地理或走位 |
| G3 场面调度／表演 | 谁先动、刺激来自哪里、对谁行动、演员走位／眼线／支撑／持物、观众注意力顺序 | `shot_direction` 消费动作／人物轨；必要时 `action` 定接触机制 | 触发未被人物接收、道具无故转移则不选镜 |
| G4 镜头覆盖／摄影语言 | 每个节拍是否得到必要主镜、共享双人、反应、线索细节的**最小**覆盖；景别／轴线／路径／焦点／触发／出点及理由 | `ShotSpec.cameraLanguageDecision` 与 `Storyboard`；运镜时间归 `TemporalSpec` | 补齐不可替代信息，删掉无任务的漂亮镜头 |
| G5 剪辑与声音预检 | 相邻镜头继续、重看或省略？动作相位、视线、世界方向、服道光、声源、环境底噪、画外声和声音桥 | `storyboard_rhythm`＋`EditorialTimelinePlan` 的计划区间 | 说明信息/运动/时间跳跃；无意错接返回所属领域 |
| G6 小样生成与试剪规划 | 按高风险依赖选测试镜头与覆盖组；计划采用区间、剪辑余量、回流候选与试剪单位 | `production_plan`；不声称实际生成、声音或剪辑已完成 | 单镜好看但不能切成一场戏则回 G3–G5 |
| G7 逐镜／逐场评审与修复 | 依据真实媒体检查身份、表演、运动、连续性与声音；诊断根因，保留合格区间 | `cineweave-review` 的 `CreativeReview/RepairPlan`；源路由负责修订 | 一次只改一个责任根因；新证据后复验 |

**严禁跨权威偷改：**摄影不能在反打时移动房间里的窗；提示词不能替人物决定新性格；平台不能把已批准的推轨悄悄换成变焦；评审不能把计划写成已生成媒体。源稿变化后只传播给相关消费者并标记先前验收失效。

## 场次导演通案：可直接填写的最小工作单

以下是**普通中文工作表**，不是新 JSON schema。复杂项目可把既有根产物以精确 ID／版本关联；没有精确来源时使用临时名称，不编造哈希。

1. **场次及基线：**场次 ID、作品时长／画幅／媒介、用户硬锁、故事节拍来源、风格与角色版本、导演视点和表演尺度。
2. **地理与道具：**北向或明确的局部方向、门窗／灯／桌／关键道具、通路、人与摄影机的可达区域、轴线及光源坐标；俯视图仅是规划约束，不冒充可验证三维几何。
3. **节拍／覆盖台账：**每节拍的前态→刺激→角色目标／策略→行动→后态；观众先后获知什么；承载它的镜号；必要的反应／道具覆盖或有理由的共享单镜。
4. **逐镜导演卡：**镜号、时长与镜头职责、世界内人物起止状态、景别／机位／轴线／构图、一个主导技法或静止、运动与焦点触发、表演行为、光源及声音、可以采用的出入点、相邻切镜关系。
5. **声画衔接：**同空间环境底声持续的范围、动作拟音来源、对白所在镜头或画外声；使用 J-cut / L-cut 时写明前后镜画面切点与声源的时间关系；**单镜内由画外声触发摇移／揭示不自动叫 J-cut**。
6. **小样与修复：**优先检查最可能失败的复杂接触、反打、声音触发、焦点变化；有媒体时保存候选和有效区间。试剪可以先凑一组足以检验场面的镜头，视频示例的「五六镜」不是强制数量。

## 两种重要表演表达层

**行动逻辑：**当前目标（Objective）→阻碍（Obstacle）→策略（Tactic）→潜台词（Subtext）→真实接收的刺激；把抽象情绪变成镜头景别可读的选择。倾听和等待也是行动。尽量不逐毫秒指定所有眼睑／口角／手指动作。

**关键节点硬锁：**只锁住准确台词／声音提示、必须出现的信息时刻、持物手、动作接触、起点／出点、重要视线目标及必要的终态。视频案例所称「70% 行动逻辑＋30% 节点硬锁」是经验比喻，**不是可计量、强制执行或最优的权重**。高风险接触仍须明确机制与相位。

## 从镜头完成到场次完成：双层验收

- **镜内计划：**导演意图、信息变化、地理、摄影分类、表演／焦点时间、关键硬锁、可用出点；已存在的[逐镜摄影选择检查器](../../scripts/check-shot-review.mjs)只验证所填计划的结构覆盖。
- **镜间计划：**节拍覆盖、相邻轴线与视线、动作／持物／伤情、世界光位、声音桥、剪辑类型与采用窗口；不把两个漂亮单镜等同于可剪辑场面。
- **实际媒体：**必须看真实视频、声音与试剪，逐时间段写发现；不因计划校验通过而声称观众可懂、接触成功或焦点无误。
- **完成状态：**分别记录「文字方案完整」「媒体候选可看」「试剪可用」「完整场次通过」。前者不能自动提升为后者。

## 表演与画面反例

- **漂亮反打但换了地理：**保留同一场景的门窗、鸟笼、桌案和光源；屏幕左右随机位可变，世界锚点不能变。
- **先转头后听见命令：**检查声音进入时间、人物可听性和剪辑采用区间，再决定修表演还是修切点。
- **切焦生成出不存在的线索：**先确认远景物件原已存在，后选择显露时间；焦点变化不是创造资产的许可。
- **每镜都推、绕、摇：**镜头运动必须由信息、人物反应、道具或空间变化触发；固定镜头同样应写明观看收益。
- **修接触同时重调肤色、构图与音乐：**改动变量过多导致无法确认原因；优先诊断归属，再做一个有验收条件的候选。
- **日常片硬造冲突：**人物共享早餐、并肩散步、无台词等待亦可成立；用小行为、空间关系、听觉和时间流动驱动镜头。
