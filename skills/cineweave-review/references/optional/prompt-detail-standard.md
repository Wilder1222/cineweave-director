# 可选参考：提示词细节与专业表达

本规范用于人物、场景、图像、分镜和图生视频提示词。按任务读取对应章节。默认交付细节充分的中文成稿，不设置压缩字数目标；精简针对重复、空泛和冲突，不能删去有独立视觉作用的细节。摄影、美术、服装和表演采用各自通行的专业术语；这些领域不存在一套统一的提示词行业标准，本规范是创作交付约定。

## 表达原则

按需阅读：[人物](#人物)、[人物情绪与表情生成](#人物情绪与表情生成)、[场景](#场景)、[镜头与分镜](#镜头与分镜)、[拍摄系统与部门协同](#拍摄系统与部门协同)、[图生视频](#图生视频)、[连贯示例](#连贯示例)。完整短片方案同时检查拍摄系统；静态图仅展开对画面有影响的部分。

采用“专业术语＋具体可见结果”：例如“低位侧逆光从画面右后方掠过发丝，在右肩外缘形成窄亮边”，不能只写“电影级轮廓光”。每项明确对象、位置、形态、材料或运动结果，按需要补充方向、强度、尺度和时间。焦距、色温和时长是原创设计值时应如此标明，不能冒充从参考图测得的事实。

原创设计可补全合理且可撤销的细节，并在正文外简述假设。参考复现只描述可见证据，遮挡和无法判断处留待核实；用户指定内容逐项保留。完整资产母稿保留全身设定，特写复制稿详细展开实际入画部分；用户要求同时表现的细节超出取景范围时，说明冲突并安排补充视图，不擅自改变景别。无妆、无发饰等明确设计也应写明，不为凑字段添加装饰。

## 人物

先固定身份和形态，再写这一镜的状态。以下维度逐项检查，相关且可见的内容必须展开；不把所有人物写成同一种精致面容。

| 维度 | 必须明确的可见内容 |
| --- | --- |
| 身份与体态 | 原创年龄段、体型、头肩比例、面部轮廓、稳定辨识点；承重脚、重心、骨盆与肩线关系、脊柱姿态、颈部和下颌位置 |
| 五官与肌肤 | 眼型、眉形、鼻部与唇形的辨识结构；肤色及冷暖底调、毛孔与细纹的部位、干湿与油光分布、透光和瑕疵；保留自然纹理，不用全脸同强度锐化 |
| 妆容 | 底妆覆盖度与光泽、眉妆形状、眼线走向、眼影色区、睫毛、腮红位置与边界、唇色和唇面质感；素颜明确无装饰性彩妆 |
| 发型与发饰 | 分缝、发际线、束发位置、发束体积、碎发范围；发饰种类、材质、形制、数量、佩戴侧、固定位置和方向，坠饰长度及摆动条件 |
| 服饰 | 内外层次、领型、襟向与闭合方式、肩袖结构、袖口、腰部收束、下摆、鞋履；面料织纹、厚薄、挺括或垂坠、光泽；纹样尺度与分布、滚边、刺绣和磨损位置 |
| 仪态与动作 | 躯干朝向、肩颈松紧、手臂与关节角度、手指握持和实际接触点；动作的施力部位、承重与制动；人物自身左右和画面左右分别标明 |
| 情绪与表情 | 内在情绪及掩饰程度；落实到眉头、上下眼睑、鼻翼、嘴角、唇缝和下颌的可见变化，避免把“恐惧”机械等同于瞪眼张嘴 |
| 眼神与注意力 | 看向的具体目标、视线方向、眼球与头部是否同步、注视或扫视；眨眼、视线转移只在相关节拍安排，不默认每镜都做 |

历史服饰名称和形制需有对应时代与实物依据；没有依据的原创混合设计按结构描述，不能标成考据复原。发饰承担装饰，不自动成为身份参考；参考人物的脸、妆、服装分开绑定。

### 人物情绪与表情生成

人物作为叙事或资产主体时，明确写出情绪与表情，不以“美丽、精致、有神”代替。先按下列六层设计，再将适用内容写进每条独立复制稿；可以用自然段或明确标注的模块，不强制六个标签。中性身份图也有明确的中性表情，无需虚构剧情；不可见面部的背影、剪影或远处点景用姿态和互动承载，不强写可见眼睑、唇纹。

| 层次 | 需要作出的决定 | 可用的具体表达 |
| --- | --- | --- |
| 情绪核心 | 当下感受、对谁或对何事、是否掩饰 | 获得帮助后放心但仍拘谨；不是同时罗列几种互斥情绪 |
| 表达强度 | 外显程度及清楚的表演边界 | 闭唇浅笑、露少量上齿的笑容或开怀笑，按本帧选择一种；不编造情绪百分比 |
| 眼神与注意力 | 一个明确注视目标、方向和交流关系 | 看画面右侧同伴的近侧眼睛；第一视角互动才可将目标定为镜头所代表的来客 |
| 面部表现 | 与情绪对应的眉、眼睑、面颊、唇与下颌状态 | 眉头舒展、下眼睑轻抬、面颊略提、唇角小幅上扬；只选能共同成立的动作 |
| 身体反应与仪态 | 头肩、躯干、手势、重心如何支持或掩饰感受 | 肩膀放松、头部稍偏向听者、持杯手腕放松，杯口水平且不遮住嘴唇 |
| 触发语境 | 情绪由什么事件引发，画面如何让观众读懂 | 对方留下照明后，人物停止攥紧衣角；动机指导表演，不把内心旁白当作可见事实 |

情绪不是固定的面部公式。难过可以压住笑、喜悦可以含泪，前提是交代主情绪、掩饰策略和可见证据。不得把一种脸型、肤色、性别、年龄或服饰绑定为某种情绪；眉形和眼型的身份结构不因表情变化而被重写。需要专业表达时使用视线匹配、反应镜头、表演节拍等术语并说明可见结果，不把动作单元编号当作通用生成参数或情绪测量。

**按交付类型编译：**

- 静态人物资产：固定一个情绪强度、一个视线目标和一个动作瞬间；表情探索各给独立稿，保持身份、妆造、景别与光照不变。中性母版可写“双唇自然轻合、眉间放松、视线平稳”，不默认为节日浅笑。
- 首帧／尾帧：分别写当前状态。首帧不能提前完成尾帧的笑容、回头或松手；变化原因、过程和时间放在视频稿。表情设计不能擅自重置已提供的实际首帧。
- 视频：写“初始状态—刺激—视线与面部响应—身体动作—结束或延续状态”，允许有动机的不同步；具体时间与对白口型按[表演轨道](video-performance-direction.md#情绪不等于面部几何)协调。
- 群像：主角、对话者与听者各有明确注意力目标和反应，不让所有人同步笑或一起看镜头。仅靠画外人物引发的情绪，需在镜头关系或声音中提供线索。

**编译前消除矛盾：**“双唇完全闭合且上齿可见”要按用户指定状态改为闭唇不露齿或微张露齿；“看同伴或镜头”要选定对象；“先看江面再回眸”只能作为视频过程或拆成两张静帧。对白时不能维持全程紧闭唇缝、固定露齿笑或僵住下颌；笑意可由眼睑、面颊和句间表情延续。眼神光反映光源位置，不能代替注视目标，也不随情绪自动变成发光瞳孔。参考被遮挡或只展示半身时，背面发饰和下装属于待设计内容，不宣称观察所得。

**静态人物复制稿示例（原创设定）：**

```text
横向16:9，中秋夜宴的坐席视点，胸口以上近景。一位约三十岁的成年女子坐在桌对面，长椭圆脸、平直眉、深棕细长杏眼和自然鼻唇结构。暖中性浅棕肌肤在鼻翼与内侧面颊保留细毛孔，颧部微润；薄透底妆、灰棕眉妆、细棕内眼线、淡豆沙腮红和低饱和玫瑰棕唇色。黑发中分低髻，一枚哑光银色叶形簪固定于人物左侧，叶尖斜向后上方，无垂坠珠链。米白交领内衣外罩灰蓝薄绸长袖，领缘窄银灰滚边，袖口有小幅织花，衣层与褶皱各自可辨。
情绪是听到对面友人祝福后的亲近与愉悦，外显程度为克制的闭唇浅笑。眉头舒展、下眼睑轻抬、面颊略提，双唇自然合拢、不露齿；视线专注落在镜头所代表的坐席友人眼睛上。头部轻偏向友人，肩颈放松，上身仅略前倾；右手将浅青瓷杯持于胸前，杯口水平且低于下巴，拇指与食指稳住杯壁、中指托住杯身，左手落于桌沿，正在听而没有开口。
桌后深栗木柱与侧边纱帘构成宴厅纵深，背景两位宾客分别面向彼此交谈，面孔自然虚化。全画幅等效50毫米设计视角，焦点落在女主近侧眼睛，持杯手与杯沿仍可读。画面左前方纱灯形成柔和暖面光，江侧开口提供微冷环境光；皮肤为柔润漫反射，瓷釉为短圆高光，银簪为窄亮边，灰蓝衣料保留固有色。
```

这是一张正在聆听的静帧，不在同一段中追加说话、伸杯和碰杯。若用户只要求将笑容改得更明亮，替换表情为“上下唇轻分，少量上齿可见，唇角舒展、面颊上提、下眼睑略收紧”，保留相貌、发饰、服饰、杯位、空间与摄影；给出替换后的完整人物稿，不只交付一个情绪词块。其他情绪按剧情设计，不沿用本例的中秋喜悦。

## 场景

| 维度 | 必须明确的可见内容 |
| --- | --- |
| 类型与用途 | 室内／室外、建筑或自然类型、空间功能、尺度、时间、天气、使用状态与生活痕迹 |
| 结构与层次 | 平面走向、开间与进深、柱网或墙体、门窗、顶棚与地面；前中后景、通行路径、出入口、遮挡和主体站位；自然场景写地形、水系、植被层次 |
| 形制与样式 | 体块比例、轮廓、构造方式、装饰语汇、纹样位置与密度；风格名称之后必须落到实际结构，避免仅列时代或地域标签 |
| 材质与状态 | 承重结构和表面饰面分别写；木纹、石缝、金属氧化、涂层剥落、积尘、水迹的位置及尺度；干湿表面对高光和反射的影响 |
| 色调与光线 | 主色、辅色、强调色各自的物体与面积关系；饱和度、明暗对比、黑位、冷暖分布；主光与补光的来源、方向、软硬、遮挡和反射，不把调色等同于光源色温 |
| 陈设与交互 | 道具的数量、位置、尺度、朝向和用途；人物可触及的高度、落脚面、接触阴影和通行动线 |
| 表现力与构图 | 用透视引导线、框景、负空间、明暗分区、视觉重心、尺度对比和遮挡表达压迫、秩序或疏离；明确观看位置及观众先看什么 |
| 动态与氛围 | 风、雨、雾、烟、水面、尘粒的来源、运动方向和浓度；只保留不会遮蔽叙事对象的必要变化 |

## 镜头与分镜

新写的影视镜头提示词必须传递[摄影语言选择](../routes/shot-direction.md#镜头语言选择关卡)的可见机位、景别、构图、固定／运动态、焦点、事件触发、采用出点与连续性。无运动也应说明固定状态。白底人物服装等独立资产、精确翻译与平台忠实投射不能无授权补充运动。
## 镜头与分镜

每镜交付镜号、叙事目的、设计时长、首帧构图、人物状态、动作过程、摄影机与焦点、光色、声音、终态和衔接。静帧正文只写一个瞬间，动作过程放在视频正文；多镜头不能以“同上”代替独立复制稿所需的视觉信息。

摄影说明至少明确：画幅；景别及实际裁切边界；机位高度和俯仰角；主体与相机朝向；镜头焦距的设计依据或视角特征；前中后景、头顶空间与视线空间；焦点对象和景深效果；固定或运动方式、方向、幅度、速度与停止点。焦距数值需注明画幅基准；没有必要时用明确视角与透视关系，避免堆砌相机型号。

| 术语 | 使用边界 |
| --- | --- |
| 特写／近景／中景／全景／远景 | 缩写与裁切习惯存在差异，同时写明脸部、胸口以上、腰部以上、全身或环境占比 |
| 推轨／拉轨 | 摄影机实际前后位移，透视和前后景关系随之变化；明确距离或构图终点 |
| 变焦 | 改变焦距和取景范围；不能自动等同摄影机向前移动 |
| 摇摄／俯仰摇摄 | 机位位置基本不变，改变水平／垂直朝向；横移则是机位平移 |
| 跟拍／环绕 | 明确相对人物的路径、速度与角度范围；环绕可能越轴，需交代方向关系 |
| 焦点转移 | 焦平面从一个明确对象转到另一个对象；与变焦、推轨分别描述 |
| 主光／补光／轮廓光／背景光 | 按画面作用命名，写明物理或设计光源；不强制每镜配置所有灯位 |
| 动作匹配／视线匹配／轴线 | 写清上一镜出点和下一镜入点的动作相位、目标与画面方向；跨轴需有明确空间交代 |

表演描述区分“人物想达成什么”和“身体如何执行”。每镜保证动作可完成、手指与道具接触连续、视线目标有空间位置；不要用高密度术语掩盖缺失的因果和物理关系。

## 拍摄系统与部门协同

把一个场次视为同一空间、同一时间和同一声场中的连续事件。人物、镜头、灯光、声音、美术和剪辑共用场次基线，逐镜记录变化。以下覆盖常规剧情拍摄主要决策，特殊题材按实际需要补充；不能宣称单份清单穷尽所有制作工种。

### 空间关系与调度

先建立可复用的空间说明，复杂交互附俯视示意图或位置表：以场景固定点为原点，注明方向、单位、地面与高度基准；标人物起止位、摄影机位置与朝向、门窗、障碍、关键道具、主光来源和声源。设计尺寸是暂定值，实景须勘景确认。场景方位固定，画面左右会随机位变化，人物左右始终按身体定义。

逐镜写清人物相对距离、前后层次、朝向与视线目标，动作路径、谁先谁后、相遇和接触位置、道具归属、遮挡及重新显露时刻。摄影机路径与演员路径分别检查通行空间，不允许穿墙、穿柱或穿过实体。多人物建立动作轴线或对话轴线，记录机位位于哪一侧；轴线改变、越轴或故意反转方向必须通过可见运动、重建镜头或明确叙事意图交代。180 度轴线原则与 180 度快门角是两个概念。

手递手、跨桌取物等关键接触按[共享空间检查](../routes/scene.md#共享空间检查)复核座位、接触点与已声明尺寸；验证可达后再编写手部近景，并将空间修订同步到场景图、镜头卡和独立复制稿。

### 构图与摄影实现

在前述镜头字段之外，检查视觉重心、视线空间、运动余地、人物头顶留白、边缘切割、人物与背景的轮廓分离、反射面与画外空间。三分法、对称、中心构图、框景和负空间按叙事选择，不设强制构图套路。前景遮挡不能无意遮住关键握持和情绪变化；字幕或多画幅裁切确有需求时才预留区域。

摄影计划说明焦距与传感器画幅基准、物距、景深意图、焦点起止对象、跟焦时点、机位高度及支撑方式。实拍需再确定帧率、快门角或曝光时间、光圈、感光设置、白平衡、滤镜、记录格式及监看变换；检查运动模糊、灯具／屏幕频闪、动态范围、肤色和高光细节。设置需要曝光和运动测试，不能把一组数值当作通用电影参数。AIGC 仅在确有视觉影响时转成清晰的画面效果要求，不把设备名当作质量保证。

### 灯光与曝光连续性

场次光位表记录自然光、画内实景光源与画外补充光的职责、方位、高度、照射对象、软硬、覆盖范围、冷暖关系及调控方式。亮暗对比需要注明比较对象；若给光比，说明是入射照度还是画面亮度关系，不写孤立的“电影光比”。补光抬起阴影，负补光通过吸收环境反射加深暗部；柔光、反射、遮扉与黑旗分别说明改变了什么。

逐镜核对人物移动后的受光、眼神光、脸部阴影、皮肤与衣料高光、地面接触阴影、窗面与镜面的倒影；反打保留世界中的光源位置，不能机械维持每张画面都从同一侧打光。实景灯和照明灯分开记录，灯体亮度不等于照亮全场的能力。雨湿、烟雾和镜头滤镜会改变光束、反差及反射，应与场次状态一致。检查摄影机、灯架、吊杆及工作人员是否入画、投影或出现在反射中。

### 收音与声音空间

先确定叙事聆听位置和声源，再决定拾音／制作方案；画面景别变化不必机械改变对白音量，但主观听觉、远近与混响变化应有意图。对白、呼吸、衣料、脚步、道具、环境底声、画外声和音乐分别列轨，区分现场同期、单独补录、拟音、后期配音与合成。无对白不等于无声；明确静默是创作决定还是尚未设计。

实拍收音方案写明吊杆、领夹或固定隐藏话筒的使用理由、相对声源的位置与指向、人物走位中的跟随方式，以及防风、减震和衣物摩擦控制。吊杆要同时避开画框、灯影和镜面；多人轮流说话时安排指向转换，无法兼顾的覆盖需另行处理。指向性话筒不能把远处声音自动“拉近”，硬质反射面和环境噪声会影响清晰度，先听现场再决定拾音方案。

收音工作表进一步检查：场地混响与交通、空调、机械噪声；无线链路稳定性；对白分轨及轨道命名；输入增益与峰值余量；耳机监听；画面与录音的同步方法、时码时基或场记板；环境底声和必要补录。录音采样率、位深、通道布局依交接要求确定，录音电平与最终节目响度分开管理，不编造已测分贝、峰值或混响时间。降噪和后期配音有代价，不能预设能修复所有现场问题。

AIGC 声音稿描述听得到的结果：声源、距离、方向、材质音色、起止时刻、动态、混响与遮挡；录音设备及通道管理放在制作说明中，不能误生成为画面中的器材。未核实模型音频能力时分开交付视频与声音稿；台词精确文本、口型同步和最终声音仍需逐项验收。声音时间表、字幕与交付规则由[视频、声音与交付](video-sound-and-delivery.md#声音职责与提示表)维护。

### 场记、覆盖与制作条件

场记记录每镜采用起止状态、动作相位、道具持有者与位置、服装妆发、汗水／湿度／污损、人物眼线、运动方向、光线天气、背景群演和环境声状态。剪辑覆盖按信息需要选择主镜头、关系镜头、反应镜头、视线对象、动作细节、空镜或过渡，不为凑数量拍齐所有类型。对白留表演反应和可用停顿；声音先入或后出时明确跨镜声源与时间边界。

实拍或混合制作计划按场次检查勘景与声学条件、日照窗口、演员与群众调度、服化道复位、器材动线、用电和雨天条件、排练与拍摄顺序、人员职责、工时预算和备选方案。涉及特技、车辆、水下或特殊效果时明确需要对应专业方案，不把文字调度当作现场执行证明。纯 AIGC 将这些映射为资产依赖、生成顺序、参考锁定、返工成本及镜头拆分。

需要视效合成时预先安排干净背景、遮挡边界、跟踪参考、接触阴影和反射关系；实拍素材交接才进一步记录镜头与摄影机数据、色彩参考和现场参考。素材管理记录镜号／条次、源文件、声音关联、采用区间、版本、备份与校验状态；色彩管理与最终输出规格沿用[视频交付规划](video-sound-and-delivery.md)，不要另建一套互相冲突的参数。

## 图生视频

图像承担首帧的外观、构图和光色，视频正文详细写变化及关键保持项。先确认输入图片与设计一致；未提供图片时只称待绑定方案。不能把原图没有的衣饰、机位或人物当作已存在事实。

1. **初态与保持项：** 绑定哪张首帧，谁在何处、握什么、接触哪里；固定身份、服装发饰、场景结构与光源方向。
2. **动作分段：** 准备、发力、位移、接触、制动、稳定；交代执行者、动作对象、路径、速度、幅度、起止姿态与道具归属。不要求每个动作都具备六阶段，但不能跳过关键接触。
3. **表演变化：** 在对应动作节拍写注视目标、头眼配合、表情起落、呼吸或唇部动作；台词原文与表演说明分开。
4. **摄影与环境：** 相机运动和主体运动分别描述，明确开始、结束和焦点对象；布料、发丝与道具惯性响应有原因，风向保持一致。
5. **终态与剪辑：** 定义采用出点前达成的姿态、道具位置、视线和相机构图；说明前后余量。时间码是调度意图，不是模型保证，应以实际候选复查。

完整母稿保留全部相关细节。平台复制稿按已核验能力组织；若长度或运动复杂度超限，拆分镜头或保留完整母稿并列出适配取舍，不能无声删掉用户要求的细节。不要同时要求固定机位与环绕、持续推近与锁定透视、猛烈跑动与衣摆完全静止。

## 连贯示例

以下是原创虚构设计，未绑定真实参考或平台。人物自身左右按人物身体定义；画面左右按观众视角定义。没有台词和交接给第二人的动作。

### 人物资产母稿

一名约二十八岁的成年女性，身形修长、肩宽适中，长椭圆脸，下颌线柔和；平直眉尾略收，细长杏眼，鼻梁平直，薄上唇与略丰满的下唇。肌肤为暖中性浅棕色，鼻翼与内侧面颊保留细小毛孔，眼下保留轻微细纹，颧骨有柔和反光，额头无大片油亮。薄透半哑光底妆，灰棕眉妆顺着毛流，棕色细眼线止于外眼角，低饱和豆沙色腮红沿颧骨浅铺，哑光玫瑰棕唇色，唇缘自然。黑发中分，后枕部低髻，耳前各一缕短碎发；一支无坠饰的哑光银簪从人物右侧横向插入发髻，簪首为窄叶形，紧贴髻外缘。

内穿米白色立领薄棉衫，外穿灰蓝色斜襟长外衣，以人物右腰侧暗扣闭合；窄肩、直袖、收口袖口，外层亚麻混纺有细密经纬纹理，低光泽、适度挺括，肘内侧形成方向明确的受力褶皱。深灰布带平整束腰，衣摆至脚踝上方，无刺绣和拖地裙摆；深褐色平底布鞋，鞋头微圆。站立重心落在人物左脚，右脚向后错开半足，膝部自然伸展不锁死，肩线平稳、下颌微收。谨慎但愿意靠近对方的情绪通过眉头轻收、下眼睑略绷紧、嘴唇轻合表达；视线落在画面右侧廊柱旁的空位，未看镜头。人物右手提一盏小型木框纸灯，手指环握提柄，拇指压住柄侧；灯体离大腿外侧约一掌，左手自然垂落。

### 场景资产母稿

傍晚雨后的室外有顶木构长廊，原创传统木构语汇，不指认具体朝代。连续方木柱形成三个可见开间，纵向梁架承接双坡屋顶；左侧为深色木板墙，右侧敞开面向低矮庭院，长廊向画面左后方收束。灰色石板地面有细窄拼缝，敞开侧地面残留不连续薄水膜，靠墙处干燥；柱脚色泽较深，木纹纵向清晰，漆层在棱角局部磨损。背景无杂乱悬挂物，通行净空完整。

灰蓝天光是主导环境光，从画面右侧敞口柔和进入；手提纸灯提供局部低强度暖色光，照亮右手指腹和袖口下缘，不照亮整条长廊。主色为低饱和灰蓝与深褐，米白灯面形成小面积暖亮视觉中心。柱列构成重复框景，前景暗柱遮挡画面左缘一小部分，人物位于中景右侧三分线，后景廊道保留可辨结构；以纵深和右侧负空间表达等待感，不加遮脸浓雾。

### 单镜首帧复制稿

横向 16:9，中全景，人物从头顶至小腿中段入画，摄影机处于人物胸口高度、水平拍摄，采用全画幅等效约 50 毫米的自然透视作为设计值。成年女性站在雨后木构长廊右侧三分线，身体朝向画面右侧约四分之一转，左脚承重、右脚后错半足，肩平、下颌微收；右手在大腿外侧环握木框纸灯提柄，左臂垂落。长椭圆脸、平直眉和细长杏眼，眉头轻收、下眼睑微绷、双唇轻合，目光落在画面右侧廊柱旁空位。暖中性浅棕肌肤保留自然毛孔，薄透半哑光底妆，细棕眼线和哑光玫瑰棕唇色；不以放大毛孔改变景别。黑发中分低髻，哑光银叶形簪从人物右侧固定入髻，无坠饰。米白立领内衫外穿灰蓝斜襟亚麻混纺长衣，右腰暗扣、窄袖收口、深灰布带束腰，袖肘有自然受力褶皱。

左侧深木板墙、右侧敞开庭院，三组方柱与纵梁向左后方形成透视纵深；石板拼缝清楚，敞开侧少量积水映出模糊光斑。右侧柔和灰蓝天光塑造脸部与衣料，纸灯仅在手指和袖口下缘形成局部暖光。焦点落在人物近侧眼部，中等景深使握柄的右手与柱列仍可辨；左缘暗柱作框景，人物右侧留出动作空间。保留自然织纹、接触阴影和面部比例；避免塑料皮肤、银簪增殖、手柄穿指和无来源的强轮廓光。

### S01 空间、灯光与声音补充卡

沿用上述原创纸灯镜头，不新增对白或迈步动作。以人物起点为局部原点，长廊纵深轴与敞开庭院方向固定；人物面向庭院侧前方，摄影机位于其左前方，看见右手提灯与右侧动作空间。廊柱旁视线目标在画外但空间位置固定，灯前送路径避开柱体。具体现场距离待勘景，不能从这段示例推断实测尺寸。

构图复查头顶至小腿中段裁切，提灯的起点、腰前终点和银簪均入画，鞋履留在人物资产设定中；前景柱不挡右手。固定机位和人物原地抬臂不改变轴线。柔和天光持续来自庭院侧，纸灯移动只改变附近手指及袖口的局部暖反光；不增加照亮全脸的突兀暖光。湿石板保留低强度反射，检查其中没有摄影机或吊杆倒影。

声音采用段与画面同为 0 至 6 秒：底层为连续低声级庭院环境与廊下短促水滴，无持续落雨声；1 至 3.5 秒随抬臂出现轻微干燥织物摩擦，3.5 至 4.5 秒灯柄与木框连接处有细小摩擦，随后衰减。声音保持近处动作可辨、背景退后，不加脚步、金属坠饰碰撞、对白或无依据的灯火轰鸣。拟音与画面实际接触同步，环境底声可跨出点延续，避免切镜处突然静音；不把此处“低声级”冒充实测响度。

若转为实拍，画外拾音需检查最宽取景及石板反射；无对白镜头可单独补录衣料和灯柄细节，并在同一环境状态采集底声。录音与画面镜号及采用区间关联，补录声音按实际动作对齐。若采用无音频输出的视频模型，另交付这份声音稿进行制作；当前没有任何已录制声音。

## 交付前检查

- 对照用户要求逐项核对人物、场景、摄影和时间维度；遗漏项补写，不可见项说明保留位置，未证实项不伪装成事实。
- 专业名词都有具体对象和可见结果；姿态、视线、光源、材质、空间方向和运镜没有互相抵消。
- 人物主体的情绪、强度、眼神、面部表现、身体反应与语境已按可见性落实；无情境中性资产明确中性。每帧唇缝／露齿状态和视线目标唯一，视频变化与对白相容，群像反应有对象和先后。用户只改表情时，所有受影响的复制稿同步更新，未涉及的身份与妆造保持。
- 视频的关键节拍按[逐节拍完整性](video-performance-direction.md#逐节拍完整性)核对：变化有触发和残留状态，运镜有发生时点，声音随声源／接触同步；逐项区分缺失、明确保持、不可见与待核实，不能只因出现“情绪／声音／运镜”标签就判为完整。
- 静帧、分镜和视频沿用同一设定；各复制稿完整，负向词针对具体风险，不用负向词弥补正文缺失。
- 区分文字完整性、结构检查和实际媒体效果。生成后另查身份、手部接触、表演轨迹、材质、光色、时序和剪辑余量，未生成时不得声称通过。
- 联合检查人物／摄影机路径、构图／吊杆边界、光位／投影反射、对白／环境噪声、正反打／轴线、剪辑／声场。部门要求冲突时说明取舍并同步相关镜头，不各写一份互不相容的方案。
