# 可选参考：对白、情绪、表情、特效与摄影机轨道

详细创作稿遵循[细节与专业表达](prompt-detail-standard.md#图生视频)；此处专项规则与机制示例不能替代完整人物、场景和镜头描述。

涉及表演、台词、多模态表演参考、视觉特效或协调运镜时加载。这些是独立编写的导演规则；有条件的平台能力声明见[平台证据](video-platform-adaptation.md)。文字描述不等于经过校准的滑杆。

本页新增来源访问日期为 **2026-10-10**。演员教学、采集系统、生成模型与引擎动画分别提供不同层面的依据；下文的导演工作法是项目应用，不是任何一套课程的完整复刻，也不是实际生成结果。

## 编写顺序

先明确节拍和观众信息变化、人物目标、物理调度、时间和锁定来源，再将表演、摄影机／焦点、光／环境、特效、对白与声音分配到不同轨道。轨道可以并行变化；不要求每段静止或只剩一个身体动作。复杂性需要可读协调及受支持模式，而不是一律禁止。

一个主要摄影机意图是有用默认，不禁止有动机的复合运动。将可选装饰标清。简化若破坏已批准的远景全身、第一视角互动、人物关系、动作结果或地理，应说明取舍，而非悄悄改成特写。

## 逐节拍完整性

视频复制稿先交代共用的身份／外观、空间／光源、视点与声音基线，再沿关键节拍写变化。普通稿可以用自然段或时间段，不强制节点标签、逐句表格或新增契约。下列维度按本景可见／可听范围落实在实际复制稿；不适用的变化可明确保持稳定，无对白、无音乐和固定机位均是有效选择。

| 维度 | 关键节拍需要明确的内容 |
| --- | --- |
| 情绪与任务 | 初始感受、面向谁的任务、听到／看到的具体触发、掩饰或策略改变，以及留到下一节拍的状态；避免只列“开心、惊讶、感动”。 |
| 微表情与呼吸 | 选择当前景别可读的一两项变化，写起落和恢复；掩饰、忍笑或迟疑需要有程度变化。呼吸仅在支撑本次反应时展开，不把所有面部通道同时做满。 |
| 眼神 | 固定交流对象的空间位置，写视线转移的触发、目标与回视；需要时区分眼睛先动和头部随后转动。POV 注视镜头代表谁，近距离接触时看的是可见手腕还是贴脸指尖，都要明确。 |
| 台词与语气 | 保留准确说话人及原文，将必要的语速、力度、重音、句间迟疑或笑意写在说明中；说话允许自然口型，倾听者的反应由已收到的信息触发。 |
| 动作与微动作 | 初始姿态与支撑、执行者及左右手、来路、接触／松开、反应和结束位置；手部、头肩、衣料或发丝的小变化有原因，避免反复使用同一种动作替代不同反应。 |
| 运镜与焦点 | 机位高度／朝向、起始裁切、移动触发、发生节拍、方向／幅度／速度、焦点和采用出点；分开演员靠近与摄影机靠近，固定段明确保持，遮挡不能盖住必要反应。 |
| 声音与同步 | 对白、呼吸、环境、动作声及已授权音乐分别说明声源、远近、起止和主次；接触／摩擦随实际动作发生，沉默期间环境连续，画外声不驱动画内人物错误口型。 |

同一节拍中的情绪、视线、面部、身体、摄影机和声音可以错开或并行，但须共享明确触发。相邻节拍承接上一状态，避免反应早于信息、每句恢复中性、全程重复抿嘴，或把所有微动作串成机械表演。不可见面部以姿态和声音承载，不补造表情观察。

时标是设计估计。按完整对白、关键接触和不可省略的反应检查时间预算，将可并行动作明确安排；短尾段容不下多次回头、前倾和遮挡时，优先减少非必要重复或按已有授权调整节拍。准确台词、身份和必要动作不因时长被静默删除或加速。没有实际语音／表演证据时，保留时长与同步待核实。

### 表演承接与接触闭合

发生关键转折时，检查刺激、接收、策略／行动与残留状态；有掩饰意图才进一步写掩饰和泄漏，不给所有情境套同一种心理流程。下一句承接上一句已经出现的笑意、紧张或犹豫；否认台词不自动让全脸归零。不同面部通道可以错开起落，听者的变化由实际收到的信息触发；有意冷淡、等待或静止无需每句补眨眼、点头和手势。

例如人物笑意已露却说“我没有。”，发音时嘴唇自然运动，眉眼与面颊可保留笑意；说完再看是否收住。此例只说明承接，不要求其他人物始终微笑或说相同台词。

涉及交接、抓握或身体接触时，明确执行者、动作次数、接近、接触、作用／回应、解除、撤离目标与出态。解除后再次接触须有新的已设计触发；不能把“松开后贴回”默算成同一次持续接触。用实际片段检查接触前后和恢复阶段，只有时间区间或一句“只做一次”不能证明动作闭合。说话与接触的先后需联合音画核验，不能从张口截图猜台词。

## 行动逻辑优先，关键节点硬锁

可把角色每一段表演写成 `目标 Objective → 阻碍 Obstacle → 策略 Tactic → 潜台词 Subtext → 对方实际提供的刺激 → 可见行为与出点`。先写**为什么做**、对谁做、何时收到信息，再只在景别可读的层次描述具体表情和身体动作。等待、听话和保持克制均能构成有因果的行动；现代日常、散文影像不强加冲突。

教学案例常用「70% 行动逻辑＋30% 关键节点硬锁」作为提示词分工比喻；这是作者经验，不是测量数值、权重参数或每镜配额。为视频模型需要的硬锁仍包括用户准确台词、可听触发、何时改变目光、动作接触与持物、使用哪只手、镜间运动相位及采用出点。若物件交接、兵器接触或口型时序为阻断要求，可以进一步明确可观察的相位，不机械放弃精确控制。完整场次交接见[导演生产关卡 G3/G5](scene-directing-pipeline.md#八个关卡及责任人)。

## 把角色处境转成可表演任务

Stella Adler Studio 的教学强调行动、给定情境与想象；Neighborhood Playhouse 对 Meisner 训练的说明强调关注对手、倾听与回应。本项目吸收两者的共同决策点：先写人物对对象做什么，以及何种刺激使这一行动改变，不要求所有演员使用同一训练体系。[行动与情境](https://classes.stellaadler.com/workshops/acting-technique-1-foundation-online/)、[倾听与对手](https://www.neighborhoodplayhouse.org/)

下面是导演起草与检查用的维度，不是每次都要交付的表格，也不是新 schema。选择本镜有独立作用的内容即可。

| 维度 | 可执行的写法 | 易失败的写法 |
| --- | --- | --- |
| 目标与对象 | “让门口的同伴留下，但不提自己害怕独处” | 只写“表现孤独” |
| 当下刺激 | 同伴把椅子推回桌下，开始转向门口 | 没有收到信息就突然变脸 |
| 策略与节拍 | 先借雨势劝留；对方仍要走，才把空椅移近 | 每句台词都同样哽咽与点头 |
| 眼线 | 先看对方脸，再因椅子移动看向空位，最后回到对方 | 眼神在无关方向漂移，或要求全程盯镜头 |
| 呼吸与停顿 | 让倾听或作决定占据句间；录制后检查自然呼吸是否打断含义 | 强制每次转折都吸气、吞咽、颤抖 |
| 姿态与重心 | 起身意图先体现为身体前移与脚下支撑变化，随后真正离座 | 脚没有承担重量，躯干已漂移 |
| 接触与物体 | 写清哪只手先握住哪里、如何施力、物体如何移动、何时松开 | 手穿过椅背，杯子自行移动，握持状态跨镜消失 |
| 台词与口型 | 准确文本对着对象说；句间听者继续自己的任务，唇部随实际发音 | 闭唇笑同时说整句，旁白却让画内人物动嘴 |

真人排练优先给行动与关系，允许演员提出不同选择；不同时微控眼睑、眉毛、手指与非自主生理。AIGC 提示词从已选演法中提取景别可读的少量变化，写清先后与残留状态。近景可读取嘴角或眼线；全身和远景更依赖方向、间距、重心与物体互动。克制不等于没有反应，强烈也不等于所有通道一起变化。

在跨镜重复动作时记录视线目标位置、身体朝向、支撑脚、哪只手接触道具、台词已说到哪里与正在倾听什么。连续动作按切点继承相位，重拍和省略分别说明；不能把人物的肩、手或视线每镜重置为中性。剧情表演与非戏剧情境都可使用这些维度，观察性场面不必虚构冲突。

## 情绪不等于面部几何

人物状态按[六层表演细节](prompt-detail-standard.md#人物情绪与表情生成)编写。普通稿用中文自然段；需要标签时，`<情绪>`写初始感受、触发事件、掩饰意图与结束感受；`<表情>`写强度、视线目标与转移、眼睑／眉间、唇部／下颌和呼吸；`<表演>`写姿态、手、重心、停顿和互动。除非实际文档提供有界控制，强度使用自然语言而非虚构数值。不默认所有情绪都以恢复平静收尾。

例如，人物放心却不愿明显表现：听完答复后看回对方，下颌松开，一侧嘴角出现又收住的笑意，轻轻呼气后停稳。不要同时索取“悲伤、开心、震惊、平静”的脸，也不把百分比叫心理测量。

首帧、终帧分别保存一个表情状态；视频稿才安排变化。参考首帧已经露齿微笑时，不能写“从全程闭唇开始”；若需要重制首帧，单独给修改稿并保留尚待生成的状态。对白区间允许唇形与下颌随发音变化，笑意可保留在眉眼和面颊，句间再回到选定唇部状态。

例如以细节规范中的聆听静帧作为已选首帧，设计一段六秒采用段：0至1秒保留闭唇浅笑、杯子在胸前、视线落于对面来客；1至3秒回应“谢谢你。”，眼神持续交流，唇部自然发音，眉间保持放松；3至4秒说完后笑容舒展，少量上齿可见；4至6秒右手将杯向来客递近一掌，杯口仍水平、低于下巴，至出点尚未接触另一只杯。摄影机保持坐席位置，服化道与光线沿用实际首帧。发音所需长度需真实音频复核，头尾剪辑余量另计；此处六秒是采用段设计，不是模型时长档位。

群像先定谁触发、谁回应、谁还在做自己的事，再安排错开的视线与身体反应。局部情绪修订须传播到表情资产、逐镜静帧、视频起止状态及相关语气指导；不改用户准确台词，不将声音情绪设置误认为面部已受控。

表演参考片段可以提供节奏与运动而不提供身份、服装、场景或调色。明确准确起止片段及排除项。只有通用视频参考时，写明希望迁移什么及未知精度，不能叫作保证成功的面部捕捉。实际使用真人身份、肖像、声音或录制表演时，按[参考证据与素材权利](../core/reference-evidence-and-rights.md#权利与隐私)核对该用途及向供应商传输的已有许可／同意；继承已确认范围，不将普通虚构创作增加为每任务审批。

## 表演迁移：输入职责先于参数

专用表演迁移与通用图生视频是不同路径。Runway Act-Two 的官方说明区分两类角色输入：图像可接受表演中的手势／身体变化，并会增加环境及摄影机运动；角色视频沿用原视频的身体、环境与摄影机运动，表演输入驱动面部，不能再假设可用相同手势开关。角色视频短于表演时可能反向往返循环；需要固定原有运动的镜头先检查长度匹配。具体界面能力在使用时复核。[Act-Two 输入与设置](https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two)

因此先决定参考职责：

1. **角色身份与造型来源：**用已选人物图或视频，保留身份、服装、妆造与场景。没有露出牙齿或侧面等部位时，不能把新露出的结果叫作已验证身份。
2. **表演来源：**用一条准确选段，迁移已指定的视线变化、节奏、台词和手势；排除录制者的身份、衣着、背景与采集光线。声音是否保留或替换单独说明。
3. **身体与摄影机权威：**角色视频、表演视频与文字分别负责什么，避免两个来源要求相反身体方向。当前模式不支持的通道保持未知或改用适用路径。
4. **第一次校准：**选择能包含本镜关键转折的短试片。若已选 Act-Two，官方建议先试默认 Facial Expressiveness，再据结果调整；这控制面部运动迁移量，不是人物心理强度。不要一边改参考、表演、取景，一边调表达量。

这里的参考分工与试片是本项目的制作决策；文字分工不能保证模型完全排除未选属性。多人对白按各人物分别规划表演和镜头接续，不把单人表演工具的输入建议强加为全片只能单人出镜；多人生成或合成路径按实际支持另定。

## 录制参考与追踪采集

先试录并回看取景、光线、声音和动作范围，再录完整表演。摄影机、演员眼线和动作标记需要可复现，避免用全身取景录完后才发现嘴唇不足以读取，或用脸部特写录完后才发现关键手势出框。

Act-Two 的输入建议包括单一表演者、连续无切镜、清楚可见的脸、最多到腰部的取景；迁移手势时，开始就让双手入画，并让初姿与角色输入相近。录制声轨保持清楚、少底噪。这是该工具的输入建议，不是所有动作捕捉系统的通用镜头规格。[Act-Two 录制建议](https://help.runwayml.com/hc/en-us/articles/42311337895827-Performance-Capture-with-Act-Two)

MetaHuman Animator 的当前单目视频采集指南按面部／身体任务分别设置取景，强调稳定机位、均匀扩散照明、可读细节与减少遮挡；全身采集需要从头到脚留有运动余量。其演员指南还列出眼镜、头发、浓妆等对面部追踪的影响，并声明当前系统针对成年面部设计。只在选用该采集路径时采用这些要求，不改写剧情角色、定妆或最终电影用光。[视频采集](https://dev.epicgames.com/documentation/metahuman/metahuman-animator-video-capture-guidelines-in-unreal-engine)、[演员外观](https://dev.epicgames.com/documentation/metahuman/metahuman-animator-performer-guidelines-in-unreal-engine)

- **取景和眼线：**把画外对手放在可重复的位置，记录相对镜头的方向与高度。是否看镜头由故事视点决定；若用眼线标记，应避免其让演员实际看到的距离与预期互动矛盾。
- **初态和动作范围：**参考与角色输入尽可能对应头向、身体朝向、手的位置和可见范围。捕捉脸部时让重要嘴形可见；捕捉身体时保护肢体和脚下支撑。极端转头、快速摆动或遮挡先作风险试片，不为技术便利删除已锁定叙事动作。
- **台词和同步：**录制准确台词、自然停顿和呼吸，保存原声；有独立录音或身体捕捉时，选择实际流程支持的同步标记或时间码。对手提示声是否进入输入或成片需要区分，不能在后期误作角色自己的台词。
- **表演选择：**比较演员完成同一任务的不同演法，选定后再做技术校准。不要用放慢表演来掩盖追踪失败后宣称情绪更真实，也不为凑工具时长删掉句尾。
- **录制光和成片光：**采集可以用平整清楚的光，角色成片按场景选侧光、逆光或阴影；只迁移选定动作。输入需要少遮挡，不等于最终镜头不能有有动机的遮挡。

## 数字人面部：检测、映射与艺术修订

Apple 的 ARKit `blendShapes` 是相对中性状态的面部特征运动系数，范围为 `0.0` 至 `1.0`，可用于驱动二维或三维角色。它不是“快乐度”“悲伤度”或对真人内心的测量；同一数值跨角色也不保证得到同样可见形变。[Apple 系数说明](https://developer.apple.com/documentation/arkit/arfaceanchor/blendshapes)

采用数字人／引擎路径时，分开检查：输入检测是否稳定，目标角色的命名与左右通道是否正确映射，形变是否保持身份和唇齿关系，以及镜头中是否读得出已选表演。中性、单通道与组合姿态分别比较；闭唇、张口、笑与转头不能只靠一个中性截图验收。

社区原作者 Pooya Deperson 提供逐通道的解剖与视觉对照，可用于定位眼睑、嘴角和下颌究竟哪个区域出错。本项目吸收这种“按通道观察”的诊断方式，不复制其角色造型，不把示例满幅值当成当前角色的最佳表情；作者工具和示例并未在本项目运行验证。[原作者指南](https://pooyadeperson.com/the-ultimate-guide-to-creating-arkits-52-facial-blendshapes/)

Epic 的 Face AR Sample 说明，组合面部形变可需要 corrective blend shape 来修正结果。因此，若单个通道正常、组合后唇部穿插，先查映射、形变组合与目标 rig；不要默认让演员减少情绪，或把全局强度调小当作唯一方案。该示例的实现依其引擎版本，不代表所有 AIGC 平台都开放这些控制。[Epic 组合形变示例](https://dev.epicgames.com/documentation/en-us/unreal-engine/face-ar-sample?application_version=4.27)

眼线、头向、唇齿、面部、身体、道具接触与声音在成片里共同成立才形成可信表演。独立面部动画通过并不证明身体捕捉、眼球运动、声音、衣物或最终渲染同步通过。

## 台词与声音表达

每句保留批准后的准确文本、说话人 ID、语言、画内／画外／旁白类别、对谁说、轮次、时间窗口、声音参考或选定声线、口型要求和字幕策略。舞台指示与口播分开；未授权改写，不改标点和措辞。

声线、逐句表演与声场分别设计：声线说明全段稳定的音域感、共鸣、质地、气声和咬字习惯；逐句表演说明想让对方做什么、重音、停连、掩饰及说完的状态；声场说明远近、房间反射和画内／画外关系。“温柔、低沉、俏皮”等词不能替代这些决定。情绪引起的语调变化不自动等于换声线，也不以持续气声或所有句尾上扬代替亲近。

声音参考只绑定实际提供的角色、采用范围和排除项；无参考时可完成原创声音设计，但不能从照片推断人物实际音色或声称已锚定。是否自然、声线是否稳定及空间是否匹配，按[声音证据与听审](video-sound-and-delivery.md#声音证据与听审)另查真实音轨。

`<台词>`中可写 `甲：“这盏灯，你拿着。”`；`<语气>`写轻声、提到物品后短停、不戏剧化哽咽；`<情绪>`写关心但不强求。真正 TTS 载荷只取口播字符串；说话人标签及外层引号是元数据，除非明确要求读出。

按已确认能力选择声音路径，不强制一种：可用的原生音画联合生成；文档明确支持的录制或生成对白作为时序／声线参考；或者单独配音后同步／剪辑，并说明工作流和限制变化。

配音面板的情绪参数只控制声音，不等于视频面部表情滑杆。选择声音、音色参考、表演录制、音素对齐口型是不同控制；未知支持保持未知。

语音长度仅在草稿中估算，最终以实际表演音频为准。呼吸、停顿、打断和听者反应要有空间，不用“字数除以固定通用语速”冒充事实。不能为了时长档位自动加速或截断已批准台词。跨镜头 J-cut／L-cut 需明确声音桥归属；旁白可跨镜头，不要求可见人物跟着动嘴。

已有声音结果可按[返回音频回流](video-sound-and-delivery.md#可选返回音频回流)声明来源、版本、候选、测量依据、所选源区间和当前节点／提示的同步锚点；声音参考输入与成片输出音轨分开。对白超出采用窗口时，先核对完整台词、停顿与测量，再提议延长／调整覆盖、使用真实合格备选或经授权重录；检查器只给帧数建议，不加速、截断或改写。确需摘录时，明确该提示的授权与准确采用文本，另行听审，不让授权字符串冒充已取得同意。环境声循环和跨镜声音桥可以保留明确映射，不把专题讲解片的固定块长、单旁白或整分钟限制推广到剧情表演。

## 摄影机与焦点

原创叙事视频继承[镜头语言决定](../routes/shot-direction.md#镜头语言选择关卡)。机身运动与焦点行为分别写：固定需给理由，移动需给路径／速度／视差／出点；移焦需写原先存在的两个焦点对象和触发，不把拉焦当推轨。演员轨与相机轨可同时变化但不能相互代替，平台实际支持另行核验。
写明视点／轴线、起始景别、运动方向／路径、与人物关系、动机、速度阶段、采用出点构图及运动相位和焦点行为。第一视角要说明是谁的视点，哪些人物可对该视点讲话，不全局禁止看镜头。

用机位高度、人物距离和眼线落实关系意图；人物前倾、摄影机推进及前景手势分别记录。返回片段以固定背景的变化辅助区别相机运动与演员运动，脸部变大本身不证明推进。结尾按叙事所需可见区域、动作相位和可用区间验收；最后一帧存在表情不等于该反应可读。需要保留脸部的遮挡动作应有终点，允许完全遮挡或运动中结束的设计则按本镜授权检查，不强制停稳。

主要路径只选一个权威控制通道：有文档的原生控制、提示词文字或有界运镜参考。可补充不冲突的意图和锁定，不叠加相反运动，也不虚构平台运动强度参数。没有受支持且已校准控制时，焦段语言只是视觉意图，不代表真实光学几何。

按节拍选择匀速、加速、减速或停顿阶段，不规定每镜都先加速再停稳。快速跟拍、遮挡揭示或弧线运动须保护画面方向、运动通道、揭示时刻和可读动作。持续运动可以在运动中切出，记录人物／摄影机的方向、速度阶段、动作相位与可续接状态；只有叙事停顿、阅读、接触或已批准端点确需时才安排停稳。人物停顿时摄影机可以移动，人物变化时摄影机也可以固定。静帧尾图只表示边界姿态，不能证明出点前停止或中间轨迹。

## 将特效写成有时间的物理事件

`<特效>`包含来源／附着锚点、开始、生长、峰值、衰减、空间范围、遮挡以及材质／光的相互作用。注明终态是否保留。现场光与调色分离：灯笼或法术可以局部暖化附近表面，但不把中性日光场景全部染黄。

原创示例：提示时刻，银色微粒从挂坠周围出现，形成小范围环绕，微弱映在邻近丝绸上，然后在最后停留前衰减。没有权威授权，不能给已批准世界增加光源或魔法能力。除非明确设计，不用遮脸闪光盖住关键对白。

身体／道具／环境接触不可分时，可优先规划生成内特效；可分离且合成能保护镜头时，独立特效层或后期处理可以是备选。但这不证明平台支持遮罩、alpha、重打光或合成。外部流程允许时保留干净原片，逐版记录修订。

## 时间工作表与验收

时间相对生成片段记录，剪辑入出点另用区间。标记主要动作、摄影机运动、面部变化、台词、光响应、特效包络、按需停顿以及采用入／出点的运动相位。并行事件不用逐项累加，但必要停顿与先后依赖必须计入；运动中切出也应把完整台词、必要接触与所需反应留在采用范围内。

实际媒体验收包括说话人／声线对应、逐字台词及说完、视线连续、表情过渡而非换脸、接触、身份／服装、有动机运镜、特效附着与消退、光色一致、采用出点状态与下一镜可续接、环境底声连续。有意运动中切出的镜头检查动作相位与残余运动，确需停稳的镜头检查停稳是否完成。素材可访问时分别检查有声和静音播放；计划时间码不是测量事件。

把录制输入与生成／渲染输出并排核对转折：参考中何时收到刺激、何时改变眼线或策略，输出是否发生在对应台词和动作附近。先正常速度看因果与可信度，再检查问题帧、接触前后和口型区间。一个稳定正面不能证明转头和张口过程中没有换脸；声画对齐不能只检查句首，还需检查关键发音、句尾与停顿。

回流声明和时间算术完成后，仍分别核查可懂度、逐字内容、完整句尾、实际声音先入／后出、关键发音与可见动作，以及相邻环境声接点。`measurementVerified` 和 `mediaVerified` 保持 `false`；实际听审与画面评审另有证据和结果，不能用结构通过解除 `SPEECH_TIMING_UNVERIFIED` 或记录媒体成功。

二次校准只改变已定位的一个因素，例如重录不清楚的句尾、修正眼线标记、匹配起始手势、调整面部迁移量或修目标 rig 的组合形变。先记录输入问题还是输出问题，再复查邻近节拍；保持已通过的台词、身份、造型、摄影机与动作。不得把供应商演示或本文的设计样例记为项目实测。

## 完整局部示例：劝同伴留下

以下是虚构剧情单镜的创作与录制方案，八秒仅为当前草稿的采用窗口，具体发音和节拍需据实际录音与试片调整；不规定平台时长档位。

**演员任务：**让摄影机右侧、已准备离开的成年同伴再坐一会儿，理由是雨势，暂不说自己不想独处。初态左手沿桌面轻理纸边，右手静放桌边，身体朝向同伴。搭档在画外转身的动作是刺激；演员先停止手上的动作，确认对方要走，再开口劝留，等待对方反应后才示意空位。采集时只拍这一位表演者，用清楚照明与稳定机位保留头、肩、手及需要的身体范围。若选 Act-Two 图像输入，两只手从开头入画，角色图初姿匹配；若选角色视频输入，身体示意和机位先存在于该视频，不能把迁移手势视作已有能力。

**通用视频正文：**

```text
八秒采用段，16:9 横向写实剧情镜头。傍晚的书籍修复工作室，一名成年男性修复师坐在旧木工作台后，深灰棉麻衬衫的袖口卷至前臂，短发中有少量灰发，整齐短胡须。桌上有一叠修复纸，摄影机右侧画外是已准备离开的成年同伴，窗外仍在下雨。摄影机在修复师眼睛高度，固定三分之四侧面中近景，完整保留头顶、肩膀、桌边双手和其右侧的空椅边缘；脸、服装与工作室陈设全段稳定。左侧窗的柔和暮光照出鼻侧与颊部层次，右侧浅墙提供较弱反光，肤质自然克制，衣料和纸张各有不同表面响应。
开头他的左手正沿桌面轻理纸边，右手静放桌边，指腹接触木面，身体朝向右侧同伴，闭唇看着对方。察觉同伴在画外转向门口，他先停止左手整理纸边的动作，视线随对方略转向右侧，再看回对方脸的位置，下颌稍微松开。他对同伴说：“你先坐下，雨还没停。”声音平实，前半句是邀请，后半句轻轻解释；唇与下颌自然随准确发音变化，眼神仍对着对方，不转向摄影机。说完后他留出倾听间隙，再将右手从桌边抬起，掌心朝上，向身旁空椅做一个小而清楚的示意；没有触摸或移动椅子。肩膀稍向同伴打开，身体仍由座椅支撑，左手继续接触桌面。他等着对方回应，到出点右手仍停在示意位置，嘴唇已自然闭合，画面保留这一邀请的未决状态。机位、焦点和光线保持稳定，焦点保护脸部与主要手势；声音保留准确对白、自然呼吸、轻微纸张声和连续雨声，画外同伴没有额外台词。
```

**参考交接：**人物图负责身份、服装、初姿和场景；录制片负责已选眼线、台词节奏与回应过程，手势迁移依实际模式。采集者的脸、衣着、背景和采集平光不进入角色设计。音轨保留准确台词；是否保留录制声线另行选择。提示词中雨声和纸张声是成片意图，不能假定表演迁移工具会自动生成这些声音。

**检查点：**刺激先于停手与开口；句尾完整；对手眼线在同一空间方向；发音时不被闭唇约束；右手示意没有误变成握持；左手接触和身体支撑稳定；八秒内是否容纳全部变化以实际素材判断。没有实际输入和结果时，只能说方案已写成，不能报告口型、身份或真实表演已经通过。

失败后按[生成诊断](generation-diagnostics.md)修一个所属变量并保留通过维度。结构合法、模型遵循、艺术偏好、权利、可复现性分别判断，不能相互推导。
