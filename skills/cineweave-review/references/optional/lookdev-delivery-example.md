# 可选参考：完整视觉开发交付样例

需要实际 G1 卡片、光位图和测试任务的写法时加载。以下是原创设计演练《归还的书》，不是用户已批准项目、影片复刻、生成记录或视觉验收。工作包 `DEMO_G1@r1`；六项设计正文已提供，媒体未提供。编号均为示例工作引用。

## 简报与交付索引

场景：傍晚的小型修书室。一名成年修书师在长桌西侧检查归还的旧书；来客位于长桌东侧，双方保持安静的工作关系。保护事实：同一人的自然肤色与相貌、灰棉工作服、书的砖红封面、固定门窗位置、无雨无雾、两盏已设计源光。色彩采用 `CG07@r1` 的柔阶思路，保留砖红书皮作为叙事锚点，不照搬影片的美术。

## 风格卡

`G1_STYLE_001@r1`：写实电影摄影的设计意图；关系平静、距离可读，旧物有使用痕迹但不破败。体块和透视自然；边缘清楚，皮肤与纸张保留细微变化；综合色度克制，砖红书皮可辨；暗部舒展但不抬成灰雾，亮纸柔和收束。运动应连续自然，纹理附着于材料。禁止磨皮、统一黄绿染色、背景乱加灯、改变书封颜色。任何胶片颗粒均作为独立可选项，首轮关闭以便比较材质。

## 配色卡

`G1_PALETTE_001@r1`：以下为原创 sRGB 显示示意，不是影片取样、材料反射率或变换参数。面积关系采用文字职责；镜头构图改变时不强求固定占比。

| 色块 | 色值 | 分配与关系 | 保留项 |
| --- | --- | --- | --- |
| 暖纸 | `#D3CCB9` | 亮部主要落在旧纸与少量墙面，不占满全屏 | 书页纤维和折痕仍可辨 |
| 烟草木 | `#84735A` | 长桌与书架构成主要环境色 | 木纹不变黄橙色条带 |
| 灰棉 | `#747970` | 修书师上衣，处于纸与暗背景之间 | 不染成饱和军绿 |
| 砖红 | `#984F47` | 唯一显著强调色，绑定书封 | 不能降成灰褐或变鲜橙 |
| 棕灰 | `#393B36` | 背景与物件暗侧 | 不将黑发与书架吞成一片 |

日末变体：窗侧光保持略冷的自然环境感，纸面暖色主要来自材料。夜间变体仅在场景另行采用时关闭窗源、保留桌灯覆盖与更深环境，不把整间房自动加暖。无夜间素材时只交此设计，不能称已匹配昼夜。

## 材质卡

`G1_MATERIAL_001@r1`：材料固有事实与照明下的外观分开。

| 材料 | 表面与反射 | 窗光／桌灯响应 | 失败判据 |
| --- | --- | --- | --- |
| 人物皮肤 | 自然底色、轻微粗糙度变化、细腻宽高光 | 窗侧略冷、灯近侧局部暖，底色差异保留 | 全脸橙黄／泛绿、蜡化、脸型改变 |
| 灰棉衣 | 哑光细织纹、折痕有厚薄 | 两源下亮度变化大于颜色变化 | 像皮革、纹理悬浮、黑边描线 |
| 旧纸 | 淡暖基色、纤维与折边、漫反射 | 桌灯下局部变暖，窗光下仍与白墙可分 | 大片无纹理白、油亮塑料 |
| 木桌 | 暖褐基色、纵向细木纹、弱宽反光 | 窗光条带较宽，灯侧局部柔亮 | 镜面化、自动湿润、纹理方向乱跳 |
| 砖红布书封 | 细布纹、磨损只在边缘、低光泽 | 受光后提亮而非变橙，暗侧仍属砖红 | 重画封面、生成新标题、色相跨镜漂移 |
| 桌灯金属 | 暗灰涂层，边缘少量窄高光 | 灯罩外壳不自发光；内侧受灯泡照亮 | 全部发光、白色金属球式反射 |

## 灯光卡

`G1_LIGHT_001@r1`：世界源 `L1` 为北窗漫射傍晚天空光，`L2` 为长桌南端的暖桌灯。L1 是人脸与桌面的主要宽光，侧向塑造体积；L2 主要强调书页与近侧手部，不额外布置轮廓灯。墙面仅承担已有反射，不新增看不见的强光源。

光比为设计关系：主光面清楚，背光面保留眼眶与衣料信息，书页亮但不压倒人物。没有现场测量，不给伪精确照度或曝光数值。L1 与 L2 的冷暖关系可辨，但肤色不被分成生硬青橙两块；调整机位不能改变两灯的世界位置。影子方向须与光位图相容。

## 光位图

`G1_PLOT_001@r1`，俯视设计示意。北在上；房间约4米东西宽、5米南北深是本样例原创假设，不是测量。人物面向书桌／对方；书位于桌中。人物轴为东西向，C1、C2 均在轴南侧；图仅展示可行设计，实际遮挡和视场仍需预演。

```text
                         北 N
             ┌─────── L1 北窗 ───────┐
             │       ↓ 宽漫射光      │
 西 W        │                      │        东 E
             │ 修书师 A → [书/桌] ← B│
             │           L2 桌灯    │
             │        ↖ 局部暖光    │
             │ C2 ↗          ↖ C1   │
             │                      │
             └──门／南西入口────────┘
                         南 S
```

图例：A 为修书师、B 为来客；C1 在东南看向 A，C2 在西南看向 B；L2 位于桌南端向书页照射。北墙只有窗，书架在东墙北段，门在南墙西段。C1 与 C2 不占用门口；反打仅改变画面左右，不调换北窗和门。图上箭头为方向设计，不是光束追踪结果。

## 测试任务

`G1_TEST_001@r1` 是完整待执行任务包，**不是已生成测试板**。全部任务先固定角色设计、服装、书封、空间、L1／L2、输出观看条件；同一任务用同一素材比较中性版本与 CG07 创意版本，独立生图不能被当作严格单变量像素实验。来源编码和显示条件待外部返回，不默认 Log 或 HDR。首轮关闭附加颗粒与光晕。

### T01 人物近景

静帧复制稿：傍晚修书室，成年修书师穿哑光灰棉工作服，在长桌西侧自然坐定，眼睛看向桌上的旧书；东南侧机位拍头肩近景，北窗的宽漫射光照出面部侧向体积，长桌南端的暖桌灯只在邻近皮肤与衣领形成微弱暖反射。保留自然肤色底色、毛孔与轻微明暗变化，眼眶可读，灰棉织纹与背景木架分离。环境为柔和烟草木与旧纸色，暗部舒展而不泛灰，高光柔和收束；无颗粒、无光晕、无额外轮廓光，不磨皮、不改变人物相貌。

判据：同人同衣；皮肤不黄绿、眼眶不堵、灰棉不变皮革。返回：原图、创意版、输入编码与实际可知参数；状态：未提供，未评视觉。

### T02 场景空镜

静帧复制稿：无人修书室的清楚空间全景，北墙一扇窗，南墙西段为门，东墙北段是木书架；长桌位于中央，砖红布面旧书在桌中，暖桌灯在桌南端。摄影机从南侧朝北观察，保留东西方位；北窗漫射傍晚天空光作为主要宽光，桌灯只照亮书页附近。烟草木色为环境主体，旧纸亮部柔和、灰棉座垫低光泽，阴影保留桌腿与书架层次，无雨雾、无新增灯具，白墙不统一染黄绿，书封保持砖红。

判据：空间锚点可找到、白面有层次、亮暗不互相吞并。返回：与 T01 同一视觉基线的空镜及准确版本；状态：未提供。

### T03 材质测试

静帧复制稿：在修书室原长桌上近距离观察并排放置的旧纸、灰棉布、砖红布面旧书和桌灯暗灰金属底座，旁边露出桌面木纹；摄影机在桌南侧略俯视，保持真实相对尺度。北窗提供宽漫射光，桌南端暖灯的覆盖只落在相邻物件，光色交界自然。纸有纤维与折边、棉布哑光细织纹、书封低光泽且砖红稳定、木纹纵向连续、涂层金属有窄而克制的反光；柔和明暗、克制色彩，无颗粒、无磨皮式模糊，不把各材质统一塑料化，不增加标签文字。

判据：五种材料可分；书封色相受光变化合理；不以噪点代替纹理。返回：中性／创意对照与对应素材说明；状态：未提供。

### T04 内外光转换

视频测试稿：同一成年修书师穿灰棉工作服，手持砖红旧书从南西入口的中性环境光区域平稳走入修书室，在长桌西侧停下；书始终在双手之间、封面颜色与结构不变。固定南侧中景机位完整覆盖这段行走，北窗宽光逐渐成为主要面部光，靠近桌面时南端暖桌灯只增加近侧手部与书页的暖反射；人物肤色、棉衣与书封连续变化，不发生全画面白平衡跳变或整脸忽冷忽暖。烟草木与旧纸环境保持柔和明暗，动作按自然步速完整呈现，无对白；仅脚步与室内底噪，无额外颗粒、光晕、雨雾。

判据：变化有空间触发，皮肤／书封逐帧连续，任何自动曝光变化均需记录；实际时长与参数依返回登记，未执行不填秒数或帧号。状态：未提供。

### T05 正反打一致性

正打静帧复制稿：傍晚修书室，成年修书师 A 穿灰棉工作服坐在中央长桌西侧，来客 B 坐在东侧，二人看向桌中同一本砖红旧书；东南机位 C1 面向 A，B 的肩仅作近景边缘。北窗的宽漫射光与桌南端暖灯保持各自世界位置，主光塑造 A 的脸部体积，暖灯主要照书页。烟草木、纸白、灰棉与砖红形成克制而分离的色彩，面部保留底色，暗部可读；无额外灯、颗粒或光晕，不改变门窗与书的位置。

反打静帧复制稿：同一傍晚修书室、同一人物外观与时刻，修书师 A 仍坐中央长桌西侧，来客 B 仍坐东侧，二人看向桌中同一本砖红旧书；西南机位 C2 面向 B，A 的肩仅作近景边缘。北窗仍在世界北侧，暖桌灯仍在桌南端，按该机位呈现真实受光方向，不为反打镜像光源。保持烟草木、纸白、灰棉与砖红的共同基线，面部保留底色，暗部可读；无额外灯、颗粒或光晕，不改变门窗与书的位置。

判据：参考同一主镜色彩关系，允许机位导致受光差异；不要求两脸同亮或背景像素相同。身份素材尚未提供，角色一致性不能凭这两段文字判定。状态：两张均未提供。
