# 可选参考：导演手法自动适配

需要比较镜头、调度、风格或节奏手法，或用户明确指定、组合、调整影响来源时加载相关小节。先按简报选择可用机制，不要求填写导演名字或强度设置；已有明确方案时不必加载。本库提供可编辑手法草稿，不改变人物、地点、故事或平台设置，也不保证复现某位创作者。

目录修订：3；原来源研究快照：2026-09-08；本次证据补强继承 **2026-10-10** 的已读正文研究，未将文本实施日当成重新访问日。未复查旧来源和未审听媒体的限制见各卡与[学习记录](film-craft-study.md#比较创作实践不把来源当现成预设)。这些是 CineWeave 对部分创作思想的原创解释，不是官方艺术家预设、背书、完整生涯总结或电影场景复制。来源支持的机制、合作者贡献与项目提出的实现方法分别说明。

## 识别与适配

从场景出发，不先索要配置。下列名字和 ID 用于组织方法库，是可选覆盖项，不是必填输入、可执行命令或规范产物引用。

| ID | 可选名称 | 适合目标 |
| --- | --- | --- |
| `hitchcock-suspense` | 希区柯克：受控悬念 | 知情差、危险预告、延迟揭示 |
| `kurosawa-ensemble` | 黑泽明：群像与行动选择 | 多人关系变化、行动因果、删去装饰镜头 |
| `wong-withheld-intimacy` | 王家卫：含蓄亲密与错过 | 未说出口的关系、遮挡、重复中的变化 |

| `cuaron-lubezki-immersion` | 阿方索·卡隆／艾曼努尔·卢贝兹基：沉浸连续性 | 连续空间中的发现、同行视角、现场感 |

1. **提取创作问题：**观众体验、谁何时知道什么、关系／压力与可见行为、可用空间／光源、媒介／时长、既有序列语法及保护事实。依据已提供证据，不单凭国籍、类型或“电影感”。不从身份推断真人情绪或用户品味。
2. **找机制，而非人格匹配：**先筛相关卡，再查看方法和禁用检查。观众先知可能适合控制披露，未完成交流可能适合暂缓展示，群体站队改变可能适合群像调度。线索只提示候选，不自动整卡采用。
3. **先过滤再采用：**排除与已批准故事、拓扑、源光、表现方式、表演锁、媒介或已知能力冲突的机制。缺少能力证据不是支持。静帧不能实现声音或时间效果，也不能为提高匹配度编造参考或来源。
4. **组合最小一致方案：**每个相关维度选最有用机制，比较其对简报的贡献、与当前段落的兼容性、可读性和可行性。自行解决推断候选之间的竞争，同等适合时优先简单、侵入小的方案。不把让用户选择推断预设作为固定步骤。
5. **直接交付，简述理由：**输出所需镜头／序列，只解释重大决定。例如“让观众先发现跟随者，保留人物不回头的动作，因此采用延迟确认与克制的镜头变化。”只有有用或用户要求时才提导演名字，不用名字列表替代实际导演设计。

只使用相关维度：调度、表演、构图、摄影机、镜头光照、节奏、声音。色板、表现方式和调色继承共享基线，不从不同卡片自动拼接。默认维度只是候选范围，不是不可拆套餐。克制意图采用小线索；更明显的几何、时长或声音反差需简报支持。“更克制”“再夸张一点”足够，不强制数字权重、开关或轻／中／强问卷。

修订需要时保留简短记录：简报线索 → 选中机制及维度 → 卡 ID／修订号 → 保留事实 → 排除冲突或未知项 → 下一项检查。这不是新增 JSON 字段、计算置信度或平台权重，不需要虚构匹配百分比。

## 边界与连续性

- **没有合适匹配也是有效结果。**证据弱或机制均冲突时，用中性创作方法提供保守草稿。重要假设要说明，不必给每场戏贴名导，也不为分类而询问偏好。只有未解决硬事实或矛盾显式要求阻止有用草稿时才聚焦询问。
- **显式指令优先。**已批准事实／硬锁 → 用户选择或排除 → 兼容的既有序列语法 → 自动维度选择 → 通用默认。点名影响不能推翻硬锁。显式要求冲突时提出聚焦问题或分别标注替代方案，不默选。
- **按维度融合，不做平均。**不同卡解决同一简报不同方面时可自动组合，每个维度保持一个一致选择。先解决推断的摄影机／节奏冲突，不为展示知识面堆参考。
- **保留段落一致性。**节拍、约束或媒介变化时复评，不逐镜重新风格化。除有故事动机外，保留色板、光源逻辑、摄影机语法和表演连续性。草稿适配不批准新全局风格包，也不暗改正式设定。
- **手法可混合，视觉保持统一。**遵循[共享视觉基线](../core/visual-bible-and-continuity.md)，保留调色、色温关系、饱和度、反差／滚降、材质、光学纹理和画幅。用光手法必须符合基线及实际光源几何。无基线时建立一份共享草稿；故事引发的照明变化不授权更换共同调色。
- **尊重任务类型。**浏览、解释、评审、精确编译／翻译和验证，不授权重做既有产物风格。只在请求需要时推荐；单变量修复保留所有已通过维度。
- **无需开关也要尊重排除。**“不要大师风格”即该范围采用中性方法；“只改构图”就限制到构图。移除旧处理时保留后续显式编辑。仅恢复已知基线；没有则提出中性草稿，不伪称恢复历史，更不能删除已批准产物。

## 1. 希区柯克：受控悬念

**默认维度：**调度、构图、节奏；只有揭示需要改变信息可见性时才调整摄影机。

**范围／证据：**1937 年本人文章以《讹诈》（1929）和《破坏》（1936）解释手、眼、物件使用及反应如何让观众理解心理行动，并允许说话声继续在倾听者画面上。[BFI 本人文章](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)原刊1937年夏，网页更新2024-08-12。[ASC 本人访谈](https://theasc.com/article/flashback-hitchcock-talks-about-lights-camera-action/)网页2017-06-12，涉及《冲破铁幕》（1966）、景别、运动与短画面可读性；摄影实现有 Jack Warren、Robert Burks 等合作者。本次继承2026-10-10文字研究，未观看影片或访谈视频。

**项目转化：**分开观众与各人物所知；先决定线索怎样进入解释，再选择共同画面、物件细节或倾听反应。让持有、迟放、误用、发现或避让形成可见行为链，避免仅写“内心纠结”。移动或切镜以认知变化为动机，不仅为增加活力；人物动作不能为插入镜头重新起手。

**可调项：**观众先于／同时／晚于人物获知；关键物最初可见多少；等待长度；固定观察或有动机揭示。

**适用／取舍：**适合已给定的知情差或物件参与的关系变化。细节覆盖能集中注意，也会隐藏共同表演、改变时间推断或过早揭底。简报禁止威胁或观众先知时关闭对应机制，不为套卡添加犯罪、武器或惊奇结局。ASC 中《西北偏北》的明亮开放空间是暗光悬念的反例；细切、阴影和长镜都不是通则。

**控制／验收：**保留披露顺序、视线目标、物件持有和动作相位；对白覆盖与切点依实际剪辑／声音支持。检查线索前后观众的解释是否改变，短插入在采用时长与交付尺寸上是否看得清，是否误示某人在看或拿该物。只看首帧不能确认心理行为链、音画覆盖或悬念成立。

## 2. 黑泽明：群像关系与决定性行动

**默认维度：**调度、构图、节奏。

**范围／证据：**Donald Richie 的[《蜘蛛巢城》（1957）现场亲历](https://www.criterion.com/current/posts/938-throne-of-blood)，1991-12-02，记录删去拖延行动、显得混乱、人物状态不符或过于漂亮的素材；正文还分别引述黑泽明与美术村木与四郎。[《天国与地狱》（1963）](https://www.criterion.com/current/posts/515-high-and-low-between-heaven-and-hell)，2008-07-21，是 Geoffrey O’Brien 对关系空间、姿态与剪辑的评论，不是导演本人公式。两项继承2026-10-10文字研究，未观看影片。

**项目转化：**先写行动前关系排列，再写谁的决定性动作使谁靠近、退出、转向或回应。将发起者、见证者、回应者分置可读空间层次，保留动作原因与后果；只删去对当前目的无贡献的重复角度。使用群体视线与距离，不自动给每人特写。

**可调项：**同时或选择性展示反应；纵深分层程度；作出决定前停顿；交代结果的最小覆盖。

**适用／取舍：**适合多人站队、压力或行动决定改变关系。多人纵深增加遮挡、焦点与身份持续风险；必要反应被遮住时简化排列或改覆盖。单人镜头、关系不发生重组或空间已硬锁时，不强加群像变化。雨、风、战斗、新地理不是签名；删漂亮素材不等于一律快剪，也不禁止有效的环境观察。

**控制／验收：**记录同时可见的关系、每人的视线／任务、动作前后排列和最小必要覆盖。检查观众能否辨明谁的行动重组群体，切走后是否丢失不可替代反应。多角度独立生成不等于同步多机位，群像身份和跨镜持有需实际素材比较；本次来源不支持通用声音处方。

## 3. 王家卫：含蓄亲密

**默认维度：**构图、表演、节奏。摄影机效果需在共同光学／时间语法中另行论证；色板继承基线，不从名字导入。

**范围／证据：**[《花样年华》（2000）本人访谈的 BFI 文献重刊](https://bfidatadigipres.github.io/world%20of%20wong%20kar%20wai/2021/07/14/in-the-name-of-love/)原刊2000年8月，重刊2021-07-14，注明可能编辑／节录；支持重复日常背景衬出人物改变。[《重庆森林》（1994）本人访谈](https://www.bfi.org.uk/sight-and-sound/features/poet-time-wong-kar-wai-chungking-express)原刊1995年9月，网页更新2020-05-21，讨论自我言说与旁白的不同用途。导演答语、采访者评价和转述张叔平意见分开；不把杜可风／张叔平等合作者的摄影、美术贡献归成导演独创。继承2026-10-10已读正文，旧未取得全文PDF仅留学习记录。

**项目转化：**让普通共同任务承载未完成交流，重复允许的动作或取景并改变一次回应。已有门洞或前景可暂缓展示关系，但遮挡不是必选；写清当下行动、猜测与重演的层次，不能让含混变成事实矛盾。台词已锁定时保留准确对白，不为“含蓄”删词。

**可调项：**无遮挡或部分暂缓展示；固定空间内的人物距离；重复或推进；未说出口的回应时长。保留共享色板、源光和服装颜色。

**适用／取舍：**适合未说出口的关系或重复条件中的变化。重复占用时长，遮挡会牺牲接触可读性，重演可能误认成当下。必须一次说明清楚事实、禁止重复或锁定无遮挡时，关闭对应处理。不强制霓虹、雨、慢动作、模糊、旁白、恋爱或不忠；《重庆森林》的旁白不能自动移植为《花样年华》路线。

**控制／验收：**固定两次观察的身份、地点与共同条件，标出唯一回应变化及是否属于重演。检查没有色彩效果时关系差异是否仍可读，必要手部接触是否被遮住，观众会不会误认时间层次。旁白、重复剪辑或时间效果依已知能力；文字不保证身份复现，也不据访谈推断焦距／曝光参数。

## 4. 安德森／耶曼：精密画面

**默认维度：**构图、调度、摄影机；节奏需叙事理由，色板仍继承共享视觉。

**范围／证据：**[Robert Yeoman 谈《布达佩斯大饭店》（2014）](https://www.motionpictures.org/2014/12/2014-in-review-dp-robert-yeoman-on-the-grand-budapest-hotel/)，2014年12月，是摄影师第一人称访谈，涉及与导演、道具／美术的协作、色彩测试、实景准备和动态分镜；不是安德森本人对全部作品的声明。保留2026-09-08研究范围，本次未重新读取来源或观看材料。

**项目转化：**围绕既有轴线建立清晰正面排列，每位演员有不同位置或入场方式。按当前节拍选择停留、明确横移或有意转向；打破排列用来表现幽默或地位变化，而不是先规定对称再修改房间。

**可调项：**严格／放松对称；正面／略斜；固定／横移；规律／打断入场。即使高度图形化，也保留共享色板和材质色。

**适用／取舍：**适合可读秩序、空间喜剧与秩序被打断。严格排列可能压缩自由表演，正面构图可能隐藏深处接触；锁定不对称、空间不足或自由表演优先时，放松或关闭对应机制。不移动固定门墙，不强上粉彩调色，不改画幅；一部影片的协作方法不等于全部作品都采用同一构图。

**控制／验收：**保留拓扑、轴线、入场顺序和关键动作可见范围；布局或运镜控制依当前媒介。检查排列是否澄清关系，打破秩序是否来自可见动作，失去对称后故事信息是否仍成立。几何整齐不能替代演法与交接验收。

## 5. 卡隆／卢贝兹基：沉浸连续性

**默认维度：**调度、摄影机、节奏。

**范围／证据：**[ASC《人类之子》（2006）制作记录](https://theasc.com/article/children-of-men-humanitys-last-hope/)包含卡隆与摄影师卢贝兹基的创作者证言，涉及沉浸连续观看、设计照明及为节奏缩短长镜头。保留2026-09-08研究范围，本次未重新读取来源或观看影片；不能从报道推断当前平台控制能力。

**项目转化：**沿可通行空间跟随一个有位置的视点，让前景事件与背景后果共存。运动发现新关系，采用出点记录人物、摄影机、焦点与环境的可续接状态；可在运动中切出，不自动减速停止。演员与摄影机／焦点轨分开但同步，确需停稳的叙事终点再明确停稳。

**可调项：**摄影机与主体距离；保留多少环境动作；连续观看时长；有动机的注意力转移次数。更长不自动更强。

**适用／取舍：**适合观众需要同时理解的空间发现与关系。持续观看增加路径、遮挡、焦点及表演同步成本，也可能拖延必要信息。已锁定切镜及不支持的路径／时长优先；不可行时给服务同一目的的剪辑方案。来源中缩短长镜是反例：更长不自动更强，连续性不等于不打光或永不剪切。

**控制／验收：**检查整条路径、速度阶段、入／出点运动相位、焦点和必要反应；不能只看主视觉帧。静帧尾图描述一个边界姿态，不能证明人物或摄影机已停住。没有受支持控制或实际结果时，轨迹、完整运动和跨镜接续保持未验证。

## 6. 狄金斯：光源驱动的克制

**默认维度：**灯光与构图；本卡本身不提供改变摄影机或色板的理由。

**范围／证据：**[Team Deakins 第4集](https://www.rogerdeakins.com/episode-4/)仅公开节目简介支持实景灯、灯具位置与房间环境这一主题。保留2026-09-08研究范围与未审听音频的限制；未核对具体作品或完整证言，不能以此给狄金斯生涯绑定视觉套餐、参数或引语。

**项目转化：**围绕已批准实景灯或环境光组织画面，保护关键脸部、轮廓或物件线索。允许背景局部退后，而不是每个物件单独补光。源光使用、人物朝向、背景明度只能在允许职责内调整；这是一项光源驱动的候选，不是节目已证明的最佳方案。

**可调项：**光源存在感；面部／轮廓强调；背景分离；暗部可读量。克制不等于全局曝光很暗。

**适用／取舍：**适合已有光源能组织必要信息的场景。少补光可能损失面部／物件可读性；必需信息与锁定光源冲突时指出条件或比较允许的机位、朝向、覆盖，不能暗加灯。不强制轮廓光、青橙调色或肤色重染；明确批准的风格化用光不是该卡的失败，克制也不等于曝光很暗。

**控制／验收：**写明现有源光怎样到达人物／物件和允许调整的职责，继承共同光色。检查目标线索是否仍可读、遮挡或转身后是否失效；未确认光源几何时不宣称灯一定照得到。纯生成的亮暗外观不是曝光／动态范围测量，播客简介不是本项目实测。

## 7. 马特尔：声音空间与悬置注意力

**默认维度：**声音与节奏，构图可选。

**范围／证据：**[BFI《扎马》（2017）本人访谈](https://www.bfi.org.uk/interviews/lucrecia-martel-time-zama)，2018-05-24，讨论三种时间与声音空间；[BOMB 本人访谈](https://bombmagazine.org/articles/2009/01/01/lucrecia-martel/)，2009-01-01，涉及《沼泽》《圣女》《无头的女人》等早期家庭作品。继承2026-10-10已读正文，未审看影片；具体三种时间的练习展开见[学习记录](film-craft-study.md#比较练习候选)。

**项目转化：**分开放映时长、叙事经过与观众发现细节所需时间。建立听觉主层，让画外声音提示未见关系；视觉注意对象与听觉优先对象可有意不同，不急于揭示来源。区分环境声音和主观联想，持续观察中设计可发现的细节，而不是自动加入转折。

**可调项：**已知／未知声音方位；前后景优先级；揭示／继续隐藏；倾听区间长度。

**适用／取舍：**适合画外关系、主观聆听或持续观察。听觉与画面分层可能暂时削弱来源定位，延后发现也需要足够可读细节。硬要求立即交代来源、无声媒介或静图时关闭对应声音机制；不编造对白、威胁或心理诊断。降低事件数不等于一律拉长镜头，更不是国别慢节奏处方。

**控制／验收：**分别记录画面活动、声音来源／方位是否已知、听觉主层、揭示时刻和采用时长。依实际声音与剪辑能力实现，静图标为部分应用。检查声音使观众新增推断了什么、是否误示来源或同时性、关键声是否被遮蔽；有声与静音比较只在实际素材可访问后进行。

## 8. 瓦尔达：散文式观察

**默认维度：**构图、调度、节奏；简报和媒介支持联想听觉时再考虑声音。

**范围／证据：**[Criterion 本人访谈](https://www.criterion.com/current/posts/4488-i-m-still-here-a-conversation-with-agnes-varda)，2017-04-05，涉及摄影、影片与晚期装置；[Janus《阿涅斯论瓦尔达》访谈资料](https://s3.amazonaws.com/criterion-production/janus_promo_packages/347-/Varda-by-Agnes_press-notes_r2%20%282%29_original.pdf)访谈录于2019-01-31、首次刊于2019-02-10。[BFI混合访谈与评论](https://www.bfi.org.uk/sight-and-sound/interviews/home-away-with-agnes-varda)原发2011-02-11、更新2019-03-29，分别保留本人答语与作者解释。继承2026-10-10已读正文／指定PDF段落，未观看影片。

**项目转化：**关注人物日常活动与物件／地点，明确谁选择并提供视点。用事实、联想、并置或构造关系连接两次观察，说明关系来自给定材料还是原创提案；不强造戏剧对抗。声音、评论或旁白只有在简报授权与媒介支持时采用。

**可调项：**人物／物体强调；观察时长；直接／联想连接；观察距离。新增评论或旁白者需故事／用户批准。

**适用／取舍：**适合个人观察、日常材料与开放联想。并置可能降低单线剧情推进，也可能让观众误认时空因果；必须明确解释因果或锁定连续行动时，缩小或关闭联想层。不改写锁定故事，不伪造纪录相遇，不从主体在场推断同意。规划／构造与观察共存是反例，随意外观不证明没有准备。

**控制／验收：**保留两次观察的来源、摆拍／真实观察类别和拟议连接，声画关系依实际时间／声音支持。检查观众为何把两段放在一起，是否把构造误认成纪录事实，是否无依据新增评论者。图片能检查并置构图，不能证明观察过程、声音联想或拍摄许可。

## 交接与示例

名字留在选择／来源记录中。将**选中的机制**而不是“由某某拍摄”编入既有产物：表现／色板归风格；演员行为归人物；光源变化归场景提案；调度／构图／摄影机／镜头光归导演；序列时序归分镜／节奏；声音／剪辑意图进入支持的时间／剪辑字段。规范 JSON 输出前阅读实际 schema。

表现／色板继承共享风格权威，不从手法卡合成新视觉。只有明确要求修改视觉时才能提出变更。相邻镜头即使创作影响不同，也保留相同视觉依据。

模式的归属／目标枚举无法表达所选交接时，不强塞进 `CinematicSkillManifest`，改用中文可读草稿或正确归属的 `WorkflowPlan`。卡片不是精确清单绑定，不造 ID、哈希、回执伪装编译。

**示例请求：**“门厅里三名接待员整齐站着，中间的人一本正经地把钥匙递错了，气氛有点荒诞。已有正面通道和桌旁台灯，人物走位、服装和房间不改，帮我设计这个镜头。”

**预期适配：**秩序和冷幽默可支持安德森／耶曼的正面构图；已有台灯若能照到钥匙，可支持狄金斯卡的源光方法。无需询问开关。保留位置、色彩事实和光源摆放，不加灯、不假定灯一定照得到钥匙。光照关系未知就标记待检查，同时继续交付有用构图。理由可写：“用正面秩序衬托递错钥匙的动作，光线优先保证钥匙和接手关系可读。”其他一致方案也可满足简报，组合只是示例，不是必须的分类结果。

## 行为检查

以下是人工评测案例，不是已经通过的自动测试。检查实际选择，不做字面匹配：

1. “观众先发现跟随者，人物最后才确认，不回头，设计8秒镜头。”应提供披露／调度方案，不问预设强度，保留认知顺序和动作锁。
2. “两人都想挽留，却只谈归还雨伞，拍得含蓄。”潜台词变成可表演交流与克制展示，不自动加雨、霓虹或婚外情。
3. “三名接待员整齐站着，有人递错钥匙，已有台灯，布局固定。”按维度形成一致方案，保留源光未知，不强制名导组合或新灯。
4. “无文字静态海报，表现等待，不用声音。”只采用能实现的视觉选择，不强制时间／声音机制，不编造声音结果。
5. “更电影感，但不改构图和运镜。”不凭形容词分类或修改锁定维度；保守的其他维度提案或无匹配均有效。
6. “原样翻译锁定镜头提示词为英文。”保留语义，精确变换不触发创意适配。
7. “只改构图，不要大师风格，不改服装、走位、光源。”只给中性构图，显式排除优先。
8. “必须固定正面，又必须持续跟到背面。”指出显式摄影机约束冲突，不默选。
9. “上镜固定机位已锁定，下镜继续等车，不增剧情。”继承语法，不强造名导、威胁或戏剧运镜。
10. “只列预设；说明撤销旧风格后如何保留后改机位。”仅浏览／解释；保留显式修改，承认缺失基线，不改产物或猜历史。
11. “同一场戏先悬念、再群像、后含蓄告别，统一视觉。”手法随功能变化，色板、颗粒、反差、画幅不随名导切换。
12. “没有视觉设定，设计三个连贯镜头，技巧可混用。”只提一份共享暂定视觉并复用；不造批准／引用，不发预设问卷，不做三套无关视觉。
