
# 可选参考：肖像、自然人物与表面质感

用于肖像重建、近距离人物测试、妆发肤质连续性或真实表面响应。

详细创作稿遵循[细节与专业表达](prompt-detail-standard.md#人物)；此处专项规则与机制示例不能替代完整人物、场景和镜头描述。人物动作与视频变化转到[表演指导](video-performance-direction.md)。本页来源访问日期为 **2026-10-10**；摄影师的个人方法作为可比较选择，平台输入要求仍需按当前模式确认。

## 分层

- 稳定身份：脸部／身体几何、比例、自然不对称、基础皮肤特征。
- 当前外观：妆容、修饰、头发、服装、临时肤况、水润程度、污渍和伤情。
- 拍摄：视点、距离、焦点、曝光、推断焦距、传感器／渲染行为。
- 表现方式：写实程度、修图克制、线条／笔触／赛璐璐表现。
- 镜头：姿势、表情、构图、物理光照。

妆容或磨皮不能变成人物身份。不从不确定视觉线索推断族裔、健康、精确年龄、真实焦距或颜值。单张照片只支持当前角度和可见区域的观察；背面结构、侧脸、全身比例和跨角度身份稳定需要相应素材验证，不能以一张正面肖像宣布“全角度一致”。

## 先分清肖像任务

| 当前目的 | 优先保护 | 本次可变内容与判断依据 |
| --- | --- | --- |
| 中性身份资产 | 稳定几何、可见锚点、轮廓与自然不对称 | 用便于比较的视角、表情和照明；不拿妆造或美颜效果证明身份 |
| 演员定妆与角色肖像 | 身份、角色处境、已选外观 | 比较发型、妆容、服装和可表演任务；只改所选维度 |
| 写实剧情近景 | 角色在此刻做什么、看向谁、肌肤与光的响应 | 表情和造型随场次变化；“疲惫”“镇定”是创作意图，照片只证明可见表现 |
| 风格化人物 | 身份关系、媒介的形体与色彩逻辑 | 水彩、插画、动画或游戏角色按媒介简化；不强制加入摄影毛孔和镜头噪点 |
| 表演追踪输入 | 五官可读、稳定曝光、追踪所需范围 | 按采集工具减少阴影和遮挡；录制照明不自动迁移为成片照明 |

摄影师 Peter Hurley 的原作者教学把表情指导作为人像工作的重要环节。本项目采用“给对象明确的小任务、比较实际表情”这一方法，不将他的招牌背景、眯眼或商业肖像取向规定为所有人物的标准。[原作者说明](https://peterhurley.com/blog/art-behind-headshot)

在原创肖像里，可给“刚听完画外同伴说话，仍在看着对方”之类的关系；中性身份测试则保持中性。真人拍摄说明先给任务与视线目标，允许演员自然回应；AIGC 静帧只选择这一回应中的一个可见瞬间。不能从眼神、微笑或姿势证明真人性格与内心。

## 细节预算

- 特写：身份关系、眼唇表面、毛孔或符合媒介的微纹理、妆容边界、发际线、材质与光的过渡。
- 中景：脸部锚点、发型体量、领口、服装结构、手部互动。
- 全身：轮廓、比例、姿势、服装层次、鞋履和接触。
- 远景：轮廓、色块、步态及场景关系；省略看不见的毛孔细节。

## 表面语言

描述四项可观察内容：

1. **光源：**哪一物理光源照到该表面。
2. **反射：**宽泛、镜面、柔和或各向异性响应。
3. **形体：**这些响应如何显出几何结构。
4. **接触：**互动位置的遮挡、压缩、湿润、灰尘或阴影。

自然人物表现保留合理的不对称、变化和材质差异。避免全局模糊、塑料光泽、夸张毛孔、美颜滤镜措辞，以及相互矛盾的硬光／柔光描述。

## 肤质、妆造和光线分别落地

皮肤真实感来自形体、局部色泽、表面与光的一致响应。它不等于瑕疵越多越好，也不等于每处都同样锐利。可在不改变身份的范围内做适度、协调的理想化；不同性别、年龄或体型均按角色需要处理，不套用一种瘦高比例或一种“完美脸”。

- **皮肤基线：**依据可见素材或明确的原创设计，保留额头、鼻翼、颊部与唇周不同的纹理尺度及色泽；不要把毛孔复制成均匀图案，或为“真人感”擅自新增雀斑、疤痕、晒伤和老化。
- **当前妆造：**明确底妆覆盖程度、哑光或局部光泽、眼线与唇部边界、胡须和发际线；完整妆容同样可以真实。湿润眼球、干燥皮肤、粉底、唇膏和金属耳饰应有不同反射，不用一个全身油亮材质统包。
- **照明：**写明方向、相对光源大小、阴影边界、填充和反光来源。柔光可以保留微纹理；硬光可以显出起伏，但不自动等于高质量。Profoto 对伞面、尺寸和扩散的说明显示，柔和过渡与较强镜面反射是不同选择；借用其可见光质差异，不要求写品牌或设备清单。[光质与修饰器](https://www.profoto.com/pl/en/still-photography/tips-tricks/whats-the-difference-between-profoto-umbrellas/)
- **曝光与清晰度：**眼睛、肤色和需要读取的妆容保留层次；亮部是否溢出由画面目的决定。焦点和景深应保护本镜的身份与表演信息，不把双眼、耳朵、背景和每个毛孔同时要求极锐。后期锐化、颗粒或放大不能补回原本错误的结构。
- **接触与天气：**托脸处有轻微挤压与接触阴影；发丝压住耳廓；领口随姿势折叠。泪、汗、雨与伤情只在故事或外观状态需要时出现，检查附着位置与相邻镜头接续。

## 可直接使用的原创静帧示例

此例是虚构角色设计，没有真人身份参考；展示一个单一瞬间，不声称已经生成或检验。

```text
16:9 横向写实剧情肖像。安静的书籍修复工作室，一名约四十岁的成年男性修复师坐在旧木工作台后，上半身近景，摄影机位于他的眼睛高度，三分之四侧面取景，保留头顶、双肩与桌边一只手。脸形略长，下颌线自然，鼻梁平直，左右眉峰有轻微差异，短黑发中有少量灰发，修整整齐的短胡须。他穿深灰棉麻工作衬衫，袖口卷至前臂，没有额外首饰；妆容克制，仅均匀修饰肤色，颊部保留细微纹理和局部暖色，鼻翼与唇周表面不过分磨平，胡须、嘴唇和皮肤各有不同质感。
他刚听完摄影机右侧同伴的一句话，视线停在画外对方的眼睛位置，眉间放松，嘴唇自然闭合，一侧嘴角有很轻的回应，肩膀略朝向对方。右手安稳放在桌边，指腹与木面有清楚接触，手腕不悬空。画面左侧大窗透入柔和日光，鼻侧和脸颊形成有方向的柔软阴影，画面右侧由浅色墙面提供较弱反光；眼球有与窗位置一致的明亮反射，皮肤亮部有层次，衬衫保留细小织纹和自然折痕。焦点落在近侧眼睛与邻近面部，远侧眼睛仍足以读取表情，背景书架适度失焦，可见书脊与修复材料的轮廓。整体色彩自然克制，保留舒适的肤色与木色关系，肤质有局部差异，人物结构与手指清楚可信。
```

## 评审与局部修复

实际图像到位后，分别检查身份、表情、肤质、妆造、照明和接触。原尺寸看纹理与边缘，成片展示尺寸看注意力与人物是否可信；放大预览本身不证明真实细节。

| 可见失败 | 优先区分的原因 | 有界修改与复查 |
| --- | --- | --- |
| 面部像蜡或塑料 | 全局磨皮、反射过于一致、曝光或低对比丢层次 | 先修局部表面或照明中的一个变量；保护原几何、构图和表情 |
| 满脸砂纸纹或重复毛孔 | 过量纹理词、锐化、纹理尺度与景别不匹配 | 降低不适合当前景别的纹理，检查颊部、鼻翼与唇周是否恢复差异 |
| 换侧面后不像同一个人 | 原参考没有该角度、几何变化、照明遮住锚点 | 先补角度证据或比较已有资产；不为解释失败而修改正确身份 |
| 表情僵硬或像宣传照 | 没有对象与任务、固定姿势与笑容不符场次 | 调整这一瞬间的视线目标或表情强度，其他外观保持已选版本 |
| 涂抹感或亮边 | 修图／放大／合成边界、曝光与材质不匹配 | 在原片和处理后图中定位差异，修局部区域，再检查眼睫、发际与唇缘 |

一张通过的肖像只证明这张图的所检维度。其他角度、连续帧、口型与身份接续要用相应素材单独评审；提示词、计划、脚本检查和供应商示例均不能替代本项目的出图证据。
