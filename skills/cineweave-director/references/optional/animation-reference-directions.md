# 可选参考：动漫作品方向

从[影视参考库入口](film-television-reference-library.md)选择表现体系后读取。动漫与真人12类分组独立，下面4类按主要表现规则区分，不能把卡数称为真人题材数。作品只提供研究候选；本次已读的作品资料与未看片限制见[证据记录](film-television-reference-library.md#文字来源与证据限度)。以下视觉与时间规则均为项目的迁移提案，不宣称已逐帧确认制作流程。

目录：[二维日常](#anim-2d-everyday) · [二维幻想空间](#anim-2d-fantasy) · [水墨线描](#anim-ink-line) · [三维东方幻想](#anim-3d-eastern-fantasy)。

共同边界：先按[风格路由](../routes/style.md)明确造型、边缘、材质、色光与时间表现，再从选定作品寻找有证据的机制。时代、人物身份、世界地理和故事不能由表现体系改写。动画不自动等于低帧率、幼态人物或夸张动作；静图不能证明运动中的线条与纹理稳定。真人自然摄影默认不反向覆盖动画卡。

## anim-2d-everyday

**题材与时代：**二维生活、学习与成长；时代和地域单独锁定，日本作品的街道、校服和家庭物件不自动迁到中国故事。

**参考作品与范围：**《侧耳倾听》作为日常空间与人物成长的研究入口；官方作品资料支持作品身份，不代替本次尚未进行的镜头采样。

**美术与造型：**以可读轮廓、有限的面部细节和有使用逻辑的房间组织生活；道具简化不删掉关键接触点，背景细节与景别匹配，表情保持角色锚点。

**光线与色彩：**用稳定的色块和有方向的明暗分区提案，天气与时段仍连续；不自动加真人毛孔、摄影噪点或一律发光的天空。

**服装妆造：**以线条和大色块解释衣服结构，褶皱服务体块与动作；领口、袖口和身份配件跨镜稳定，不照搬参考主角服装。

**情绪与用途：**含蓄、好奇、努力与共同生活；适合递物、收拾书桌、走过熟悉街道。动作幅度与节拍由当前人物任务决定。

**禁用与验收：**不默认幼态脸、复制角色或统一怀旧滤镜；检查表情转换、手物接触、轮廓和服装色块跨帧稳定。未有视频时只验静态设计，时间表现保持未验证。

## anim-2d-fantasy

**题材与时代：**二维幻想中的空间探索与尺度变化；幻想时代另定，不把东亚传统建筑视作单一朝代样本。

**参考作品与范围：**《千与千寻》作幻想环境候选，《借东西的小人阿莉埃蒂》作尺度关系候选；分别采样需要的维度，不平均拼成同一世界、角色比例或色板。

**美术与造型：**先画清通路、门口、楼层或微缩物件尺度，再安排发现；重复的尺寸锚点使幻想可理解。保留既有拓扑，不以梦境为由让空间随镜漂移。

**光线与色彩：**现实空间光向与幻想表现响应分开决定；允许明确的表现性明暗，但关键脸、手与路径仍可读。发光物存在与否由世界规则批准。

**服装妆造：**轮廓和身份配件适合相应尺度，布料简化与人物体块一致；不把参考角色的脸、发型或标志衣服当表现方式。

**情绪与用途：**发现、陌生、谨慎与亲近；适合穿过新空间、跨越尺度障碍、在巨大日用品旁完成任务，不自动新增怪物或惊吓。

**禁用与验收：**不强制宏大奇观、任意变形或无限移动镜头；检查尺度锚点、进出路径和接触是否连续。图像只能说明布局提案，不能证明完整探险镜头成立。

## anim-ink-line

**题材与时代：**水墨、线描与纸面留白的二维叙事；可以用于东方幻想或生活题材，不等同某个朝代或固定神话。

**参考作品与范围：**《辉夜姬物语》为线描、笔触与空间留白的研究候选；具体哪一段如何更新笔触需实际片段，不由官方作品页推断制作参数。

**美术与造型：**提出体块、动势线和有限细节预算；留白不删空间锚点，失边不遮关键接触，墨色密度与动作信息分工。

**光线与色彩：**明暗可由笔触／墨块简化表达；物理源光仍继承场景，表现性省略不能暗改世界。色板先定一份，不与真人高光、摄影焦外自动混合。

**服装妆造：**以领袖结构、轮廓与少量褶皱保留服装身份，纹样按景别分配；时代不明不声称复原和服／汉服。

**情绪与用途：**轻盈、安静、焦急或情绪突变；适合人物姿态与留白承载的关系。笔触变化需明确触发，静止处不靠随机噪声制造手绘感。

**禁用与验收：**不把画面闪烁、五官漂移或纹理游动当艺术性；检查轮廓、笔触附着与接触点，明确有意保持画格与失控跳动的区别。静帧合格不宣布时间稳定。

## anim-3d-eastern-fantasy

**题材与时代：**三维体块与东方幻想；真实朝代、虚构世界和神话改写分开，未给定就保持架空。

**参考作品与范围：**《白蛇：缘起》为三维东方幻想作品入口；基础资料仅支持作品身份与题材，具体布料、皮肤或特效技术待制作证言／媒体。

**美术与造型：**建立一致的人体比例、体块简化、山石建筑与道具尺度；三维空间服务角色行动，不靠无限细节、软件名或渲染器词汇作美术方案。

**光线与色彩：**分别决定皮肤、织物、金属等表面响应与世界源光，控制高光滚降和明暗可读性；保持一套共同色彩，不把真人毛孔与卡通体块平均混合。

**服装妆造：**衣层有重量与活动余量，发束体积、配饰和身份锚点在转身中稳定；不得继承参考角色身份或在近景无故增加真人级皮肤细节。

**情绪与用途：**亲近、疏离、发现与行动抉择；适合幻想环境中的人物相处、飞行前后有规则的身体状态和具体物件交接。

**禁用与验收：**不默认塑料皮肤、发光边缘、巨大发饰和满屏魔法；检查体块转面、布料穿插、头发／饰物稳定及动作空间。有明确授权的神力单独按世界与动作规则处理，不因“自然”静默删除。
