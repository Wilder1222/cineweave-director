# 可选参考：旁白序列与说明片交接

将主题／文档转视频、制作画外音说明片、插画叙事或旁白驱动序列时加载。本指南补充讲述内容与画面的对应关系；完整短片沿用[全套流程](short-film-creation.md)及适用的逐镜评审。只要剧本便止于剧本，不自动制作音频、渲染片段、选择供应商或装配视频。

## 解决会改变方案的选择

先阅读给定主题或文档，提取受众、知识背景、目的、时长、旁白语言、表现媒介、画幅、字幕与已有讲述者／固定角色选择。在授权范围内补充可撤销草稿，不强制预设目录或分轮访谈；声音或身份选择确实影响交付时才询问。

事实性内容保留来源、日期、不确定性及事实／解释区别，及时核实需要当前证据的声明。无法研究时给出范围明确、保留待核项的草稿，不编造来源。个人经历依据用户给定事实，新增虚构另行说明，不推测私生活。

结构服从意图：

- **说明：**问题 → 有用机制或例子 → 后果 → 回答。
- **步骤：**目的 → 前提 → 可观察步骤 → 结果与检查。
- **个人／戏剧叙事：**保留给定经历和因果转折。
- **沉思／联想：**发展感知或主题关系，不强加冲突与销售开头。

## 先建立对应，再润色提示词

用稳定的局部节拍、旁白与镜号标签，不冒充正式资产或平台任务 ID。简表即可：

```text
节拍 | 声明／来源或故事作用 | 准确／拟议旁白 | 可见证据或隐喻 | 镜号 | 时间 | 声音／文案要求
```

每拍应增加理解或所需情绪变化。分清视觉演示、情境插画与隐喻；插画不能冒充事件实拍或数值证据。避免漂亮但无关的画面持续铺在旁白下。

一个语义节拍不必对应一个镜头或一个音频文件。旁白可以跨切点，一幅图解可以承载多句解释，也可整镜无旁白。镜长由理解、动作和节奏决定；只有用户或已核实流程要求时才使用固定块长，不将供应商的十秒分块或英文字数限制推广到所有语言。

旁白文本与表演说明、视觉指导、声音事件和准确画面文字分别列出。用户锁定措辞原样保留；拟议口播可以将数字写成适合朗读的形式，但不得暗改准确引文、字幕或给定文本。

## 统一表现，独立管理身份

继承[视觉基线](../core/visual-bible-and-continuity.md)。新风格明确媒介、色彩作用、边缘／表面、纵深与运动规则，不暗示参考图或正式风格包已存在。

风格样张可验证规则，无需凭空增加人物、产品、标志或地点。用户需要固定吉祥物时，身份和外观独立于风格参考；风格来源只控制授权维度。动态一致性还需时间规则，静帧一致不证明动画稳定。

每镜明确目的、初态、可读变化、终态、主体／摄影机／环境运动、继承规则及失败检查。保持镜头可以成立。以目标尾帧设计揭示时仍需核实能力、检查真实返回；锚点不保证精确落帧。

## 时间、旁白与声音

按所选语言、表达和停顿估计旁白时间，说明依据；字数不是实际语音长度。有录音后，使用实测时间再确定最终同步。超时可缩短未锁定措辞、调整画面窗口或换录音，不暗自加速声音或拉伸素材。

根据依赖选择外部制作顺序：

- **声音主导：**确定所需文案成熟度，取得外部录音时间，再定画面窗口。
- **画面主导：**保留已定画面事件，将拟议旁白安排在其中。
- **文字与总时长均锁定：**明确冲突，可行草稿不授权修改任一硬条件。

这些是交接依赖，不是启动任务的指令。独立资产可以并行规划，连续生成的可行性需要真实继承边界。

保持指定讲述者的表演意图一致，分开画外旁白、画内台词与口型要求。外部配音时，片段内的音乐与环境声不能带入意外第二讲述者。明确声源位置、语音优先级、停顿和声音桥，不统一禁止对白或写实表现。声线与录音稿沿用[声音工作表](video-sound-and-delivery.md)。

## 对应关系与交付检查

交接多资产序列前，核对：

1. 请求的每拍有明确作用和相应画面或有意保持，事实声明保留来源状态。
2. 每段旁白对应其覆盖的全部镜头窗口，包括跨切点；无旁白镜头可以成立。
3. 每个返回槽位说明源稿版本、候选、时间、用途和验收项，不猜测 URL 或任务 ID。
4. 字幕单独安排准确文本与时间，一句旁白可拆成多个可读字幕。
5. 时间线、声音、字幕和规格对应完整交付；片段集合不能冒充成片，明确仍需外部装配。

硬切算术可用[只读交付检查器](../../scripts/check-delivery.mjs)，输入详见[视频与声音指南](video-sound-and-delivery.md)。可选 `narration` 单轨只检查声明的旁白与镜头对应，不读取媒体。例如为完整工作表添加：

```json
{
  "narration": [
    {
      "id": "N1",
      "startFrame": 48,
      "endFrame": 168,
      "text": "远景与细节里，都能看见同一道修补缝线。",
      "shotIds": ["S1", "S2"]
    }
  ]
}
```

假设 S1 为 `[0,96)`，S2 为 `[96,192)`，这段旁白跨越切点。上例只是扩展片段，不是完整输入。`narration` 可省略，空数组表示无旁白；各段按顺序、不重叠，ID 在整个工作表唯一，`shotIds` 按时间顺序精确列出全部相交镜头。仅接触边界不算相交。时窗与文本是规划声明，通过不证明真实时长、可听性或视听效果。

## 返回、恢复与评审

将真实返回文件与预期槽位、版本对齐。候选映射不明确时不能称为完成。缺失、失败、等待中分别记录；超时本身不证明外部任务失败，也不授权自动重复请求。

逐项与整片分别检查语音可懂度、声明与画面对应、身份与风格、剪接边界、字幕和格式。关键动作／时序检查相邻镜头，合格静帧集合不能证明序列合格。完整场次继续执行[逐镜评审](ensemble-direction-and-review.md)，对应表不能替代其他适用视角。

只修正失败维度及实际消费者。旁白改词需要时间与字幕复核；语义和窗口仍匹配时，画面可能保持有效。仅画面修正无需重录已通过旁白。保留通过版本，按[变更影响](drafts-and-change-impact.md)处理依赖。

## 24 秒规划示例

原创虚构情节：信使归还遗落雨伞。用户授权调度，不要人物对白，采用一名画外讲述者。

| 窗口 | 画面作用 | 旁白／声音关系 |
| --- | --- | --- |
| 0–6 秒 | 建立站台与长椅上遗落的雨伞 | 先听环境，观众看清后再入旁白 |
| 6–14 秒 | 信使通过尚未关门的车厢窗口认出失主 | 同一句可跨切点，认出过程清楚，不虚构口型 |
| 14–24 秒 | 失主接回雨伞，信使退回站台 | 新一句完成叙事，随后留出无旁白反应 |

时长是合计 24 秒的可修改草稿，不是实测媒体。请求完整旁白时须提供实际逐句文本，不能把这张示意表称为完整配音稿或影片。
