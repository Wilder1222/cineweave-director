# 可选参考：色彩与影调风格预设

35张色彩卡、25张真人妆容卡和8张动画人物画法卡，共78个高清参考文件；色彩与人物分开。实拍只收合格剧照；动漫场景按用户要求只选官方海报／主视觉或来源可核对的具名代表场面，海报只作美术配色参考，不证明正片调色。没有合格图片的模块不进入当前目录。均为原创设计意图，不是官方LUT、软件节点文件或已验证媒体。按视觉风格名及CG ID调用；[参考来源](style-still-references.md)逐图记载来源、尺寸与用途。

## 选择与交付

每张卡正文的“卡片修订”是当前配方版本来源；无显式旧版本的既有卡本次补录为 r1，规则语义不变。目录名称修订不改变配方版本；不得从同号 MU、样例或文件日期猜测 CG 修订。

命名采用“视觉母题／色彩气质·呈现特征”，例如“宋韵清雅·古偶柔光”。默认目录、卡片标题、推荐和复制稿不以剧名领头；研究作品放在来源记录，用户以旧名或作品名检索时返回当前风格名与稳定 ID。题材词是检索语境，不授权更改角色、时代或场景。

本页是整体风格库的**色彩与影调模块**。风格组合还可分别引用妆容、肤面、发型服装、灯光和成像规则；如何组合见[风格组合与妆容](visual-development.md#风格组合与妆容)。名称中的“柔光”描述期望的成像关系，单选调色不会自动换妆、布光或制造柔光。

全部卡采用[风格卡与组合记录](visual-development.md#统一风格卡与组合记录)，作品名只用于来源和检索。真人妆容与动画人物画法独立选用；CG13、CG35仅提供有图支持的色彩模块，不附加空人物卡。只调色保持人物原外观及表现体系。

先识别用户要的体验、现有光源／材料和硬锁，再选择一个共同基线；明确点名预设时直接在相容范围采用。已有合格基线则继承，不因构图或导演手法变化自动换调色。各卡只能在列明范围调整，不能把多个整套预设平均或逐镜轮换。用户只要浏览时只展示，不改项目。

每次应用交付：选中卡 ID 与修订、适用场次、受保护事实、实际调色意图卡、配色卡、昼夜／场景变体、完整颜色段和对照测试。可用强弱语言表达程度，不编造“原片强度 70%”。用户只说“电影感”时按简报给一个有理由的草稿，无相容卡时使用中性基线，不强迫选择名单。

## CG01 矿物沙金·旷野史诗

**卡片修订：**1。

**来源依据：**S01 支持前期测试、色彩与胶片纹理分工及按项目区别处理；以下沙金关系为原创设计，不声称原片每个星球共用一种色调。

- **配色角色：**主色砂岩 `#B69B73`；辅色岩褐 `#6E6255`；强调色旧铜 `#9A6544`；亮中性骨白 `#DDD4C2`；暗中性炭灰 `#292C2D`。优先绑定现有石、布、金属，不为填色增加沙漠或改服装。
- **明暗／色彩：**中间调扎实，明亮漫反射保留起伏；高光柔和收束，阴影保持中性或随环境略冷；低至中等综合色度，局部暖材质仍能辨色。避免用压黑制造体量。
- **肤色／材质／纹理：**脸部随源光保留肤色差异；石与皮肤不能同成橙块。哑光布、砂石、金属反光分别保留；细颗粒可选，默认不附加光晕或失焦。
- **变体／调节：**日外主要调亮部收束与材质分离；夜景沿用材料色，暖色只在现有暖光覆盖区。可减弱暖中间调、调整环境色度，不能把日夜做成同曝光。
- **禁用／验收：**鲜艳品牌色必须准确时限制色相压缩；不可新增沙尘。检查亮墙／沙地层次、深色服装折痕、肤色和铜色分离；关闭颗粒后调色仍须成立。

**中文颜色段：**整体采用克制的矿物色关系，砂岩与灰褐环境形成宽阔色块，亮面保留细微材质起伏，高光柔和收束；阴影依实际环境光保留中性或轻冷层次。人物肤色与环境暖色分离，深色衣料不压成死黑，局部铜色仅来自已有材质与光源。

## CG02 暗域暖点·都市冷峻

**卡片修订：**1。

**来源依据：**S01、S02；Cole／Fraser 的实际处理保留暗部与局部色彩，不以全局强反差去饱和作为统一处方。

- **配色角色：**主色墨灰 `#202526`；辅色烟褐 `#554A40`；强调色琥珀 `#BE743D`；亮中性灰米 `#B6B0A3`；冷辅助深青 `#3E5658`。暖点需有现有灯或反射依据。
- **明暗／色彩：**整体低调但延长暗部可辨层次，中间调按主次分离；灯芯可亮，邻近亮面渐进收束。综合色彩克制，保留叙事所需红、琥珀或其他局部色，不一律去饱和。
- **肤色／材质／纹理：**面部暗侧仍有体积，不统一变青；区分黑布、皮革与金属。湿反射仅在已设为湿的表面出现；光晕为独立可选光学意图，不借调色生成雨或雾。
- **变体／调节：**夜外以实际暖灯为锚，日内保持同样暗部层次但撤去无来源琥珀。优先调黑位弯曲与局部亮度，再决定环境色偏；禁止一键压低全部曝光。
- **禁用／验收：**明亮清透的既定基线不适用；检查黑发／衣领／背景三者、眼神与关键道具、灯光颜色和相邻反打。暗部信息消失即退回强度。

**中文颜色段：**保持低调的墨灰与烟褐环境，暗部仍能分辨衣料、面部转折和关键物件；已有暖灯形成有限的琥珀亮点，亮点周围平滑收束。保留必要的局部鲜明色彩，肤色随实际光源变化，避免全画面泛青、统一去色和大片死黑。

## CG03 粉彩秩序·复古绘景

**卡片修订：**2。**来源依据：**S03；彩色小镇与黑白舞台分开设计。本卡只研究彩色部分；人物黑白近景不用于色彩取样。

- **配色角色：**主色沙粉 `#D6AB91`；辅色浅青 `#74B5B0`；亮色奶油 `#E6DCB9`；局部珊瑚 `#BD705D`；暗色灰褐 `#63594E`。均为原创显示示意，依附现有材料。
- **明暗／色彩：**明亮中间调与清楚色块边界，保留午后或高位日光原有阴影；亮面柔和收束不等于全场柔光。浅青、沙粉不污染全部白衣或脸。
- **肤色／材质／纹理：**皮肤、粉墙、青绿漆面和纸张分别可辨；不把演员脸变成粉色，不默认美颜。
- **变体／调节：**日外保持已有光向；暮色降低环境明度但仍辨色；黑白叙事须另立灰阶方案，不能把彩色卡平均到黑白片段。
- **禁用／验收：**检查浅青与天空、沙粉与肤色、奶油白亮部。对称构图、荒漠、道具和复古服装不由调色新增。

**中文颜色段：**将既有沙粉、浅青和奶油白材料组织为清楚而柔和的色块，局部珊瑚作为已有物件的重音。中间调明亮，受光面保留材质，阴影遵循现场方向；人物肤色与粉墙、青色环境保持差别，不统一罩粉或青，不靠模糊和漂白制造复古感。

## CG04 湿润蓝绿·亲密夜色

**卡片修订：**1。

**来源依据：**S04；章节 Look 服务人物感知，绿蓝增强有具体叙事范围。这里不照搬三章结构或指定某种肤色。

- **配色角色：**主色海蓝 `#3D747F`；辅色叶绿 `#56806A`；强调色珊瑚 `#C67B66`；亮中性贝白 `#DFDFCF`；暗中性深蓝灰 `#23363E`。环境、衣物与点缀各有归属，肤色不绑定 HEX。
- **明暗／色彩：**中等至鲜明色彩，保持蓝绿间色相距离；中间调有厚度，高光保留湿润反射但不削平皮肤纹理；暗部富有层次，不整体升黑漂灰。
- **肤色／材质／纹理：**保护不同深浅肤色的明度关系、底色和允许的源光染色；不把深色皮肤提灰或硬拉向统一肤色线。皮肤光泽必须来自已设表面，不能自动涂油；水／叶／皮肤分离。
- **变体／调节：**日外提高环境蓝绿色度前先保护人脸；夜景按真实蓝色环境光建立分离，暖室内仍继承色彩厚度。可改环境色彩密度，不把全场冷暖拉成极端青橙。
- **禁用／验收：**无蓝绿环境时不制造水或植物；检查脸部底色、局部光泽、唇色、蓝绿边界与镜间色彩跳变。颜色已剪切的素材先降低处理力度。

**中文颜色段：**现有环境中的蓝与绿保持鲜明而彼此分离，中间调饱满，亮部细腻过渡。人物保留自身肤色深浅、底色与受光侧差异，允许的表面光泽清晰可见；不把皮肤提灰或统一染青，不靠全局饱和度制造环境色。

## CG05 墨色层染·东方写意

**卡片修订：**2。**来源依据：**S05；张艺谋与赵小丁的作品及造型／美术资格已核实，近单色外观来自剧照观察，非已获取后期配方。

- **配色角色：**墨灰 `#25292A`、石灰 `#7F8583`、绢白 `#D5D6CF`、湿青灰 `#56625F`、浅肤褐 `#AD9E91`，不是影片测量值。
- **明暗／色彩：**低综合色度，以灰阶与少量材料冷暖分开空间；近单色保留皮肤细微底色，不一键把所有材质变为同灰。
- **肤色／材质／纹理：**布、竹、石、漆面保留反光差别；皮肤不做石膏白；雨水只在现有湿表面反射。
- **变体／调节：**日外保留雾中远近层次，室内保留窗光与暗木；允许少量已存在妆色，不默认鲜红强调色。
- **禁用／验收：**不能因名称加雨、伞、竹林、血迹或水墨裂纹；检查脸、白衣和灰墙不粘连。

**中文颜色段：**采用克制的墨色层染，让墨灰、石灰与绢白材料通过明度、纹理和少量冷暖区别形成空间。人物肤色只适度收敛色度，仍与布石材料分离；保留窗光方向、暗部表情和亮面细节，不统一漂白，不新增血红点缀、雨雾或裂纹。

## CG07 柔阶年代·沉静叙事

## 调色意图卡与技术交接

调色意图卡至少写：工作 ID／修订、基线及选中预设、实际场次／镜号、明暗曲线意图、色相／色度关系、肤色保护、材质保护、纹理、允许变体、明确排除、输入与输出未知项、测试和证据状态。提示词复制稿展开实际颜色段，不只留 CG 编号；外部调色交接可附编号和完整意图。

可按以下职责交给外部调色人员，顺序不是所有软件通用节点树：

| 层 | 本库要求 | 不可混淆 |
| --- | --- | --- |
| 输入识别与归一化 | 记录准确素材、编码／色域／传递函数、全／限范围、是否已烘焙 Look；未知先记未知 | 网络成片或生成视频不能默认当相机 Log |
| 技术平衡与镜间匹配 | 先建立可比较曝光和白平衡，保留有动机的不同光源色 | 中性平衡不等于抹平所有环境光色 |
| 共同创意 Look | 选择一张卡，明确工作空间和作用范围 | sRGB 色块不直接喂给 ACES；不能叠加两个整套显示变换 |
| 局部修正 | 需要时分离皮肤、衣料和背景；记录选区与跟踪要求 | 局部处理不能伪称包含在普通 3D LUT 内 |
| 光学与时间纹理 | 颗粒、光晕、锐度、降噪分别考虑分辨率和运动 | 不借调色改变身份、物件、镜头几何或动作 |
| 输出与复核 | 核对准确输出目标与观看条件，分别检查 SDR／HDR；输出变换只按已知流程配置 | HDR 不是加亮滤镜；网页预览不证明交付色彩正确 |

需要规范 JSON 时，创意意图进入现有 `StylePackage` 的可用字段与原子规则；技术输入／显示交给 `ColorPipelineProfile`。该技术契约当前要求 `creativeLookPolicy.appliesCreativeLook: false`、空变换名称列表及 `ownerBoundary: style-intent-separate`，不要为保存 CG ID 擅改枚举或将其填作 OCIO 变换名。工作卡 ID 保留在人工交接记录；元数据不齐可先交工作稿。

## 最小有效验证

固定同一人物、服装、场景、机位和物理光；仅比较中性基线与选中 Look。需要强弱比较时每次只改变一个有意义维度。五类测试覆盖近景皮肤、空镜与白部、材料板、内外源光转换、正反打，动态素材另检颗粒、选区漂移和色彩闪烁。

| 判据 | 需要的证据 | 失败后的归属 |
| --- | --- | --- |
| 皮肤、妆色与物件颜色保护 | 同输入前后图及允许差异说明 | 色彩修正／参考绑定；不能重画脸解决 |
| 高光、黑位与色域 | 已知编码的真实素材、正确显示流程和示波器／画面联合检查 | 技术变换或调色强度；文字和 HEX 无法证实未裁切 |
| 材质与空间仍清楚 | 相关近景、空镜、材料测试图 | 材质／光源或局部对比，不能统加锐化 |
| 镜间／昼夜一致 | 同场主参考、反打、转换段的实际素材 | 共同基线与场景变体；不同机位不要求像素相同 |
| 运动稳定 | 实际片段和准确时间区间 | 跟踪、纹理或生成稳定性；单帧不能通过 |

没有媒体时只完成设计检查，保持视觉质量未验证。标准产物范围见[阶段清单](stage-deliverables.md)，六张卡与测试任务的实际文字样例见[LookDev 交付样例](lookdev-delivery-example.md)。
