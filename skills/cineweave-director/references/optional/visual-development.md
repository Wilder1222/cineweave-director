# 可选参考：视觉开发与资产收敛

用于人物、表演、服饰、场景与整体美术的探索、定稿和跨镜头复用。单条已明确的提示词直接完成；需要探索才给备选。具体维度由[细节与专业表达](prompt-detail-standard.md)维护，这里负责如何比较、选定并生成相互一致的资产稿。

## 从创意到可比较方案

先明确待解决的视觉问题及不变项。例如“同一角色，比较工作服的结构与行动便利性”，不能同时改脸、灯光、年龄和摄影机后宣称某种布料更适合。开放概念探索可以多维变化，但每个方向必须写清改变了什么、适合的叙事功能及代价。

用户委托完整设计时可提出一个主方案并完成全部所需稿件，探索页展示有用的替代即可；未获选择的替代不混入主方案。用户明确要先探索再选择时，完成可比较的具体候选，不擅自把偏好当作正式决定。两者都不要求先填写完整世界设定或机器契约。

每个方向给出：设计命题、固定项、变化项、完整可复制提示词、比较视图／条件、验收点和所需下一步。方向名称是检索标签，不能替代具体形制、材料、色彩、光照和表演。

## 人物与服化道探索

将稳定身份、当前外观、表演和拍摄条件分开。需要比脸时保持服装、表情、视点和照明一致；需要比服装时固定人物身份、姿态与可辨照明。不要把人脸多样性压缩为颜值排序，也不把同一发型或衣服当作身份一致的证据。

| 探索目标 | 设计方法与交付 |
| --- | --- |
| 身份 | 定义年龄段与面部／身体结构、比例、不对称和辨识锚点；给所需正面、四分之三侧面或侧面独立稿，相关视图保持相同身份 |
| 服装与发饰 | 先剪影和内外层次，再领襟、肩袖、收腰、下摆、鞋履及附件；细化面料厚薄、织纹、垂坠、磨损、发饰形制和固定位置，另给背面或细节视图解决遮挡 |
| 肌肤与妆发 | 区分自然肤色纹理、当场汗湿／污损与化妆；底妆、眉眼唇腮和发束结构逐项明确，不用“精致”代替设计 |
| 仪态与动作 | 从承重、脊柱、肩颈、手势、视线及道具接触设计可读姿态；动作研究展示准备、关键接触、结果，不能把连续过程塞进一幅普通静帧 |
| 表情 | 固定面部结构与取景；按戏剧情境设计表情起落，让眼睑、眉头、唇缝、下颌、视线和呼吸各有作用，不以机械瞪眼或大幅变脸表示全部情绪 |

身份或服装多视图通常分开生成和审阅，再装配为参考板；拼图仅用于比较，不自动当作模型能解析的单人身份参考。表情板沿用同一身份与妆发；需要动态表演时再设计表演片段或关键帧，不宣称静态表情板保证口型、眨眼和转头稳定。

## 表演弧与镜头可读性

把“角色现在要什么—用何种策略—受到什么刺激—如何改变策略”映射到动作和表情，按[人物情绪与表情生成](prompt-detail-standard.md#人物情绪与表情生成)完成六层设计与冲突检查。内心情绪、外在掩饰与观众读法可以不同。给出表演强弱的具体差异，不把数值强度当作心理测量或供应商参数。

例如，同一名准备求助的成年旅人：初段嘴唇轻合、目光在柜台人员与出口之间停留；决定开口时视线稳定到对方近侧眼部、身体略向前倾；被接纳后肩部张力下降、下颌放松，嘴角只小幅抬起。三段沿用同一脸型、肌肤和妆发。特写可写眼睑与唇角，远景改用躯干、距离、停顿和手部动作承载，细微表情保存在表演母稿中。

给人物分别写动作起点、施力与路径、与他人／道具的接触、制动或延续、终点及眼神。听者反应不自动随发言人切走；决定是否需要反应镜头由信息变化和剪辑决定。拟定的微表情若在模型中难以稳定呈现，先测试相关片段，再给保留情绪目标的可见替代，不预先判定某类表情一定无法生成。

## 场景与整体视觉探索

先确定空间类型、用途、地理与建筑逻辑，再设计色调、材质、陈设和表现方式。风景与自然场景用地形、水系、植被和天气建立结构；室内与建筑用体块、柱网、墙体、出入口和通行动线。人物互动所需的平台高度、空隙、遮挡和触及关系必须能在场景方案中找到依据。

探索时可分别比较：空间开敞或封闭、构造与装饰密度、主辅色与强调色、表面干湿和风化程度、光源覆盖与阴影、前中后景层次及观看位置。场景的压迫感、秩序感或疏离感应由这些关系表达，不能只换“赛博”“高级”“史诗”等标签。

明确表现媒介：写实摄影用表面响应与物理光；二维表现可用线条、色块、明暗分区和造型简化；三维表现明确几何、材质和动画语法。风格化光影可以有意非写实，但必须形成可复用规则，不能在同一方案中混用彼此冲突的表现要求。

需要空间复用时，交付一个结构清楚的主视图和必要反向视图，附简短平面关系说明；光线测试视图与场景本体分开记录。反打改变画面左右，世界中的门窗和光源位置不随之翻转。

## 收敛为资产母稿

选定方向后形成一份详细母稿，按下游需要生成独立复制稿。母稿的作用是保持统一事实，不能以“同上”“继承设定”取代实际复制稿必需的文字。已有明确图像绑定时可由图像承担外观，视频稿重点写变化；未绑定真实素材时必须补齐文字，不把别名当成图片。

资产交付表包含：名称、用途、当前设计／实际素材状态、稳定项、允许变化、所需视图、对应提示词及使用镜头。版本仅在发生选择或修改时更新；无需为初次草稿编造哈希。只生成实际需要的视图，不能因指南列出维度而机械要求所有人物都有全套转面图或九宫格。

对于“全套提示词”，逐项列出实际需要的身份、服装、表情、姿态、场景、道具与镜头稿。某项已有可用素材或不适用时说明原因；不能在资产表列了任务，却只交付一条通用示范让创作者自行补齐。

## 比较与修订

在一致视图与观看条件下检查结构、辨识、材料、表演可读性和镜头用途，再记录审美选择。先分离“画得漂亮”与“可作为后续动作起点”；漂亮但已经完成交接的图不能作为未开始交接的首帧。

用户改变袖口、发饰或情绪时，先更新对应母稿，再更新实际消费这些信息的资产图稿、镜头稿和评审状态。保留其他身份、空间、光色与时间设置；新稿与新媒体分别验收，不能把“要求保留”写成“已经保持一致”。
