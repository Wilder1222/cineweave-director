# 可选参考：视觉概念、产品叙事与封面

创建视觉方向、产品图、封面／缩略图或关联资产组时加载。精确翻译、已选方案的直接编译和局部修复跳过概念探索。本指南沿用现有路由；人物、服饰和场景的具体探索继续使用[视觉开发](visual-development.md)，不建立新的服务或根契约。

## 从实际交付开始

区分三种情况：

- **应用已有系统：**继承用户给定的权威资产与规则，只设计本次用途。
- **补齐部分系统：**只解决本次产物实际消费的缺失选择；无字静物不必等待字体系统。
- **原创设计：**在授权范围内开发概念，分开原创提案与现有商品、人物的事实。

从简报提取受众、传播目的、主体事实、用途、准确文案、视觉偏好与排除项。只询问会改变结果的缺口。生活场景图需要可信使用情境，封面需要真实内容承诺，成组图片需要共同的设计理由。单张静物不自动扩成商业战略、全套品牌、旁白或演员设计。

## 先确定视觉机制，再编译提示词

重要原创选择可以用简短概念卡表达：

```text
目的：观众首先注意、理解或感受到什么
依据：给定事实、来源观察，以及另行标记的原创提案
机制：具体的空间、材料、动作或信息关系
主次：第一个视觉焦点与随后有用的发现
共享规则：相关身份、物体、场景、风格、文案和布局约束
允许变化：本应用或候选可以改变什么
取舍：这一选择牺牲什么
检查：什么证据会使我们修订
```

机制应能画成草图。“安静的高级感”没有决定画面；“修补缝线承接侧光，周围布面保持哑光”才形成具体关系。需要概念时给少量有实质差异的方向；已有确定机制则直接使用。候选数服务用户的决策，不设置强制头脑风暴或逐级审批。

将主体替换成无关物品，若画面仍毫无变化地传达同一含义，应寻找更贴近主体的关系。选择一个主要表达动作，其余元素支持它；轮廓、色彩、运镜和密集文字同时争夺注意力，可能破坏主次。这是可读性检查，并不禁止繁复风格。

分开四层职责：

1. 概念确定传播机制。
2. 相关路由解决可见事实、表现、调度和物理光。
3. `image_prompt` 编译这些选择的画面结果，不另加隐喻或偷换概念。
4. 制作规划按请求安排准确文字、图形位置、交付与验收。

选择草稿不等于批准为正式设定；继承现有授权规则，渲染成功或自行排名也不能代替用户保留的决定。

## 产品图：先选用途，再安排可见依据

产品几何、包装、材料与磨损归物体／场景事实；色板与字体沿用既有风格／文案职责。人物身份独立管理。灵感参考不能改写真实商品。

| 用途 | 创作重点 | 关键检查 |
| --- | --- | --- |
| 目录／中性产品图 | 轮廓、有用角度、落地关系、表面响应 | 不虚构标签、零件、内容物或尺寸 |
| 生活方式／使用场景 | 用可信动作与环境体现给定用途 | 手部、接触、相对尺度、产品辨识度 |
| 细节／演示 | 一个真实结构、纹理或使用步骤 | 细节存在，放大不暗示虚假性能 |
| 主视觉／横幅 | 产品层级及文案空间 | 目标裁切后仍保留商品和信息 |
| 轮播／说明组图 | 每张增加一项有用信息 | 不重复图的用途，共享规则与准确文案 |
| 广告变体 | 不同已给利益点或比较假设 | 产品、声明、身份与控制变量可追溯 |
| 试穿／佩戴 | 合体、垂坠、接触与产品可见性 | 保留人物和服装结构，不保证实际尺码效果 |
| 概念静物 | 一个获准的物理或图形隐喻 | 表达处理与事实性性能声明分开 |
| 风格改造 | 有范围的表现或氛围变化 | 产品形状、文字与其他硬锁不变 |

用途重叠时，交付物决定构图：使用场景横幅仍需文字区；轮播是一组信息序列，不是无关生活照。具体平台要求需核对当前规则，构图建议不证明上架合规。

产品短片按简报选择演示、揭示、使用、比较或讲解。开头吸引力应有真实产品依据，收束到给定信息。讲解人不是必需；不得虚构证言、个人使用结果、优惠或行动号召。先分清画内说话与画外旁白，再安排口型。

## 封面：准确内容中的信息差

依据实际视频／故事承诺，增强可见关系，但保留事件、出场者和已有事实。不为点击率虚构效果、截图、统计或事件；封面也不是内容发生过的证据。

| 框架 | 适用目的 | 边界 |
| --- | --- | --- |
| 对比／前后变化 | 真实变化是核心 | 保持可比条件，不伪造结果 |
| 转折动作 | 内容包含可读选择或事件 | 不暗示未发生的动作 |
| 尺度／数量 | 已核实关系具有反差 | 夸张不能变成虚假测量 |
| 人物与结果 | 给定人物的反应承载故事 | 身份来源与表情指导分别管理 |
| 产品细节／隐藏机制 | 真实特征回答标题问题 | 特征存在，或明确为虚构设定 |
| 地点／路线／图解 | 空间或说明结构是主体 | 地理、数据有来源，不虚构精度 |

建立明确第一视觉焦点与前后景分离，只保留能解释信息差的辅助物。按实际展示尺寸与全尺寸分别评审；约 120 像素宽可作为小封面压力测试，不是统一交付标准。无需所有题材都用人脸、艳色、分屏或图内标题。

风格参考只在声明范围内提供层级、能量、光线或色板依据。分别识别人脸、产品、标志与风格来源。准确标题按[文字与排版交接](../routes/image-prompt.md#准确文字与排版)独立管理；无字也是完整设计选择。

## 成组资产与公平比较

为相关资产保留同一基线，明确各元素的作用：主体与背景反差、强调色、材料处理、线条及尺度规则。色板不是把所有表面涂成同一种颜色。复用准确标志与文案，不为配合背景重新绘制权威资产。

只为请求范围维护简表：

```text
资产标签 | 用途 | 消费的基线／版本 | 独有内容 | 允许变化 | 格式 | 验收重点
```

- **概念备选：**可改变多个已说明维度，以比较想法；不声称某一变量导致效果。
- **受控变体：**除命名变量外，保持主体、参考职责、取景和处理一致。
- **修复：**沿用单变量 `RepairPlan`，保留已通过维度。

用“缝线侧光”“手部使用”“细节揭示”等稳定标签，并记录后续编辑采用的基准候选，不能默认为最新候选。要求像素级保留只是待验收要求，不是成功保证。

先整体检查主次、色板作用、尺度、视点与材料一致性，再逐项验收用途与格式。只有策划时检查指令一致性；有真实输出时检查实际证据。好看的拼图不能证明字体、色值、透明通道、可编辑结构或平台合规。

多尺寸交付区分继承内容与重新构图；直接裁切会损坏主体、标志或文字时，重新安排画幅。若问题仅是文案、颜色或位置，计划最小的确定性修改，不重启全部设计。

## 方向示例

给定：为现有修补帆布包策划三图，保留给定标志与橄榄绿布料，不加文字，以维修结构为重点，不虚构耐用性能。

- **共同机制：**修补缝线成为视觉主角，环境保持安静。
- **目录图：**四分之三角度同时展示缝线与提手，不重新设计标志。
- **使用图：**一只手从真实提手位置提起包，缝线可见，握持可信。
- **细节图：**侧光展示给定针脚结构；没有尺寸依据便不标尺度。
- **整组检查：**同一包、布料与标志，三种不同信息作用；三图不意味着三个身份或无依据的性能声明。

这些是方向与提示词输入，不是已生成图片。修订与交付使用[变更影响](drafts-and-change-impact.md)及[制作规划](../routes/production-plan.md)。
