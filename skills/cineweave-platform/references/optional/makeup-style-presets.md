# 可选参考：独立妆容与动画人物画法

25张真人妆容卡与8张动画人物画法卡；全部按视觉风格命名。真人配方保留既有修订，动画卡为r1。只迁移所标可见部位；局部参考不证明完整脸部设计，作品与人物不作身份模板。

## 选用、组合与覆盖

先识别保持原妆、整套换妆、只改某部位或新设计。仅调色不激活 MU；指定妆容时展开卡内正文。CG 与 MU 的同号配对是可选起点，不自动同时启用。可以跨卡组合；不要求肤色、性别、年龄或五官与剧照演员相同。各色名是设计方向，按本人肤色深浅调整浓度与明度，不把所有人物改成同一冷白皮。妆容保持原有骨骼、眼裂与唇形，排除参考人物的痣、胎记、伤疤和年龄特征。

以当前完整妆容为基线，局部覆盖只替换获准部位，再编译一份完整无冲突正文。底妆和肤面合并成一套规则；亮泽范围由妆容决定，照明呈色与反光强度由实际灯光及 CG 响应解释。不可同时保留“全脸哑光”和“全脸水光”。眉眼线条不以改眼型实现；花钿、贴钻、金箔、伤妆、汗湿与污损须单独选择。MU22 不默认汗湿；汗湿始终是独立场次状态。

组合示例：CG11@r2 + MU11@r2 用于清雅茶坊人物；CG15@r2 + MU02@r2 可用于冷夜眉眼焦点；CG18@r2 + MU08@r2 可用于清朗职场人物。只改唇部时，可在当前 MU11 上使用 MU15 唇部规则，保留其余妆面并输出完整结果。黑白转译只检查眉、眼、唇的明度分离，不能由灰阶图倒推真实妆色色相。

## 证据与验收

真人卡关联按质量精选的实拍参考，动画卡关联可读人物帧图，张数按实际取得文件确定；人物卡不使用海报来推断完整妆面；低清占位图不入库。人物妆面、场景和造型按可见部位标记，实际妆面数量及适用边界逐卡说明，来源作品逐图标明。黑白只支持灰阶，强色光、玻璃、眼镜和远侧遮挡不支持推断真实化妆品色号。同组可呈现不同人物的妆感，不代表同一配方。下述完整配方为原创迁移提案。先在本人及中性可辨光下检查妆面、身份与颈脸衔接，再进入目标色彩场景；动态连续与跨人物生成尚未验收。
