# 可选参考：视频、声音与交付规划

涉及动态影像、声音、交付版本或资源限制时加载。已有契约能表达的内容使用其真实字段，额外内容放入明确标注的非规范工作表。不要给严格 schema 添加虚构字段，也不宣称外部系统已经运行。

## 视频意图

镜头导演负责运动与时间结构；制作规划负责可行性和交接。文生视频、图生视频、首尾帧条件、续写和有界编辑只是规划意图，不能默认任何平台都支持。

每个片段记录镜头／时间引用或暂定工作引用、时长与时基、初态、可读变化、终态、人物／摄影机／环境轨道、身份和空间不变量、允许变化及可见失败检查。人物运动和摄影机运动分开。注明图像锚点的职责；计划中的图并不是真实条件素材。

续写应记录准确来源片段／帧、边界时间、继承状态、允许演化、新动作和停稳／余量要求。来源媒体未知则续写可行性未决。不要让一条静态图像提示词承担整段时间变化；另给有时间定位的自然语言指令。平台语法属于单独的证据支持适配，暂不被契约覆盖的视频字段仍保留在工作表。

需要判断输入状态、参考条件冲突或失败风险时，按节读取[生成诊断](generation-diagnostics.md)。先检查真实锚点准备度，再规划依赖它的交接；保留图像已经确定的外观，文字重点描述时间变化。时长和重试上限是给定约束或草稿估计，不是平台保证，也不说明任务已提交。

按当前需要加载：

- [视频平台适配](video-platform-adaptation.md)：区分平台、模型、界面、模式与官方证据。
- [类型化节点标签](tagged-video-nodes.md)：中文创作母稿及不同节点的必要字段。
- [视频表演与镜头](video-performance-direction.md)：台词、语气、情绪、表情、特效和运镜分工。
- [视频时长与剪辑余量](video-timing-and-handles.md)：生成窗口、有效区间、首尾状态和返回时长。

可选只读工具 `scripts/check-video-plan.mjs` 检查视频工作表声明的一致性；下面的 `scripts/check-delivery.mjs` 检查最终剪辑覆盖与 SRT。两者不会生成媒体、检查真实像素或声音，也不能互相代替。

明确要求视频提示词已经授权起草可评审的时间稿，不需再次授权才写正文。[群像调度与逐镜评审](ensemble-direction-and-review.md)负责触发到回应的编译、配角活动、逐镜批评、提示词限额及修订／Take 分别记录。项目字数限制按需使用，不设统一的 5000 字规则；未指定技术值保持未决或明确标为设计建议。

### 续写与生成段落边界

规划独立片段时，围绕连贯地点与因果过程分组，不按固定镜头数量切段。每个接点写明上一采用状态、拟接入状态、共同锚点、声音／动作相位，以及剪辑选择所需重叠或停留。新地点或互斥故事分支可以单列段落，这是规划选择，不是通用平台上限。

例如上一片段中快递员放下包，下一片段中店员拿起包，中间应有可支撑状态：包落在柜台上，快递员松手，店员再接触。有需要才围绕此状态设计重叠。返回后检查真实可用区间，不能虚构余量，也不能把重叠重复计入最终时长。本节独立参考 [Leos 生成控制](https://github.com/MasterLeos/leos-six-department-directing-team-skill-v1/blob/2ed50edb3c7838fc9ffb68e50824e0ebff59c7d4/references/generation-control.md)的边界规划思想，不继承固定格式或模型假设。

## 声音职责与提示表

角色声线与逐句配音的组织规则见[完整短片的声音与剪辑](short-film-creation.md#配音声音与剪辑)。声线、准确口播、表演指令和后期空间处理分开；台词时间须以实际音频复核。

现场拾音、声音空间与画面部门协调，按[收音与声音空间](prompt-detail-standard.md#收音与声音空间)展开；完整场次使用[交付模板](prompt-detail-standard.md#场次与逐镜交付模板)。本节维护声音时间表与交付规则，避免复制另一份参数权威。

故事负责对白、旁白内容及戏剧功能；人物负责虚构声线和表演意图，真实人声参考另需同意及用途决定；镜头导演负责提示时刻与可见动作的关系；制作规划负责声音交付、同步检查和外部交接。

每条声音提示记录 ID、对白／画外音／环境／拟音／音乐角色、准确文本或听觉意图、说话人／声源、时间区间、同步锚点、聆听视点、相对语音的优先级、权利状态和验收标准。注明说话人是否在画面内、是否需要口型同步。不能从静帧推断真实语音时长，也不能把提示表当作已存在音频。

分别评审可懂度、听觉转场、所需安静、同步锚点和连续性。技术混音目标应是用户给定要求或未决假设，不能虚构已测响度和供应商保证。

## 精确文案与时间检查

原样保留旁白和字幕。涉及字数时区分汉字、Unicode 码点和可见字素簇；标点不是汉字。不要在说明中写未经验证的字数。字数不能证明口播长度：先明确估算，再根据返回音频核实最终同步。

需要精确字数、剪辑覆盖或 SRT 时间戳时，使用随 Skill 分发的只读[交付检查器](../../scripts/check-delivery.mjs)，需要 Node.js 22+。从实际 Skill 目录定位脚本，安装后的插件不依赖仓库 checkout 或额外依赖。运行 `node <skill-root>/scripts/check-delivery.mjs --text "值得专程回来"` 可得到六个汉字。没有 Node 时使用等价算术工具，说明未运行检查，不阻止有用草稿。

简单硬切时间线可把实际边界及准确文案写入以下工作表，运行 `node <skill-root>/scripts/check-delivery.mjs <worksheet.json>`。这是可选计算输入，不是新的根契约：

```json
{
  "frameRate": { "numerator": 24, "denominator": 1 },
  "totalFrames": 288,
  "shots": [
    { "id": "S1", "startFrame": 0, "endFrame": 96 },
    { "id": "S2", "startFrame": 96, "endFrame": 192 },
    { "id": "S3", "startFrame": 192, "endFrame": 288 }
  ],
  "subtitles": [
    { "id": "VO1", "startFrame": 192, "endFrame": 264, "text": "值得专程回来", "expectedHanCharacters": 6 }
  ]
}
```

区间为左闭右开 `[startFrame, endFrame)`。镜头必须无缺口、无重叠地覆盖 `[0, totalFrames)`；有意空白也要自己的镜头条目。字幕可有间隙，但属于单一、不重叠轨道。`subtitles`、`expectedHanCharacters` 可省略。无效输入须先纠正，失败时返回 `srt: null` 和非零退出码。工具不写文件、不改文案。

帧率使用精确有理数，例如 `30000/1001`，不用近似 `29.97`。每个绝对帧边界按精确比例换算秒，只在 SRT 毫秒处舍入一次，不累计每镜的舍入误差。SRT 是经过时间，不是 SMPTE 丢帧标签。叠化、变速、多重叠轨道或丢帧套底，需要本文的[剪辑交接](#剪辑)和适当的外部时间线检查。算术通过不代表语速、字幕可读性、实际交付媒体或同步已验证。

## 交付与资源工作表

记录时长、有理数帧率、画幅、目标分辨率、受众／平台、字幕语言和准确文本来源、安全区、备选版本、必要原片和验收证据。请求规格与实际测量分开；竖版适配需要重查构图与文字，不等于自动裁切。

记录用户给定期限、预算上限、每镜最大候选数、修订轮次及停止条件。估算须说明依据；价格未知保持未知。本 Skill 不进行实际费用记账或自动重试。

约束无法满足时，给出服务相同目的的创作替代，例如拆分复杂运动、缩短片段、静帧配剪辑运动或减少背景活动。说明改变了什么创作质量，仅在超出授权时寻求决定。不能悄悄降低硬性身份、权利或叙事要求。

## 外部结果返回清单

实际媒体、候选、返回规格与设置按[人工交接与返回](video-platform-adaptation.md#外部人工交接与返回)记录，并附相关权利声明。元数据缺失时按[评审范围](../routes/review-repair.md#评审)限定可访问画面和声音；可复现性及平台合规性分别取证。

### 可选返回音频回流

已有 `cineweave-video-workbook/v1` 可选择添加 `audioReturns`，把已采用音频的来源声明映射回具体节点和声音提示；不把未选备选放入采用列表。没有返回音频时省略该字段，不用计划提示长度填虚构实测值。输入 `references` 中的声线或音频时序参考不表示输出音轨已经存在。

下例只是追加到已有工作表的数值夹具片段，不代表真实录音。已有 `V1` 的对白提示 `D1` 为 24 fps 下的 `[0,96)`，实际使用时替换为返回来源和确有依据的测量声明：

```json
{
  "audioReturns": [
    {
      "id": "AR1",
      "mediaType": "audio",
      "source": "fixture:narration.wav",
      "version": "v1",
      "candidateId": "take-A",
      "durationMs": 4000,
      "measurement": {
        "basis": "user_supplied",
        "source": "fixture:数值试算，非实际录音"
      },
      "bindings": [
        {
          "id": "AB1",
          "nodeId": "V1",
          "cueId": "D1",
          "sourceRangeMs": { "start": 0, "end": 4000 },
          "usage": "full",
          "sync": { "sourceMs": 0, "targetFrame": 0 }
        }
      ]
    }
  ]
}
```

| 字段 | 使用规则 |
| --- | --- |
| 来源与候选 | `source`、`version`、`candidateId` 声明准确采用来源；返回 `id` 与各 `bindings[].id` 分别唯一。来源不会被工具打开或上传。 |
| 音轨类型 | `mediaType` 为 `audio`；采用视频音轨时为 `video` 并明确 `useAudioTrack: true`。不从视频扩展名推断有可用声音。 |
| 时长与测量 | `durationMs` 为正的安全整数毫秒；`measurement.basis` 为 `provider_metadata`、`local_probe` 或 `user_supplied`，`source` 指明该测量声明的依据。工具不调用探测器、不核验原报告或波形。 |
| 采用与同步 | `nodeId`、`cueId` 定位该节点内的 `dialogue` 或 `sound` 提示；`sourceRangeMs` 是来源左闭右开区间；`sync` 把区间内一个来源毫秒锚点对到提示内的整数帧。 |

`usage: full` 必须保留完整 `[0,durationMs)`；`excerpt` 明确选择非空来源子区间。对白摘录还需在该绑定内填写 `dialogueExcerptAuthorization: {"approvedBy":"声明的批准者","reason":"当前提示的摘录依据"}`。这两个字符串只记录授权声明，不能证明真实同意或所选区间包含准确台词；未经授权不截断或改写对白，采用后仍须逐字听审。`loop` 只用于环境／音乐等 `sound` 提示：按锚点确定循环相位并填充声明的提示窗口，可以从选段内部开始，包含首尾部分循环；不循环对白，也不执行真实循环或混音。

同一来源可以明确绑定到不同提示、跨镜声音桥或多个环境声层；同一来源、版本、候选、媒介类型及音轨选择的总时长声明必须一致，相同完整采用映射不得通过换 ID 重复登记。不同 ID 仍可在一致元数据下复用准确来源。声音桥须在对应提示明确 `allowHandle: true` 并另行复核相邻时间线，不能靠回流字段掩盖越窗。

仅在明确采用“每个视频块一条旁白”的模板时，追加 `audioPairing: {"mode":"one_audio_per_video_block","nodeIds":["V1","V2"],"bindingIds":["AB1","AB2"]}`。`nodeIds` 是调用者明确指定的有序范围，普通 `nodes` 数组顺序不替代它；逐位 `bindingIds` 必须属于对应视频节点的对白提示。范围内所有已采用对白绑定都须列入，缺失、额外、重复或错序要修正。额外环境声层可以并存；没有该模板时不强制每镜一条音频。

用现有 `check-video-plan.mjs` 检查即可，无独立音频 CLI。`audioReturnChecks` 给出所选来源一次播放的 `requiredFrames`、提示的 `availableFrames` 及 `fitsDeclaredWindow`；循环样本的 `requiredFrames` 不代表循环后的成片时长。这些值只按声明与[精确时长算术](video-timing-and-handles.md#返回音频与采用窗口)计算，不修改工作表。所有结果保留 `measurementVerified: false`、`mediaVerified: false`、`capabilityVerified: false`；`SPEECH_TIMING_UNVERIFIED` 不因填了测量来源而解除，声明齐全也不等于声音、授权、口型或同步验收通过。

## 剪辑

使用约分有理数帧率和整数帧区间。声明素材／镜头意图、源素材可用状态、入出点、空白、停留、转场长度、剪辑余量、音频意图和未知媒体。相邻序列窗口不能意外重叠。

占位必须明确标注，不得冒充已生成媒体。时间计划不执行套底、渲染或导出。保留分镜与序列节奏的权威，技术时间线不能发明节拍。

## 调色

分开场景物理光源与材质状态、导演曝光与注意力意图、风格的反差／色板／滚降、创意调色意图，以及技术输入／显示／交付假设。

说明工作假设和未知项，不声称已经应用变换。预览意图和交付意图不同。显示风格不能烘焙进规范身份、材质或源光事实。

导演手法不同，镜头仍继承同一视觉和色彩流程假设。对照基线匹配色板、色温关系、饱和度、反差／滚降、肤质／材质和纹理，不逐镜附加新的名导调色。昼夜或光源变化可改变曝光和照明，但不替换共同调色意图。修改视觉需明确限定范围的修订。没有实际可比较媒体，只验证规划一致性，不宣称完成色彩匹配。

评审检查高光／暗部裁切、肤质与材质分离、中性／参考处理、镜头间连续性，以及创意调色是否仍尊重物理光照。色彩档案始终是交给外部色彩管理工作流的计划。
