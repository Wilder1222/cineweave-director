# 可选参考：电影模式

用户要求可复用的揭示、缓推反应、追逐升级、匹配剪辑、门槛入场、暂缓反打或平行动作时加载。

电影模式是参数化的创作程序，不是提示词预设。定义稳定模式 ID 与版本、故事功能及适用／禁用情境、必要绑定槽位、有类型且有范围和默认值的参数、有序步骤、质量检查与待决事项。每一步只属于一个路由和一个目标产物。不得包含供应商、模型、适配器或执行字段。

参数可以是注意力目标、揭示延迟、机位距离变化、反应停留、轴线规则、节奏阶段或匹配维度。参数改变的是创作控制，不是正式设定。

`CinematicSkillManifest` 收录模式。`ShotCompilerPlan` 选择一个版本、解析精确绑定和值，向创作者展示摄影机／表演／节奏控制，并输出计划交接。编译器不生成最终 `ShotSpec` 哈希、不补造故事事实、不选工具、不宣称已生成媒体。

一个模式步骤只有一个归属。故事功能属于故事／导演，演员时序属于人物，地理属于场景，表现方式属于风格，模型措辞属于提示词。跨领域便利不能成为隐藏覆盖。

创意选择或适配模式时，使用[自动导演手法匹配](master-style-presets.md)，无需名字或开关。该目录是简报驱动的决策辅助，不是已经实例化的 `CinematicSkillManifest`；保留共享视觉，只在确实需要规范输出时形式化兼容机制。

模式目的和取舍参见[导演方法](directing-craft.md)，摄影机／用光可行性参见[摄影方法](cinematography-craft.md)，转场参见[剪辑与声音方法](editing-sound-craft.md)。只加载相关指南。将影响来源展开为可观察选择；创作者名字不是控制值或质量保证。

## 从创作者语言到可评审镜头

对于“她听到脚步，继续走，掩饰慌张，同时摄影机靠近”，先解析人物和场景绑定。提出最小且有动机的模式，例如缓推反应；把摄影机运动、克制表演、反应时长作为独立控制。除非用户或已批准产物已固定时长，否则数值只是建议。人物领域把克制转为可见行为，导演把摄影机和时间与其对齐。

展示简短导演卡：戏剧变化、精确资产绑定、镜头意图、可观察表演、时序、保留事实和下一个未知决定。“克制程度 80%”只是创作输入，不是心理测量或平台权重。只调整用户点名的控制，保留其余已接受值。摄影机变化需要新走位或时序时，先说明依赖，再将受影响选择视为确定。

## 编译一致性

`ShotCompilerPlan` 中每个参数和绑定槽位的 ID 唯一。每项控制映射已解析值，并命名对应计划字段赋值。交接与追踪目标保持相同契约类型、归属与操作标签；输出归属来自当前发行版 `contracts.json`。`temporal_direction`、`performance_timeline` 等兼容协议标签表示归属路由中的操作，不是新 v3 路由。

交接依赖来自声明的精确绑定或上游引用，并保留绑定／上游赋值实际消耗的所有引用。别名绑定同时指明别名和精确注册表。分组、交接和追踪步骤严格递增，交接内部不重复赋值同一目标。每个非验证追踪步骤指向匹配交接赋值。

这些局部检查不能验证不可访问清单或注册表的内容。需要查看实际精确产物，核对模式版本、参数类型／范围、槽位要求和别名映射。缺少输入时，返回带未知决定的导演卡，不编造规范编译计划。

## 叙事镜头必经检索及静止出口

所有原创影视叙事镜头必须由导演按功能使用本词典进行候选选择，区分机位构图（K／C）、机身运动（M／K04／K06）、焦点调度（F／K07）及剪辑（E）。不需每次读完全部条目或用满 35 种技巧；需要固定中性镜头可选择 `neutral_static`，同时交代所看对象、焦点、理由与剪辑接口。名导名称和“电影感”并不代替具体路径与观众信息变化。
## 镜头语言与叙事作用词典

这里收录 7 种核心技法与 28 种扩展镜头方式。先区分**构图机位、摄影机运动、焦点控制、剪辑**，术语可能叠加但不可互相替代。相同手法不必产生固定情绪，效果由故事、场面调度和观众对信息的理解共同决定。这是非执行型创作参考，不是模型预设或新的 schema 枚举。

**自动选择流程：**目的／角色冲突 → 观众在什么时机看到什么 → 人物与道具 Blocking → 一个主导 Camera Idea → 起点、触发、运动／焦点变化、出点 → 相邻镜头连续性。先排调度，再选镜头；没有必要时优先固定机位、双人同框和已有覆盖，不堆砌招式。

### 七种核心手法：可见机制与边界

#### K01 双腿叉开框景（Between-the-Legs / A-frame）

- **归类：**前景构图＋可选低机位，而非运动。
- **机制：**从较近的角色自然分开的双腿之间看远端人物，双腿形成 A 形边框，保留地面、距离、站位和相互视线。
- **作用：**突出阻挡、对峙和体量差。压迫来自角色距离与关系，并非叉腿本身。
- **触发与出点：**先建立前景人物的位置，再让对手走入框景、停下或抬头；切点保留双方持物和站姿。
- **禁忌／审核：**不为镜头迫使角色异常宽腿，不把画面无故性感化；遮挡若吞掉表情或关键接触，应改景别。
- **中文镜头例稿（计划，尚未生成）：**石桥上从守卫背后近地面固定取景，守卫双腿自然分立为画面两侧前景，远处剑客在腿间清晰停步，桥面和剑鞘可见，摄影机不穿过人体。

#### K02 过腰／过胯（Over-the-Hip, OTH）

- **归类：**前景关系构图；可叠加腰高机位。
- **机制：**机位在甲侧后方越过腰胯，近景保留其腰带、手与佩剑，远景看见乙。区别于单指机位高度的 Hip-Level Shot。
- **作用：**把腰间道具与对手建立一镜内的关系，表现戒备、藏匿、威慑和犹豫。
- **触发与出点：**由甲的手接近物体触发注意，再读乙的反应；如需两者同时可读考虑景深和远近安排。
- **禁忌／审核：**近景不能挡住手到道具的真实路径；只是镜头与腰同高时不能冒充过胯。
- **中文镜头例稿（计划，尚未生成）：**从女将右后腰附近越过取景，佩剑和尚未握柄的右手在近景，三步外来者清晰可辨，女将注视对方的手，剑仍在鞘内。

#### K03 过肩（Over-the-Shoulder, OTS）

- **归类：**双人关系取景，不是相机移动。
- **机制：**从甲肩后偏侧看乙，甲的肩、头部边缘是空间锚点，乙的面部、视线或动作清楚；需要反打时另核对轴线和相对位置。
- **作用：**保留说话与倾听关系，读出对手刺激带来的微反应，而非每句台词一正反打。
- **触发与出点：**准确台词或动作触发倾听者的停顿／决定；允许在同一镜中听完一句话。
- **禁忌／审核：**肩膀不能遮住关键道具；不同机位反打不能把眼线方向和左右位置颠倒。
- **中文镜头例稿（计划，尚未生成）：**从师父左肩后拍徒弟正面中近景，肩线轻虚位于左下，徒弟听到『今夜出城』才垂眸，师父肩膀位置和两人的方位连续。

#### K04 反向包抄／背后绕到正面（Rear-to-Front Arc Reveal）

- **归类：**有触发的单镜弧线运动。
- **机制：**由角色后背或后侧起步，摄影机连续绕过一侧侧脸来到正面，背景门柱／建筑随位移产生真实视差；不必机械绕足半圈。
- **作用：**从隐藏表情变为揭示决定。局势反转必须由新出现的表演、线索或行动承担。
- **触发与出点：**听到追兵、看见敌阵或作出决定时开始绕；抵达正面时读出表情或已有手中物件。
- **禁忌／审核：**移动改变动作轴线时要保留方位锚点；不能使角色与敌人莫名换边或让人物与相机无理由反向旋转。
- **中文镜头例稿（计划，尚未生成）：**山门前从女将后背开始，听到追兵喝问后沿她右侧稳定绕行至近正面，门柱向后景滑移；她抬眼举起右手原本握住的令牌，摄影机运动中可切出。

#### K05 上帝视角俯拍（Overhead / Bird's-eye）

- **归类：**近垂直顶拍机位；可静止。
- **机制：**从上向下展示人物、障碍、出口和互相位置；与斜向下的普通高机位不同，升降运动也是另一控制。
- **作用：**有利于交代阵形、路线、包围缺口、孤立或命运隐喻；不天然提升临场感。
- **触发与出点：**群体位置出现改变时用顶拍澄清空间，再转近景读出动作和表演。
- **禁忌／审核：**顶拍可能读不出面孔、手部握持，切回地面时必须保持行进方向。
- **中文镜头例稿（计划，尚未生成）：**从石桥正上方固定垂直俯拍，主角在南、五名追兵在北，水流向东和两侧竹林清楚；主角向西闪开后队形产生可见缺口。

#### K06 迈克尔·贝式低机位环绕（Bay-style Orbit）

- **归类：**主体中心弧线移动，可结合略低机位。
- **机制：**摄影机沿约四分之一圈到大半圈弧线运动，主体保持视觉中心，建筑和近景有位移视差；不强制每镜 360°。
- **作用：**放大英雄决定、重逢、合围或情绪高点；无路可逃要由既定敌阵、出口与障碍证明。
- **触发与出点：**关键决定／对方反应触发环绕，弧线进行中也可切出。
- **禁忌／审核：**过用会像预告片；不要在密集搏斗中无依据地叠加高速绕行、变焦与多次移焦。
- **中文镜头例稿（计划，尚未生成）：**略低机位从女将右前侧开始沿半圈缓慢绕行，持剑姿态和脚下支撑稳定，城门与战旗在后景出现视差；披风顺已有风向运动，接到号令时仍在运动中切出。

#### K07 虚实焦点切换（Rack Focus）

- **归类：**同镜头内焦点平面变化，机位可固定。
- **机制：**焦点由已存在的近景对象 A 转到已存在的远景对象 B，A 变软、B 清楚；观众获得信息的时机被改写。
- **作用：**伏笔揭示、观察对象变更、表情与物件关系；不是任何单一导演的专属技巧。
- **触发与出点：**由目光、声音或关键台词触发；后景清楚后保留能认出的阅读时间。
- **禁忌／审核：**不得借切焦凭空生出道具。若两人的接触需同时可见，先比较深焦或双人覆盖。静帧不能验证时序移焦。
- **中文镜头例稿（计划，尚未生成）：**书房固定中近景，先清楚拍到女子压住信封的双手，后景屏风已有纹章但虚化；门外剑鞘声响起后焦点转向纹章，机位不动，信封与纹章的位置不变。

### 镜头决策矩阵

| 要解决的问题 | 优先比较 | 放弃信号 |
| --- | --- | --- |
| 对峙和压迫 | K01、K02、C01、C07，必要时补空间广景 | 主要对手、武器接触或表情被框景吞没 |
| 对话的倾听和权力差 | K03、C05、E03，必要时共享双人镜 | 一句未说完已机械反打 |
| 道具与对手关联 | K02、F01、K07 | 道具与对手无法建立同时或先后因果 |
| 反转与情报揭示 | K04、K07、M02、M08 | 镜头动了，事实却没有变化 |
| 群战阵形、追逐地理 | K05、M03、M05 | 人物、地标和方向无法辨认 |
| 角色决断与史诗情绪 | K06、M01、C01 | 环绕既无触发，也无必要 |
| 伏笔和观众视线管理 | K07、C08、F03、E02 | 两个焦点平面原先不存在或阅读时间太短 |
| 快速动作转向 | M06、M07、E01，先锁定动作节拍 | 失焦和模糊掩盖落空或真实接触 |

### 九项镜头卡与现有契约交接

每镜回答：**(1)** 戏剧目的与信息变化；**(2)** 初始人物站位、朝向、持物和地理锚点；**(3)** 机位构图与景别；**(4)** 动作／声音触发；**(5)** 相机真实运动还是原地摇、俯仰或变焦，路径和速度相位；**(6)** 开始焦点与转换时机、可读时长；**(7)** 谁先行动、谁后反应、接触或落空与持物状态；**(8)** 采用出点的运动相位以及下一镜继续、重看还是省略；**(9)** 轴线、透视、遮挡、光照和身份风险及证据情况。

规范交接**沿用现有 schema，不新增字段**：机位、景别、高度、角度、透视、焦点目标、轴线侧、运动意图归 ShotSpec.camera；前中后景及遮挡归 ShotSpec.composition；人物路径／持物归 ShotSpec.blocking；相机路径和速度阶段归 TemporalSpec.cameraMotion（弧线可用 arc，多个不同阶段可用 compound），移焦时序归 TemporalSpec.focusTimeline；剪辑与采用出点由 storyboard_rhythm 规划。正式参数化编译才根据 CinematicSkillManifest 和 ShotCompilerPlan 提供合法槽位、参数、所有者、版本与检查；不能把 K01、M09 直接冒充受支持的字段值。

### 原创古装 AIGC 示例（仅计划，非生成结果）

**守桥对峙（K01 → K02）。** 镜 A 采用桥中央低机位，守桥武者自然分立的双腿为前景框架，远端剑客站在桥北端，腰间武器未出鞘。镜 B 切到守桥武者右后腰，近景露出剑鞘和正在抬起但尚未握柄的右手，远端剑客仍停在北端，桥缘与溪流方向继承镜 A；不能把剑客和守卫互换位置，也不能在切镜间突然出鞘。

**山门反转（K04）。** 女将背对镜头，听到追兵喝问后摄影机沿其右侧持续绕至正面，山门门柱产生空间视差。此时她抬眼举起右手原有的令牌，追兵仍从同一方向靠近。新信息来自令牌与表演，弧线负责展示；不凭空创建道具，不让山门左右翻转。镜头可以在运动中切到追兵反应。

**书房伏笔（K07）。** 固定镜头原先聚焦女子按住信封的双手，屏风上已存在的纹章处在后景模糊平面；门外剑鞘声响后才将焦点移向屏风，留出辨认纹章的片刻。镜头不移动，不改信封持有者或原场景光源。只有实际视频才能核实焦点转移是否成功。

### AIGC 文本／标签和最小验收

普通视频提示词按**初态 → 触发 → 镜头／焦点变化 → 出态／续接**写成可见自然语言；静帧只写一个瞬间，不宣称动画已形成。用户需要标签时使用现有 <运镜>、<表演>、<情绪>、<台词>、<剪辑余量>，准确台词归原说话人，起止状态继承硬锁。K07 如果相机不动，必须明确固定机位；K02 必须说明前景腰与后景目标的关系；K04 与 K06 必须有可见背景视差和地理锚点。

**回归检查：**双人对话允许过肩或双人同框，避免强制正反打；腰间藏剑不混淆 over-the-hip 与 hip-level；背后绕行遵循人物／敌阵方位；所谓无法逃脱需要既有障碍证据；切焦两个对象最初就存在；顶拍仍可读阵形、出入口与地标；接触、握持和运动相位跨镜连续。复杂短镜优先一个主导摄影动作，避免将腿间取景＋高速环绕＋两次切焦＋推拉变焦堆在同一关键接触镜头。
