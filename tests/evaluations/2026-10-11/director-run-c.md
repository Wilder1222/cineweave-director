# director-run-c：独立文字试跑

来源范围：本地 `skills/cineweave-director/SKILL.md` 与本稿所需参考。全部内容是原创文字设计（CD-E59 v2，CD-E60 与 CD-E61 v1），没有输入图片、视频或音频；没有调用媒体生成或供应商 API。设计参数用于表达拟采用画面，不代表平台能力或实测结果。

## CD-E59

### 原请求

```text
同一傍晚书店三段十二秒：先看出信被藏在书下，再看三人的不同回应，最后甲乙告别。角色服装、书店空间、北窗自然光和低饱和木色固定，台词只有“明天见”。给全套逐镜视频稿，方法可随功能变化，视觉一致。
```

### 实际回答

输入澄清记录：原请求逐字保留在上方。初稿 v1 原先拟按“三段各十二秒、总三十六秒”的可撤销假设起草；尚未运行逐镜检查，也没有生成媒体。根代理随后澄清为“三段合计十二秒，各段时长可自行分配”，其余请求不变。`clarificationCount=1`。这不是无澄清首次通过，也不是已观察的技能失败。

最终文字稿为 v2，采用三段各四秒、合计十二秒；三段依次承担发现、回应、告别，各用一个镜头。未指定的外观、站位与画幅为可撤销的原创设定。信的内容、来历与藏信者保持未交代，只让观众看清它原来压在书下。

共享基线：16:9 横向写实剧情影像。甲为二十多岁的成年女性，黑色齐耳短发、长椭圆脸、平直眉，穿米白圆领细织棉衫、灰褐直筒长裤和棕色平底鞋；乙为三十岁左右的成年男性，短黑发、较方的下颌、浅色胡茬，穿灰蓝翻领棉衬衫、炭灰长裤和黑色低帮鞋；丙为四十岁左右的成年女性，黑发低束、圆框细边眼镜，穿浅褐针织开衫、白衬衣和深灰长裙。三人不戴额外饰物，不改变发型、衣服层次或衣料颜色。面部保留自然细纹和皮肤明暗，不用磨皮或逐镜新增妆容。

书店只有三人。北墙中央一扇大窗，窗下是低矮书架；中央栗褐木桌长边东西向，东南侧留出通向东墙出口的走道，乙转身后到出口约两小步，门已打开。甲站在桌南侧偏西，乙在桌南侧偏东，丙在桌北侧靠东、手边有一本合上的登记本。桌南边的一本无字灰布封面书压着米白信封，信封右下角只露出一小片。书、信封与登记本位置不随换机位重置。主光始终是北窗进入的柔和自然暮光，白墙提供弱反光，窗外无直射金色阳光；室内灯不亮。木桌、书架与地板保持低饱和棕褐，灰蓝与米白是小面积服装色，肤色自然，暗部有细节，高光柔和，无逐段滤镜变化。摄影机均留在桌南侧与东南走道一带，不穿过桌体或书架。

声音基线是同一室内声场：很轻的窗外远处车流、纸张与衣料、木地板脚步，无音乐、旁白或额外台词。仅甲在最后一段对乙说一次“明天见”，乙以动作回应。没有字幕。

#### E59-S1：观众先发现信

镜头卡：四秒。摄影机在桌南侧偏西，略高于桌面、向下俯拍，桌面与甲胸口以下入画；开头灰布书占画面中部，甲右手在书右边缘，信封小角位于书的画面右下方。自然近距离透视，设计视角相当于全画幅约五十毫米；焦点先在书封面，后交给露出的纸角，桌北书架轻微虚化。摄影机只向桌边前移约一掌，不越过桌沿。三人的脸暂不入画，身份由衣袖与后续关系镜承接。

完整视频复制稿：

```text
四秒有效采用段，16:9 横向写实剧情镜头，同一傍晚书店。北墙大窗的柔和自然暮光照在栗褐木桌与书页上，低饱和棕褐木纹、米白纸张与灰布书封面保持自然材质，暗部不堵塞，窗光不突然变暖，室内灯不亮。桌南侧偏西的甲是黑色齐耳短发的成年女性，米白圆领细织棉衫与灰褐长裤；本镜只见她的胸口以下、右前臂与手。桌南侧偏东的乙穿灰蓝翻领棉衬衫，手持一张无字价签；桌北侧靠东的丙穿浅褐针织开衫和白衬衣，她的登记本合在桌面上。乙、丙的身体仅在上方边缘形成可辨的衣色层次，不加其他人。

首态：一本无字灰布封面书平放在桌南边，米白信封压在书下，仅右下角露出约两厘米。甲右手放在书的右侧边缘，尚未抓紧；她没有碰信封。摄影机在桌南侧偏西，略高于桌面俯拍，灰布书居中，右下纸角清楚留在画框内。

0–1秒：甲右手沿书右边缘整理放置方向，食指停在露出的纸角旁，但不夹取纸角。摄影机缓慢向桌边前移约一掌，幅度只够让纸角尺寸更可读，手、书和桌沿同时可见。
1–2秒：甲注意到纸角后，拇指压住书封面右边，四指伸到书右侧下缘夹住书体，先确认握稳，再将书的右边缘缓慢抬起。书左边缘仍接触桌面作支点，右边缘升起约十厘米；米白信封留在桌上，不随书粘起。摄影机停止前移，焦点从灰布封面的织纹转到信封露出的封口折边。
2–3秒：甲保持右手托书的姿势，让信封的米白纸面和三角封口在书下显露；信封没有姓名、字迹或图案，不展示内容。画面先让观众读清书遮住信封的大部分，再读清甲手撑开的缝隙，确认信原本藏在书下，不能变成书页间的一张普通书签。
3–4秒：甲不抽信、不翻信，右手仍托着书右边缘。她的身体微向桌前倾，只以姿态表示重新关注这个物件。乙与丙从原任务转而看向甲正在抬起的书及露出的信封，各自视线能从桌边直接到达该物，不穿过书体。两人的明显回应留到下一镜，不在背景同步夸张表演。

终态与切出：甲右手稳定托住书右边缘，书左边缘抵桌，信封完整留在书下的桌面上，乙与丙已看到这个线索。4秒处硬切到同一时刻的三人共享画面，继续动作，没有重放抬书，也没有省略抽信。
声音：0–4秒延续同一室内轻微底声；1–2秒有书布封面、指腹与纸页的近处摩擦，抬书后声音自然衰减。无对白、音乐和提示性惊悚声效。
保持：书店北窗、木桌和低饱和木色不变，甲右手握书、信封不移位；不新增文字、手、人物或强逆光，不让信封漂浮或穿过书。
```

#### E59-S2：让三种回应同处一幅画面

镜头卡：四秒。摄影机改在桌南侧偏中、眼睛以下高度，水平固定拍摄三人从头顶到大腿中部，桌面占下方约四分之一；甲在画面左、乙在画面右、丙在后方中右。设计自然略宽视角相当于全画幅约三十五毫米，三人的面部、手与书信接触均处于可读景深，丙不被乙挡住。甲确认异常，乙收住手上动作并让开，丙把工作暂时放下、留出安静。没有给乙“藏信者”或丙“知情者”的事实身份。

完整视频复制稿：

```text
四秒有效采用段，16:9 横向写实剧情镜头，同一傍晚、同一书店。北墙大窗位于画面后方，柔和自然暮光从世界北侧照入，窗下低矮书架、栗褐木桌、东南侧通向东墙出口的走道保持原布局。低饱和棕褐木色、米白纸张、灰蓝衬衫与自然肤色保持同一反差和材质表现，不增室内灯光，不变调色和锐度。

甲在桌南侧偏西、画面左，黑色齐耳短发、长椭圆脸和平直眉，穿米白圆领细织棉衫、灰褐直筒长裤；右手正托起灰布书的右边缘，书左边缘仍抵住桌面。乙在桌南侧偏东、画面右，短黑发、方下颌与浅胡茬，穿灰蓝翻领棉衬衫、炭灰长裤，右手持无字价签。丙在桌北侧靠东、画面后方中右，黑发低束、圆框细边眼镜，穿浅褐针织开衫、白衬衣和深灰长裙，合上的登记本就在她左手旁。米白信封仍压在书下，右侧纸面与三角封口从抬开的缝隙显露，信封没有字迹。

摄影机在桌南侧，眼睛以下高度水平拍三人头顶至大腿中部，固定机位。甲、乙的间距约一臂，丙隔桌稍后；中等景深让三人的眼线、双手与桌面物件同时可辨。甲手与书信占下方前景，三张脸组成不同高度的中景，不让乙遮住丙。焦点保持在这组关系，不逐人拉焦，也不正反打。

0–1秒：直接承接上一镜书右边缘已抬起的状态，不重复伸手和抬书。甲的目光仍落在书下信封，眉间轻收、唇缝自然闭合，下颌略向前，身体前倾一点；她的任务是确认自己刚看见的东西，不震惊张嘴。她只托书，不抽信。
1–2秒：乙看清信封后才停止捻动右手中的价签，手指仍握着价签，没有丢下。目光从信封短暂移到甲的脸，再落回桌沿；嘴角原有的轻松状态收住，肩部微向后撤，给甲桌前空间。这个动作只表示他选择不打断，不宣称他知道信的来历。甲继续看信封，不立刻迎接乙的眼神。
2–3秒：丙从信封转看甲，确认甲没有开口，才把原本搭在登记本边缘的左手收回半掌，让桌面安静空下来；她眉头舒展、双唇轻合，站在原地，不跨桌抓信，不与乙同步点头。甲随后用右手缓慢降低书右边缘，书左边缘仍作支点；灰布书落回桌面并重新遮住信封，只留下同一右下小角，右手在书面轻压一下确认平放，再松开。
3–4秒：甲从书上抬眼看向乙，仍保持克制的疑问而不说话。乙接收到甲的眼线后先将价签放在自己一侧桌面，确认它平放、松开右手，再把身体转向东南走道，右脚向出口方向迈出半步。丙仍在桌北侧，注意力跟着甲，双手留在自己的登记本区域。三人的回应依次发生，不集体笑、不集体转头。

终态与切出：甲空手留在桌南偏西，书平放、信仍在书下露同一小角；乙价签已放在桌南偏东，身体转向出口、正在迈出第一步；丙留在桌北侧靠东，登记本合上且未移位。4秒硬切至东南走道内同一动作的继续，下一镜承接乙的迈步相位，不从面对桌面重新转身。
声音：连续室内底声；2–3秒书缓慢落桌产生短而轻的钝响与衣袖摩擦；3–4秒价签触桌有纸声、乙第一步有木地板脚步，所有声音对应实际接触。无台词、旁白和音乐。
保持：三人服装、身份、站位关系和北窗自然光不变；不让甲抽信，不把乙或丙的表情写成已获证据的秘密事实，不新增遮挡关键接触的背景动作。
```

#### E59-S3：甲乙告别

镜头卡：四秒。摄影机在东南走道、仍处于桌南侧半空间，胸口高度水平拍摄甲、乙从头到鞋，乙在画面右、甲在画面左，丙留在后方桌北区。设计自然宽视角约全画幅三十五毫米。先用共享画面容纳一句台词与回应，再沿走道向东平移约半步跟随乙，甲仍留画面左侧。跟随到乙通过东门便止，镜头不是环绕，光色不随亲密告别突然升温。

完整视频复制稿：

```text
四秒有效采用段，16:9 横向写实剧情镜头，同一傍晚书店。北墙大窗持续提供柔和自然暮光，窗下书架、中央东西向栗褐木桌与东墙出口不变，东南走道空出通行。低饱和木色、灰蓝和米白衣料、自然肌肤明暗沿用前两镜，暗部有细节，无金色夕阳滤镜、泛光增加或新增室内灯光。

甲是黑色齐耳短发、长椭圆脸、平直眉的成年女性，米白圆领细织棉衫、灰褐直筒长裤和棕色平底鞋，空手站在桌南偏西，画面左侧。乙是短黑发、方下颌、浅胡茬的成年男性，灰蓝翻领棉衬衫、炭灰长裤和黑色低帮鞋，刚从桌南偏东转向东南走道，画面右侧，双手空着。丙黑发低束、圆框细边眼镜、浅褐开衫白衬衣深灰长裙，留在后方桌北靠东，只看这次告别，不抢占前景。灰布书仍平放在桌南边、压住米白信封、只露原右下小角；无字价签留在乙原站位前，登记本留在丙手边。

摄影机在东南走道靠南的一侧，胸口高度水平拍甲乙头顶至鞋，东门在画面右方，甲乙之间和乙右前方各留通行空间。保持同一轴线侧，门框不挡住乙的脸和甲的口型；北窗光从世界北侧进入，在乙转身时自然改变脸部受光面，不把光源挪到相机侧。起初固定机位，中等景深让甲的脸、乙的回头和后方桌面状态都可辨。

0–0.6秒：乙承接上一镜右脚向出口迈出的动作，右脚继续承重、左脚向前跟上，沿东南走道向画面右侧迈一步；没有重新转身。甲先看向乙背侧，再向前迈半步离开桌沿，肩部转向他，准备叫住告别而不是阻拦。
0.6–1.6秒：甲对乙说一次准确台词“明天见”。声音轻而清楚、完整说完，不加称呼、前后词或第二次重复；视线落在乙近侧眼睛所在方向，唇部和下颌随发音自然运动，句间不用闭唇状态锁死口型。甲说话时摄影机保持甲乙共享画面。乙听到声源后才减缓当下步子，转头看甲，身体仍朝出口，不抢在台词前作告别反应。
1.6–2.2秒：乙在句尾之后面对甲的目光轻点一次头，嘴唇自然合拢，不说任何话。甲眉间张力减弱，嘴角有一瞬很小的上扬，右手抬到腰上方、掌心向乙作一次短小挥别，再放回身侧；不夸张大笑。丙在后方看到甲的挥手后才把注意力转回自己合上的登记本，不点头、不随甲挥手。
2.2–3.6秒：乙转回前方，恢复平常步速沿走道向画面右侧走至东门；左、右脚连续交替支撑，双手自然摆动。摄影机沿走道向东平移约半步，以乙的前进带动构图，速度低于乙，甲仍留在左侧、桌子与书信不脱离原空间。摄影机不穿门、不穿人，不绕到动作轴线北侧。甲留在原地目送，不追出去、不再说话。
3.6–4秒：乙通过已经打开的东门离开书店，画面右侧露出门内空位；摄影机完成短距离平移后留在门内，甲在画面左侧放松肩部，目光停在刚离开的门口。丙留在桌北侧，灰布书与信封的最终位置不变。最后0.4秒是告别后的关系余韵，不安排新的发现或人物入店。

终态：乙已出门，甲留在店内左侧目送，丙留在桌北，信封仍在书下。声音：0–4秒保持同一室内底声；乙脚步由近处走向东门逐渐远去；0.6–1.6秒只有甲说“明天见”，对白在环境和脚步之前可懂，句尾完整；1.6–2.2秒仅轻微衣料声。无乙的答话、其他对白、旁白、音乐或字幕。
```

## CD-E61反馈后修订v2

### 首次 v1 的独立文字审阅记录

根代理独立审阅将首次 v1 标为 `warn`：人物向东走时左髋在北侧，而两镜摄影机都在南侧；书竖贴左髋，稿件要求左手接触可读，却未具体落实避免躯干遮挡。该结论是规划可读性提醒，没有实际媒体，因此不是已观察的媒体失败。上方 v1 正文、工作表和原始脚本结果全部保留；v1 的脚本退出码0仅说明表格一致性，不能覆盖这项独立语义提醒。`initialTextReview=warn`，`feedbackRevisionCount=1`。

### 最小变量与传播范围

唯一根因变量：持书相对躯干的位置。从 v1 的“左手竖贴左髋（世界北侧远侧）”改为“左前臂横过上腹，左手竖持红书在下胸前偏人物右侧（世界南侧近侧），书与衣服留一掌空隙；下书边与左手指触同在近侧，右手自然摆动在书下方”。这个姿态在采用入点前已经建立，段内不添加抬书、移书或交接事件。
