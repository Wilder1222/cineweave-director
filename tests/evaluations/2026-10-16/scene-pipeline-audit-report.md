## 前向审阅中真实发现并修正的具体缺漏

1. **A-S02→A-S03 毛笔位置缺乏转移事件**：起初 A-S02 只说顾的手与笔在桌面，下一镜已经「毛笔搁在账册上」。已补充 A-S02 正式放笔动作和出态，并更新剪辑接口，防止自动将笔瞬移。
2. **A-S03→A-S04 唯一证据匣的握持容易丢失**：补充 A-S03 出态仍由沈右手握匣，避免近景排除她后下一镜重新创造物件。
3. **A-S06 关键木匣可达性**：顾从桌北拿桌南匣时加入身体自然前倾，不能只靠手臂伸长穿过桌案。
4. **B-S04→B-S05 三瓶道具账本不完整**：补充唐栀仍右手持绿瓶、林夏黄瓶与乔宁透明瓶仍在木台，保证 B-S05 的收拾不是道具瞬移。
5. **B-G2 物理顶灯缺真实空间锚点**：把中性顶灯独立登记在室内天花，而不是随意绑定到东侧窗台；避免错误的物理灯位声明。
6. **G5 原稿遗漏生产级声音交接**：在两案都补齐每人声线、每句台词的角色／受话人／语气／未测的计划发声窗／字幕精确正文、声场混音与调色意图，不将准确台词和声音设计混为一类。
7. **G6 原稿遗漏剪辑余量声明**：新增每镜暂定 12 帧头余量＋24 帧尾余量及 `provider_unverified` 状态；不擅自宣称平台有相应秒数档位。
8. **Stage 文档最初只定义动作步骤，没有实文退出标准**：在 `scene-directing-pipeline.md` 补正式场次逐阶段交付矩阵、跨域引用闭合与媒体证据边界；只在需要场次交接时加载。

## 机械回归及反例设计

`tests/reliability.test.mjs` 针对上述两份完整工作簿执行只读结构检查：

- 必有 G0–G7，场次导演语句、完整剧本节拍、人物／场景／道具的独立正文。
- 角色、场景、道具与镜头绑定可解析；节拍的 `coverage` 与真实镜号互指。
- 每镜有相机决策／移动或静止理由、完整独立首帧与运动正文；图生视频路径缺首帧必失败。
- 每镜 `startStateId/endStateId` 必须接续，`propContinuity` 必须精确描述两侧最新出入状态；所有帧区间连续、精确总计 60 秒。
- 每句准确台词在剧本、视频提示词、声画事件与字幕映射中一致，声音窗口处于所在镜头的整数帧范围；每位角色有声线，模型平台是否支持仍为 `unverified`。
- G6 的测试组与镜号真实对应，尚未产生媒体时 G7 不能冒充 `mediaVerified=true`。
- 故意破坏阶段、资产、空间锚点、节拍覆盖、演员目标、首帧、固定机位解释、相邻状态、镜号时间窗、准确台词、字幕声线、剪辑余量或媒体证据必须触发对应错误。

这些检查**只证明字段、引用、区间及精确字符串的局部一致性**。即使所有断言通过，仍需人工检查镜头表达和实际媒体的几何、光影、动作及声场。负例证明检查器可抓到其覆盖的问题，不证明能抓所有语义错误。

## 持续调研与采用取舍

- [Adobe：How to Make a Shot List](https://www.adobe.com/creativecloud/video/discover/shot-list.html) 说明镜头清单应支持可剪辑覆盖，也提醒过度详细会妨碍执行。CineWeave 采用“节拍与必要镜头覆盖”的实用交接，不把常见镜数上限当作一刀切硬规则。
- [StudioBinder：Script Supervisor](https://www.studiobinder.com/blog/script-supervisor-forms-template/) 强调道具与表演在不同拍摄和镜头中的连续，故场次将“谁拿着什么、在什么时候做了什么”加入入出态对照，而不是只看两张关键帧好不好看。
- [OpenAI：Agent Evals](https://developers.openai.com/api/docs/guides/agent-evals) 将代表性轨迹调试、可重复的数据集及评审标准分开，本文对应“完整输出正文与失败案例回归”。这是设计类比，当前**没有实际 API trace 或独立模型调用**。
- 注意 OpenAI 的旧 Evals 平台官方已公告将在 2026-11-30 结束；因此这一轮只使用仓库内 Node 测试和 GitHub Actions，不引入即将停用的云端服务依赖。[OpenAI 官方说明](https://developers.openai.com/api/docs/guides/evals)

## 仍需实证的下轮门槛

- 有真实选择的角色身份图、场景母版、各镜参考首帧及精确供应商能力／模式，才可对资产绑定和图像身份评审。
- 有真实可播放视频和音轨，才可对走位、手部接触、焦点时序、声画桥、剪辑余量进行原生证据评审。
- 至少一段完整连续场次的试剪，在普通播放速度下检验观众的空间与因果理解；这不是本次文字回归的成功范围。
- 需要独立执行的 CineWeave Skill 冷启动轨迹，才可测宿主触发、加载、跨技能交接、自动生成正文的重复稳定性；此文件只保存由同一助手手工执行的创作流程。
