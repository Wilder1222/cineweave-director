# 可灵 4.0：12 秒中文产品广告条件稿

## 结论与前提

建议条件路径：可灵 4.0 的 **Omni Reference** 中以产品图约束产品外观，以声音样本创建的声线档案约束画外旁白的音色；音乐在后期使用用户提供的现成音乐。官方用户指南所述入口的音频参考目前只接受声线档案，不接受上传背景音乐或音效作为音频参考，因此现有证据不支持三份素材以用户期望的三种职责同时作为该入口的生成参考。后期使用现成音乐与“上传作为音乐参考生成”有差别，需用户选择；也不证明用户指定的未知入口必然有相同限制。

产品类别、品牌、尺寸、使用方式、画幅、具体入口和账号均未知。以下是可审阅的原创广告草稿，假设静物陈列适合产品；不推测产品性能、重量或使用结果。**12 秒是成片目标**，广告语逐字锁定：“轻一点，也能走更远。” 所有素材尚未提供，尚未观察图像、听过声音或音乐，不能认为已绑定、授权、生成或验收。

## 导演设计

单镜一镜到底，12 秒设计目标。画面是简洁静物广告：产品置于干净、与实图兼容的中性展示空间；正面或实图中最可辨认的面朝镜头，避免发明产品不可见的一侧。柔和侧光勾勒轮廓并保留标签与材质可读性，背景轻微虚化。固定中近景、眼平略侧，产品居中偏下并留出呼吸空间；焦点持续落在产品可辨识区域。固定摄影机是为了让观众先辨认产品再听完整文案，避免运镜扭曲包装；无可见人物，采用画外旁白，无口型约束。

- 0–3 秒：展示产品的真实轮廓和材质，让观众辨认主体；安静的光线缓慢变化。
- 3–8 秒：保持同一构图，一道柔和的光沿产品边缘缓慢移动；不让产品形状、包装和文字发生变化。以平静、有前行感的语气读出完整广告语。
- 8–12 秒：光线稳定，产品继续清晰停留，给完整语尾和后期音乐留余韵。时段是导演节奏，不是逐帧或语音时长保证；实际语音测量后调整剪辑。

如实图的裁切、视角或产品形态不允许该陈列，先以实际图片为准调整镜头母稿；图片参考不自动等于严格首帧。包装上的细小文字和标志若有准确要求，建议用授权原图或素材后期合成并人工逐字核对。

## 主方案：声线参考生成画面和旁白，后期配现成音乐

仅当目标入口的可灵 4.0 Omni Reference 确认支持产品图与声线档案同次使用、12 秒可选，并完成相应绑定后，以下作为条件复制正文。上传顺序及实际界面标签核实前，不填造 `@` 别名；如界面生成真实标签，按其要求把产品图的实际标签放在产品职责处。选择声线档案并把它绑定至画外旁白的具体操作，以界面为准。

```text
以提供的产品图为产品外观参考，保持产品的轮廓、比例、颜色、材质、包装及可辨认标识。简洁写实的静物广告，约12秒、一镜到底。产品安置在与参考图相容的干净中性展示空间，最易辨认的一面朝向镜头；背景柔和虚化。眼平略侧固定中近景，产品居中偏下，焦点始终保留在产品及可辨认标识上。开头先清楚呈现产品；随后一束柔和侧光缓慢掠过产品边缘和表面，再稳定下来。产品本身保持静止，画面末尾继续清楚停留。没有画面内说话人。

画外旁白使用所选声线档案，普通话清晰、自然、平静而有向前的力量，在画面中段完整说出：“轻一点，也能走更远。” 句尾自然结束并留出安静余韵。无背景音乐，无字幕。
```

**声音后期交接：**实际听审可灵返回，若旁白完整且音色符合要求，保留该旁白；在获得相应用途许可后，把现成音乐作为独立轨道放入剪辑，选择能覆盖 12 秒且与画面气质相容的片段；旁白期间压低音乐，保障每个字和句尾清晰。先检查输出音轨是否有无法单独去除的音乐或其他声音：若已有混合音乐，不能假称可无损分离；可重新生成、在具备可用分轨时采用分轨，或按下方方案改做独立旁白。最终混音、剪辑和导出时测量成片长度，避免裁掉文案或余音；声音样本本身不是这句广告语的成品录音。

## 不支持时的可选方案

1. **产品图及声线档案可同次使用，但无法上传音乐参考：**采用上面的完整稿，保留生成的声线旁白，后期加入原音乐。保住实际音乐的选择，但音乐不会在生成时作为参考控制画面或原生音乐；若现成音乐较短、需要循环、裁剪或改编，也要取得适用授权并实际听审接点。
2. **希望由模型生成音乐，接受不使用现成音乐参考：**产品图与声线档案仍须确认可同次绑定。使用下方完整替代稿；所得音乐是文字描述引导的新生成声音，不保证旋律、编曲、节奏或质感与未听过的现成音乐相同。实际听到样本后才可由使用者补充具体音乐描述；这不是已观察结果。

3. **产品图和声线参考不能同次使用，或声线档案不可用：**在支持图片输入的可灵 4.0 模式用下面完整画面稿生成，声音独立后制：优先请原说话人录制准确广告语；或在另一个已核验、获得说话人适用授权的声音工具中用样本生成这句旁白，实际听审后与原音乐混音。这样不再由该次视频生成原生使用声线参考；声线相似与否无法预先保证。若图作为严格首帧，必须先确认图片实际画面与起点相容。
