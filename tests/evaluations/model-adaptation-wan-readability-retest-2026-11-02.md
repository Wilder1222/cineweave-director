# 百炼 Wan 3.0：12 秒新品广告与接口交接（条件稿）

## 先看结论

**原要求尚不能作为同一次 API 调用提交。** 截至 2026-11-02 查阅的[阿里云万相 3.0 视频生成 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)规定，`first_frame` 与 `file` 同一请求互斥；前者严格指定首帧，后者用于让模型读取文档。PDF 也尚未提供，广告语未知；因此没有办法核实逐字正确与片尾可读。账号、业务空间、地域及模型权限均未知。用户的全部原目标保留，下面三条是待选方案，不视为已批准。

官方文档列出 PDF 限 100 MB、50 页，并支持官方上传后获得的临时 OSS URL；该文档的文件输入并未列出本地路径或 Base64。**临时 URL 不是公开网页，但文件仍须传输给服务方，不等于文件仍只在本地，也不自动符合公司保密规则。** 先核实公司允许向该地域的百炼服务传输和处理文件、临时文件权限及保留政策；不能以“非公开”为由自行上传，不能用公开 URL。产品图的发送许可亦待核实。本次没有上传、调用或生成。

## 创作基线与 12 秒分镜

假设产品图及产品类别、形态、构图、环境、光线均待实际观察；不预设产品材质、品牌、卖点或包装。优先沿用真实首图的画幅与空间；若它与成片投放画幅不一致，需用户决定如何处理，不能擅自裁切首帧。全片单一空间、同一主体、不增加人物和未经证实的产品功能。空间中的前中后景与光源以源图实际内容为准，不将设计示意写成已观测事实。

| 时间 | 观众获取的信息与画面 | 摄影决定、焦点及切出 |
|---|---|---|
| 0–3 秒 | 第 0 帧严格使用现成产品图，先辨认产品和其原始构图；随后从画面已有状态自然展开，产品本体与标识保持稳定。 | 与首图视点一致，先固定机位；焦点留在产品主体，避免开场运动改写第一帧。到 3 秒产品仍清楚可辨，作为下一节拍入口。 |
| 3–8 秒 | 顺着源图已有光色，让已有光影轻微流动以展示产品轮廓；不新造结构、功能或文字。 | 如素材允许，摄影机从固定状态缓慢小幅推进，因观众此时已认出产品，需要引导注意到主体；焦点持续保护主体和原有标识。8 秒以推进自然减速进入下一节拍，不强制硬切。 |
| 8–12 秒 | 画面稳定成为片尾背景，准确广告语后期逐字叠加；不遮住产品关键外形或已有标识。 | 稳定机位与主体焦点供阅读；文字实际位置、字号、行数及起点待获得文案、画幅后试排。12 秒结束。 |

以上是**一个候选镜头中的三个节拍**，不是要求模型逐帧照时间点执行。8–12 秒的 4 秒阅读窗仅为试排起点，文案未知，不能断言足够。拿到准确文案后在目标设备和实际画幅下逐字校对、试排和试读；必要时先向前调整文字入点或重排 0–12 秒的已有节奏，且文字不能覆盖原始首帧。如果仍不足，明确向用户提出延长、改变画幅／版式或调整文案等取舍；未获选择前不删字、不压到不可读、不改变 12 秒或首帧。成片首帧还需检查导出过程的缩放、色彩和压缩是否满足用户所说的“严格锁定”；API 的首帧模式声明本身不是最终编码文件逐像素验收。

声音先按**无旁白、后期可另配获授权的简洁音乐**规划；若需要原生声音或必须静音，待用户选择。没有口播文案，不虚构功效与声音内容。

## 待选方案 A：保留严格首帧、PDF 留在本地

本方案适合优先保留首帧和不向服务传 PDF：由有权人员在本地打开 PDF，提取原文并校对，生成后在本地确定性排版。**损失：视频模型不读取 PDF**；本地处理和后期排字是新工序。把原文发到模型提示词也属于外部传输，不应自行操作；准确文案只进入本地编辑器。下面提示词不把未知文案或后期流程当成画面：

```text
从输入首帧的真实构图、产品姿态、环境与光线开始。产品形状、包装、颜色和已有标识保持稳定，不添加产品结构或功能。起初摄影机固定，让产品清晰可辨；随后摄影机以很小幅度缓慢推进，已有光影轻柔变化以展示产品轮廓。推进逐渐减速，画面回到稳定，留出清楚、安静的产品画面作为结尾。焦点保持在产品主体；不加入新文字、人物、额外物件或场景切换。
```

**条件 API 请求体模板**（只在图片与外传许可、账号地域、真实入口完成核对后补齐；占位符不是可直接提交的素材）：

```json
{
  "model": "wan3.0-video",
  "input": {
    "prompt": "替换为上面的完整视频提示词",
    "media": [{"type": "first_frame", "url": "待填写符合官方格式且获准传输的产品图"}]
  },
  "parameters": {"duration": 12, "ratio": "adaptive", "audio": false, "prompt_extend": false}
}
```

`duration: 12` 是用户请求值，官方此模式无视频输入时允许 2–30 秒整数；真实账号可用性及返回时长仍需检查。`adaptive` 是设计建议，需以实际源图画幅、返回结果与投放要求核对；分辨率用户未定，勿把默认值当作已确认。图像允许 Base64、官方临时 OSS URL 或公网 URL；本案不使用公网 URL，Base64 仍是向服务方传输。原图格式、尺寸、透明通道和大小按官方参数校验；若转换会改变首图，须先决定严格首帧的验收口径。`audio:false` 是此无旁白草稿的建议，可根据用户声音要求调整。

## 待选方案 B：让模型读取 PDF 与参考产品图

这一单次调用可在官方支持的**参考生视频**中把 `file` 与 `reference_image` 组合，并在本地后期叠加准确广告语。**损失：产品图不再是原生严格首帧，只是参考图**；生成开头可能改变构图与外观。仍须先取得允许向服务传输 PDF、产品图的明确依据；临时 OSS URL 的合规性需另核，不得公开文件。

```text
以图1为产品外观参考，结合所提供文件理解产品信息，制作一支12秒新品广告。画面始终围绕图1中的产品，不虚构文件没有支持的功能、参数或效果。开头让产品完整、清晰地出现；中段以轻微摄影机推进和受控光影突出产品轮廓，尾段推进减速并保持稳定。构图为结尾文案预留清晰空间，产品外形与已有标识尽量保持一致，不添加人物、额外物件和新文字。
```

接口模板（产品图排在参考图片序列第一位，故称“图1”；文档不是 `first_frame`）：

```json
{
  "model": "wan3.0-video",
  "input": {
    "prompt": "替换为上面的完整视频提示词",
    "media": [
      {"type": "reference_image", "url": "待填写获准传输的产品图"},
      {"type": "file", "url": "待填写获准使用的官方临时文件 URL"}
    ]
  },
  "parameters": {"duration": 12, "ratio": "adaptive", "audio": false, "prompt_extend": true}
}
```

官方要求使用 `file` 时 `prompt_extend:true`；不代表模型一定正确理解 PDF 或能逐字排版。产品资料内容、广告语由用户核对，成片准确文字用本地确定性排版；本方案仍未满足严格首帧。

## 待选方案 C：分两次调用，成片首帧与 PDF 阅读分开

片段 C1 目标 0–6 秒，使用方案 A 的 `first_frame` 图生视频，画面从产品原图开始，摄影机固定后小幅推进，出点产品主体完整、焦点稳定；`duration:6`。片段 C2 目标 6–12 秒，使用方案 B 的 `file` 与 `reference_image`，`duration:6`、`prompt_extend:true`；从构图、产品朝向与光线尽量接近 C1 真实采用出点的状态开始，推进减速至稳定片尾，随后本地叠加准确广告语。C2 的参考输入需在看过 C1 的实际出点后决定并确认授权，不把计划状态说成已存在；两段各自调用，6+6 秒仅为剪辑目标，实际返回与衔接须核验。

C1 可复用方案 A 提示词和 JSON，将时长改为 6；C2 可复用方案 B 的媒体结构与参数、将时长改为 6，提示词如下：

```text
以图1为产品外观与构图参考，结合所提供文件理解产品信息。镜头开始时产品完整清晰，产品位置、朝向和环境光尽量与图1保持一致；摄影机轻微向产品推进并逐渐减速，最终稳定在清楚、安静的产品画面。焦点保持在主体，不虚构文件没有支持的功能、参数或效果，不添加人物、额外物件和新文字。
```

**损失与条件：**不是一次生成，PDF 不参与 C1；切点存在外观、位置、光线和运动相位跳变风险，严格连续性与 C2 的首帧均无保证。C2 可引用经用户允许的 C1 出点图，但参考图仍不是严格绑定的首帧。采用窗口和片尾广告语须在实片上重新安排；若连续性或阅读空间不够，不能宣称达成。如公司不允许向百炼传输 PDF，此方案也不可执行。

## 接口和验收交接

- 目标：百炼 HTTP 异步视频生成，模型 `wan3.0-video`；版本及账号实际可见性、业务空间、地域未知。官方示例列出多地域 endpoint，模型、endpoint、API Key 必须同地域；以实际账号为准，不自行猜测。无须提供密钥给本交接。
- 创建请求使用目标地域、对应业务空间的 `/api/v1/services/aigc/video-generation/video-synthesis`，JSON 请求头含 `X-DashScope-Async: enable` 与安全配置的认证；返回 `task_id` 后用同地域 `/api/v1/tasks/{task_id}` 查询，勿在状态不明时重复创建。官方说明任务 ID 及成功结果链接有效期均为 24 小时；实际任务、返回设置和结果当前均不存在。
- A 的绑定是首帧图；B、C2 是参考图加 PDF，二者不能偷换。以上请求体是条件模板，素材和权限未落实前不得提交。精确广告语的唯一来源是经本地逐字核对的 PDF 原文，按实际版面在后期原样输入，不用虚构占位文字替代正文。
- 成片检查：实测时长 12 秒；以用户确认的口径对照最终视频首帧与原图；产品外观和标识；广告语逐字、标点、换行、遮挡及目标设备可读性；画面连续、音乐权利及实际音画；实际返回值与请求值分别登记。无真实图、PDF、返回媒体或试读证据，均未通过。

需要用户决定 A、B、C；并提供可授权处理的产品图、准确广告语及其本地核对方式、投放画幅与阅读设备，以及账号地域和文件传输政策。若不能选任何损失，原始全套要求在所核验的单次 API 组合下仍未解决。
