## 缺少的两次请求、剪辑条件备选

若用户选择接受**多次生成和分镜剪接**，可在正式策划时提出例如：

1. **请求 A，首帧生视频：**仅绑定产品图 `first_frame`，约生成 4 秒，从实际首帧开始采用约 3 秒；人物、画面与产品内容以实际图片为准，不在同一请求添加 PDF 或其他参考。
2. **请求 B，文件参考视频：**在目标地域支持且组织授权将内部 PDF 和产品图传给服务的条件下，独立提交 `file + reference_image`，指定 `prompt_extend=true`，例如请求约 9 秒。此段是根据文件和产品图**新生成**的视频，不是对 A 返回视频的编辑或自动延续；不能声称它严格沿用 A 的末帧、机位或产品细节。
3. **本地后期：**核对 PDF 原页与提取出的准确广告语，把它作为独立文字层放在 B 的末尾约 3 秒，按实际素材选择 A、B 采用窗口并完成约 12 秒总长；检查首帧、画面衔接、文案、音画和最终导出。

对应损失和前提：与一镜到底不同；不同生成片段可能在身份、外观、文字、光影、机位及运动上不连续；文件送往供应商而不是留在本机；模型理解文件不等于拿到了精确可核对文案。时长只是交接示例，仍须核验当地区模式、返回长度、剪切点和可读性。最终成片首帧是否符合用户定义的严格标准只能基于实际成片验证；不能因 API 定义了 `first_frame` 就推断经过缩放、编码和剪辑后的逐像素一致。此备选未获用户选择和批准，不可默认执行、上传或消费额度。

## 地域、URL 和私密性

中国站 API 对 `file` 写明公网 HTTP(S) 或通过官方上传流程获取的 `oss://` 临时 URL；不能把本地文件路径直接冒充 `file.url`。盲测稿对该限制限定为中国站，并区分 PDF 不公开与仍向供应商传输，未擅自要求公开或声称已上传。不同地域／入口的 URL 规则应按该地域当前文档和账号能力确认，不能将中国站规则未经核实推广至其他区域。

[官方临时文件指南](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)描述当前北京和新加坡可用、48 小时有效、文件绑定模型和主账号，并称临时 URL 不应用于生产环境；相关适用性、组织授权、保密条件及可用稳定存储仍待确认。临时不公开不等于未向供应商发送，也不等于组织已批准外传。文件 PDF 格式、最多 100 MB 和 50 页的声明与当前中国站 API 所列限制相符。
