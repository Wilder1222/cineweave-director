**A．删除杯子，尽量保留原视频**

执行条件：在官方 Kling 4.0 创作工作区选择 **Omni Reference**，上传实际原片作为待编辑主视频，并核对真实素材标签。该指南列出：单段视频 3–30 秒、≤300 MB、宽高比 2:5–5:2；所有视频合计≤30秒、最多5段。实际文件及账号入口仍须核对。编辑指令应明确使用 `Edit @Video1`，并列出保留项。[官方指南](https://kling.ai/quickstart/kling-4-model-user-guide)

若有多只杯子，应先补充目标的位置或外观。假设绑定标签确为 `@Video1`，提示词为：

```text
Edit @Video1。只删除桌上的目标杯子，清除该杯子对应的投影和倒影，自然补全它原先遮挡的区域，使纹理、透视和光照在连续画面中一致。

其他画面内容尽量保持原样，包括人物及其动作、其他道具、桌面结构、背景、构图、摄影机运动、光线、色彩和原片时长。修改范围限于移除杯子及必要的区域补全。
```

“保留”是验收目标，不能保证逐像素无损；返回后须对照原片检查杯子残影及无关区域变化。

**B．只借运镜，生成全新画面**

执行条件：在官方 **Omni Reference** 中绑定实际视频，明确它**只负责摄影机路径及运动节奏**；另外提供新主体、场景和动作的完整描述。该工作区的视频规格同为单段3–30秒、≤300 MB、比例2:5–5:2，全部视频最多5段且合计≤30秒。官方指南支持运镜参考与更换主体、背景，但这不证明存在单独的“运镜参考”开关。[官方指南](https://kling.ai/quickstart/kling-4-model-user-guide)

新内容尚未指定，以下以“沙漠公路上的白色跑车”为可替换示例：

```text
@Video1 仅用于参考摄影机的运动路径、方向、速度变化及起止节奏。视频中的人物、道具、场景、表演、光色和声音均不作为迁移内容。

生成全新的写实画面：一辆白色跑车停在沙漠公路上，远处是连绵沙丘，黄昏阳光照亮车身与沙面。摄影机围绕这组新主体与空间，按照 @Video1 的运镜方式展开拍摄，保持透视和空间关系连续。无对白、无字幕、无背景音乐。
```

此处不用 `Edit @Video1`，也不加入“其余画面保持不变”。原片运镜尚未读取，不能擅自称其为推镜、环绕或跟拍。

**C．Wan 首帧与运动稿冲突**

冲突成立：**右手在身侧且能够够到玻璃，只说明可达，不等于开场已靠近，更不等于已接触或抓握。** 应保留首帧，补齐伸手过程。

执行条件：

- 实图须与假设一致，右手能够完成伸手和抓握，运动路径可行。
- 玻璃须是可移动、可由右手稳定握住并抬起的物体；不能擅自理解成玻璃杯。
- 生成时长须容纳伸手、接触、握稳和抬起。
- 将实际图片绑定到所选 Wan 入口的**首帧输入**。例如百炼 Wan 3.0 API 使用 `input.media[].type=first_frame`；其他版本另核，提示词不能代替图片绑定。[Wan 官方 API](https://www.alibabacloud.com/help/en/model-studio/wan3-video-generation-api-reference)

满足这些条件时，将原运动句替换为：

```text
右手从首帧所示的身侧位置开始，连续抬起并伸向玻璃，逐渐靠近可抓取的部位；接触后，手指合拢握稳，再将玻璃平稳抬起。手与玻璃的运动连续，接触前玻璃保持原位。
```

若玻璃是固定窗玻璃，“拿起”仍不可执行：可另选“伸手后触碰玻璃”的动作，或更换为可拿起的素材；这两项都是待选择的替代方案。
