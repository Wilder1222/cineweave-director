按 **8 秒、两个镜头**设计。以下是给 Seedance 2.5 的中文文字稿；时码为剪辑目标，尚无视频验证。

空间假设：店员在画面左侧，访客在右侧，隔柜台交接一把银色钥匙；店门位于访客右后方。两镜保持同侧轴线、相同光色。

**S1｜0–4 秒｜交接细节**

> 固定机位，略俯拍手部近景。柜台边缘位于前景，双方的手和钥匙位于画面中央，店内背景柔化；焦点保持在手指与钥匙的接触处，使交接清楚可见。  
> 店员右手捏住钥匙齿端，从画面左侧递向右侧访客。访客右手迎上，拇指与食指夹住钥匙头部；夹稳的同一节拍，店员手指刚好松开并撤离，钥匙始终有支撑。访客右腕随即开始向自己方向回收，在动作刚启动时硬切。  
> 双方视线仍落在交接处，眼睛在本镜画外，作为下一镜继承状态。约3.6秒，门外传来一记钟响；访客此时不转头。保留连续店内底声，无对白、无音乐。

**S2｜4–8 秒｜收钥匙，再转头**

> 动作匹配硬切到访客腰部以上的中近景，摄影机仍在轴线同侧并保持固定。前景下缘保留柜台，访客的脸、右手和完整收手路径同时入画；店门位于右后方背景。清晰范围兼顾脸与手，不在两者之间切焦，便于同时读到持物和反应。  
> 开镜承接上一镜的运动：钥匙已经夹在访客右手拇指与食指之间，店员手指已脱离，正在画面左缘撤回。访客右手沿原方向继续向胸前收钥匙，速度自然连续，不重新接取、不换手。  
> 钟声余音跨剪点继续衰减。访客先完成收手，约4.8秒视线转向右后方店门，随后头部跟着转过去；神情由专注交接变为留意声源。钥匙始终留在右手、停在胸前。末尾保持朝门外倾听，店内底声连续，无对白、无音乐。

**剪点与声音桥**

| 标记 | 设计位置与状态 |
|---|---|
| 画面剪点 | **4.0秒硬切**。S1末：访客已夹稳，店员刚脱手，回收动作已启动；S2首接下一运动相位，钥匙方向、右手夹持位置与回收方向一致。属于继续同一动作。 |
| 钟声起点 | **3.6秒**，先于画面剪点，也先于访客转头。声源来自右后方门外。 |
| 声音桥 | 同一记钟声从S1跨入S2，约**5.3秒**衰减结束；剪点处不重敲、不截断，响度和空间位置连续。 |
| 反应顺序 | **钟响 → 继续收钥匙 → 视线移向门口 → 转头**。 |

钟在两镜中始终处于画外，因此标为 **“跨剪点画外声桥”**；仅凭钟声提前或余音跨切，不能确定它属于 J-cut 或 L-cut。
