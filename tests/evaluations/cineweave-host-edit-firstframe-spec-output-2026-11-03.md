**C．Wan 首帧与运动稿的冲突检查**

题设支持“右手在身侧且能够够到玻璃”，**不能据此推出“开场已靠近玻璃”**。若玻璃恰在身侧近处，两者可能相容；没有实图，不能认定。遵循首帧的方案应保留身侧手位，补全：

**伸手靠近 → 接触 → 稳定握持 → 拿起。**

执行条件：

- “玻璃”须是可单手拿起的独立物件；若指固定窗玻璃，“拿起”目标本身不成立，不能擅自改成擦拭。
- 以下稿件适用于右手空闲、尚未接触目标、路径无遮挡，且现有构图能容纳拿取过程的情况。这些仍须对实图核查。
- 实图须绑定到实际 Wan 版本的首帧入口。例如百炼 Wan 3.0 API 使用 `first_frame`；普通参考图绑定不能替代它。[官方首帧说明](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)

条件成立后使用：

```text
从首帧中右手位于身侧的姿态开始，保留人物、玻璃物件及其原有空间位置。

右手先从身侧自然抬起，沿连续路径伸向玻璃物件；随着距离缩短，手指调整为适合该物件形状的抓握姿态。手指先接触物件，再合拢形成稳定握持；握稳后才缓慢向上拿起，物件随右手离开原来的支撑位置。

伸手期间物件保持原位，拿起后手指与物件的接触连续。沿用首帧机位与构图，摄影机固定，使伸手、接触、握持和抬离的过程清楚可读。
```

若时长不足，应增加动作时间，不能通过开场跳到玻璃旁来省略伸手过程。
