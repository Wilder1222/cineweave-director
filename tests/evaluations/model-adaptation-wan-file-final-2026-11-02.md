# 12 秒新品广告：Wan 3.0 分镜与接口交接

## 结论与原要求

原要求保留：现成产品图**严格锁定首帧**；Wan 3.0 **读取公司内部 PDF**；PDF 的**精确广告语原样**出现在画面最后；成片 12 秒，PDF 不公开。当前没有产品图、PDF、广告语、账号及地域信息，尚未读取材料或生成视频。

按 2026-11-02 查阅的[百炼 Wan 3.0 API 文档](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)，同一次请求中的 `first_frame`／`last_frame` 与 `file`／各类参考互斥；因此，**不能用一次 Wan 3.0 API 请求同时实现严格首帧和模型读取 PDF**。PDF 原文又未提供，不能编造广告语，也不能保证模型生成文字逐字准确。即使拆成两次调用，也不等于同一次请求同时具备两种输入；文件参考模式的理解结果也不是逐字提取凭证。

以下是供选择的条件方案，**尚未选定**：

| 方案 | 保留 | 明确损失与条件 |
| --- | --- | --- |
| A：严格首帧 + 本地提取与后期排字 | 产品图用 `first_frame`；最终画面叠加经人工核对的 PDF 广告语；12 秒成片 | Wan 不读取 PDF，改由有权限人员在本地提取并逐字校对。为验证“严格”，需检验实际首帧及最终导出；输出编码和缩放可能改变像素。 |
| B：PDF + 产品参考图 | Wan 同请求读取 `file` 和 `reference_image`；产品图仍参与视觉参考；12 秒 | `reference_image` 不是 `first_frame`，首帧不能宣称严格锁定；文件输入要求 `prompt_extend=true`，改写及生成文本均不能保证广告语精确，仍建议本地核字并后期排字。需先确认组织允许向所选服务传输 PDF；不公开不等于不向供应商传输。 |
| C：仍要求全部原样 | 所有原始要求作为未解决目标保留 | 不提交互斥组合；等待支持同次严格首帧及 PDF 输入的经核验接口，或调整需求。此处没有证据证明已有这样的替代接口。 |

## 导演工作稿：产品由静到活，落在清晰尾版

产品品类、外形、广告语和实际首图未知；以下只使用源图中真实存在的产品、环境及光线，不假设产品用途、功效、标志、瓶盖动作或背景。风格暂拟克制、质感清晰的产品广告。画幅以产品图与最终投放要求为准，当前不假定横竖比例。产品外观、包装文字和品牌标志以实际图为准，不能因视觉设计而改造。

画面为一个连续镜头内的三个导演节拍，总长 12 秒；这不是三个独立生成任务，也不是接口保证逐秒切点。摄影机与产品的空间关系继承真实首图；柔光方向继承首图。画面留给尾版的区域应在看到实图后确定，不得预先假定有空白。若实图不适合推镜或尾版构图，先回到导演稿调整，不伪称首图已有相应结构。

| 时间 | 导演意图、画面与摄影 | 出点与声音 |
| --- | --- | --- |
| 0–3 秒 | **辨认产品。** 0 秒完整呈现实际首图状态：景别、机位、前中后景、位置与光照都由首图决定；固定摄影机，焦点留在产品最有辨识度的可见部分。静止的原因是让观众先识别真实包装。 | 产品位置和朝向持续；轻柔氛围音乐由后期另配，无对白。 |
| 3–8 秒 | **突出质感。** 若真实图允许，镜头从原机位极缓慢靠近，突出可见材质和轮廓；前景若有实物不得穿模，背景不过度变化，产品保持完整、文字标志不被新造或重绘。焦点保持产品主体。 | 靠近后保持相同朝向与光线，以现有产品状态进入尾版；音乐渐起。 |
| 8–12 秒 | **留足阅读。** 镜头停止或近乎静止，焦点仍在产品。画面尾部的准确广告语使用后期文字层排版，最后至少约 3 秒保持可读；具体字号位置按文案长度和产品图试排。 | 12 秒结束；音乐平稳收束。最终文字不遮挡产品关键标志，文字版本与 PDF 核对。 |

如果首图是复杂海报或已有小字，缓慢靠近可能放大生成变形或导致裁切；优先固定摄影机并由真实样片判断。画面运动和尾版节拍是导演意图，返回视频须逐帧检查，不能仅凭提示词判定实现。

## 方案 A：首帧生成条件稿

先由有权限人员读取本地 PDF，定位目标页，将广告语逐字提取，与原 PDF 复核包括标点、空格、大小写、换行及特殊字符；文案未经核实不得填入。保留原样文本供本地排字，不把未公开 PDF 或文案发到公共位置。将真实产品图以 `first_frame` 绑定，接口素材不能仅写本地路径。图片上传到供应商或发送 Base64 前，确认素材许可、公司政策和区域。若不允许向服务发送产品图，本方案也不能执行。

**可复制的生成正文（不含未取得的广告语）：**

```text
从已绑定的产品首帧开始，准确继承画面中产品的外形、包装、标志、摆放、环境和光线，不添加未出现的产品部件或功效展示。前3秒摄影机固定，让产品清晰可辨；随后摄影机从原机位极缓慢靠近，突出产品现有材质与轮廓，保持产品完整、朝向与环境连续；最后画面稳定，让产品保持清晰并为后期广告文字预留适合的空间。不要重绘或添加包装文字、标志、字幕和额外物品。无对白，无旁白。
```

参数与媒体旁路表（请求值是计划，解析值／返回值均未知）：

| 项 | 请求／待绑定 | 核验点 |
| --- | --- | --- |
| 平台与接口 | 百炼 HTTP API，模型 `wan3.0-video`，首帧生视频 | 当前账号、业务空间和地域能否使用该模型；模型、Endpoint 与 API Key 必须同地域。 |
| 输入图 | `input.media` 一项，`type=first_frame`，`url` 为符合接口的图像数据或授权临时定位 | 图片未提供；检查图像内容及 JPEG/JPG/PNG 无透明通道/BMP/WEBP、单边 240–8000 像素、不超 20 MB、长宽比不超 8:1；实际区域的具体支持再核验。 |
| 生成时长 | `parameters.duration=12` 秒 | 官方文档支持 2–30 秒；界面解析值、返回长度仍未知。 |
| 画幅和分辨率 | `ratio=adaptive`，分辨率暂拟 `1080P` | 随源图自适应画幅；源图、目标像素尺寸和最终发行要求尚未知。 |
| 声音 | `audio=false`，后期另配获授权音乐 | 以实际返回音轨为准，不构成已配乐。 |
| 输出 | 生成视频，再做尾部文字合成 | 模型首帧规范和最终导出首帧分别检查；若严格逐像素为硬验收项，先定义尺寸、色彩、透明度、编码及对比方法，无法满足则不得称通过。 |

**请求体骨架（示意，不含凭据或真实素材，替换占位后仍需按当前地域接口检查）：**

```json
{
  "model": "wan3.0-video",
  "input": {
    "prompt": "填写上方完整生成正文",
    "media": [{"type": "first_frame", "url": "已授权图像数据或临时定位"}]
  },
  "parameters": {"duration": 12, "ratio": "adaptive", "resolution": "1080P", "audio": false}
}
```

首帧与 PDF 不在此请求中混用。后期将已核实的广告语作为独立文字层叠加在 9–12 秒；保持原文字符，不做自动改写或替换标点。导出 12 秒，复核画面首帧、文字、时长与完整播放，保留可编辑工程和核对过的文本。若广告语过长导致三秒不可读，延长尾版占比或缩短前段，仍维持 12 秒；文字本身不删改。

## 方案 B：文件与产品参考条件稿

仅在用户选择本方案、确认组织允许将 PDF 和产品图传给对应地域的百炼服务后执行。官方中国站文档列出的文件输入为公网 HTTP(S) 或通过官方上传流程获得的临时 OSS URL，**不要求公开 PDF**，但临时上传仍向服务传输内容；具体地域、账号和临时文件可用性需核验，不能把某地域支持外推所有地域。文件限制为最多一个、不超过 100 MB，PDF 不超过 50 页；不能直接将本地路径放到 `url`。中国站临时文件方案的有效期及生产适用性以[临时文件指南](https://help.aliyun.com/zh/model-studio/get-temporary-file-url)和实际组织政策为准。

`reference_image` 仅作为产品外观参考，**不承担严格首帧**；`file` 负责参考文档内容，图与文件可以组合，但不得增加 `first_frame`。`prompt_extend=true` 为文件输入必需值。若 PDF 的内容中包括不适合外传的其他信息，先由授权人员确认可用的材料范围；本方案不承诺文件中只有广告语被处理。

**可复制的生成正文：**

```text
制作12秒克制、清晰的新品广告。图片1只用于参考产品真实外形、包装和标志；文件用于理解产品和品牌资料，不添加文件没有支持的功效或事实。开头用清晰稳定的产品画面，让产品易于辨认；中段从原有视角缓慢靠近，突出已有材质与轮廓，保持产品外观与环境连续；最后稳定画面，为后期精确广告语留出可读空间。不要自行添加或重绘文字、标志、字幕或额外产品部件。无对白，无旁白。
```

参考请求体结构：

```json
{
  "model": "wan3.0-video",
  "input": {
    "prompt": "填写上方完整生成正文",
    "media": [
      {"type": "reference_image", "url": "已授权产品图定位"},
      {"type": "file", "url": "已授权PDF临时定位"}
    ]
  },
  "parameters": {"duration": 12, "ratio": "adaptive", "resolution": "1080P", "audio": false, "prompt_extend": true}
}
```

此路径让模型理解文档，不提供可靠的逐字文本提取回执。为满足画面最后的精确原文，仍须授权人员本地取字、复核并后期排字。若坚持文字由模型原生直接绘制，可在取得文案后把精确原文放进提示词，**但无法保证逐字准确**，不合格需人工修复或重做。

## 接口操作与验收

1. 确认选 A、B 或继续等待 C；提供可用的产品图、目标文案所在 PDF 页或经核对的原文、最终画幅及分辨率要求。确认账号、业务空间、地域、模型开通和素材传输授权；不发送 API Key、签名链接或内部 PDF 到对话。
2. 按对应地域的[官方 API](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)创建异步任务，HTTP 请求头包含 JSON 内容类型、Bearer 鉴权及 `X-DashScope-Async: enable`；密钥由操作者的安全环境提供。只有在各项前提确认后才能提交。本方案没有实际请求、任务 ID 或上传回执。
3. 若提交已产生真实任务 ID，按官方接口轮询；不因为等待而重复创建任务。记录请求值、界面解析值、任务状态、实际返回值和可访问成片，按官方时效及时安全保存，勿公开临时链接。
4. 使用真实文件检查：方案 A 的生成首帧和最终成片第一帧与原图按事先约定的精确标准比较；整个产品形状、标志、文字及背景是否漂移；时长、画幅、音轨是否合格；8–12 秒画面是否适合排版。方案 B 额外检查产品参考偏差及文档中涉及的事实是否准确，但不将视觉相似称作首帧锁定。
5. 审核尾版文字逐字符、标点、大小写、空格与换行，并人工对照原 PDF、检查字幕安全区及最终成片完整播放；确认音乐授权。若首帧、文案或实际播放不合格，返回对应环节修正，不把文字方案当作媒体验收。
