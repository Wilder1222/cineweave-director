建议用**手部近景 → 访客中近景**，在收手途中硬切。暂拟现代小店、16:9、总长约7秒；以下秒数是剪辑设计目标。

S1（0–3秒）：看清钥匙交接。

```text
写实风格，16:9，现代小店木柜台，柔和日光。店员穿深灰衬衫、黑围裙，位于画左；短黑发访客穿米色外套，位于画右。

固定手部近景，柜台边缘在前景，两人的右手与一把银色钥匙位于画面中央，背景货架虚化。焦点保持在钥匙与双方指尖，让交接接触清楚可见。

店员右手捏住钥匙齿端，递向访客。访客伸出右手，拇指与食指夹稳钥匙圆头的同一瞬间，店员指尖刚好松开、离开钥匙。钥匙由访客右手独自夹持，没有悬空或掉落。店员空手向画左撤回，访客右手开始向画右、朝自己胸前回收。

采用出点：访客右手已经出现回收位移，但钥匙仍在柜台上方，尚未收至胸前。双方头部与眼睛不入画；视线按设计仍朝向交接处，访客尚未转头。

镜头尾部先传来门外一声钟响，余音延续。室内环境底声稳定。无对白、无音乐、无字幕。
```

S2（3–7秒）：接续收钥匙，再回应钟声。

```text
写实风格，16:9，现代小店木柜台，柔和日光。短黑发访客穿米色外套，位于画右；穿深灰衬衫、黑围裙的店员位于画左。店门在访客右后方，钟在门外、不入画。

切到轴线同侧、稍宽的固定中近景，取访客头部至腰部，右手从柜台收到胸前的路径完整入画。前景保留柜台，背景带到画右店门。脸与右手保持可读，摄影机不跟随转头，让观众看清反应。

开场访客头仍朝柜台，眼睛仍看右手中的钥匙。右拇指与食指夹着银色钥匙圆头，承接刚开始回收的运动，继续向胸前收回；店员右手已经空开，不再接触钥匙。不重演夹住或松手，不直接跳到收手完成。

开场只有门外钟声的连续余响，没有第二次敲击。访客听见钟响后，视线才移向画右店门，随后头部转向门口；收钥匙的动作继续完成。结束时右手夹着钥匙停在胸前，目光留在门口。店员脸与视线不入画，保持关注交接处的承接设定。

室内底声连续，无对白、无音乐、无字幕。
```

画面与声音按同一个剪点 **C＝约3秒** 对齐：

| 标记 | 画面／声音 |
|---|---|
| C前约0.2秒 | 门外钟声首次起音；访客尚未转头。 |
| C：画面硬切 | S1右手刚开始回收 → S2紧邻的下一运动相位。匹配手的高度、夹持位置、钥匙朝向、速度与方向。 |
| C后约0.3秒 | S2中访客视线移向门口，随后转头；右手继续收钥匙。 |
| 跨越C | 同一次钟声的余响连续衰减，室内底声不断。后期用同一条钟声跨切，S2不重新起敲击声。 |

这是**跨剪点的画外声桥**：钟始终不入画，按本方案无需强行标为 J-cut 或 L-cut。
