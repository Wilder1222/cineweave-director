# 澈澈婴幼儿短片：当前创作工作单

用户授权：完成并根据家长亲述补充修订故事、分镜及Seedance 2.5提示词。当前范围为B01—B14、F01—F14、G01—G13，共41条；保留原有片目并增加九条真实过程启发的原创改编。每条30—60秒、9:16原创三维生活动画；交付完整文字设计稿，不执行媒体生成或发布。当前片目见相邻目录baby-family-short-video-topics.md，来源采用与排除范围见research-adaptation.md。宝宝的名字由用户确定为“澈澈”。

## 统一原创设定提案

- 宝宝名为“澈澈”，不写性别与精确月龄。圆润脸颊、深棕眼、短黑绒发、额前一小撮向右弯的头发；奶油色棉连体衣。外貌与服装为暂拟设计，以用户后续人物参考为准。不同能力阶段保持同一身份，四肢与躯干随阶段自然变化。穿袜/脱袜题材在当条明确左右及状态。
- 爸爸：短黑发、砖陶色棉衬衫、深灰长裤；温和、有自己的手头事，不固定成笨蛋。妈妈：深棕低马尾、雾蓝棉上衣、米色长裤。爷爷：灰短发、浅灰开衫、深蓝长裤。不存在其他未经交代的人物。
- 可以自然加入中文台词，由实际出场的家人用简短普通话交流，逐句注明对象、语气、发声窗口和可见口型；不要求每片都有对白，也不以旁白解释已经看得见的动作。澈澈按本条婴儿能力用笑声、咿呀和动作回应，不默认说完整句子。
- 生活物理与婴儿动作尺度；专注、停顿、动作不完全熟练，避免成人阴谋表情。没有超能力、成人式宝宝对白、教育旁白或强制反转。
- R0：仰卧、伸手探索、翻身的片段。R1：坐姿、抓握、交换与咿呀互动。R2：爬行、扶物站立。R3：短暂放开支撑迈一步。R4：稳步行走与初语。R5：幼儿拼图与短句。它们是角色在各条故事中的能力标签，不是统一医学顺序或月龄标准。R4/R5需成长后的幼儿造型，R0/R1不能借用较大幼儿的步态或长句；原帖自报年龄只保留在来源说明里，不自动成为澈澈的精确月龄。
- 世界空间有两套：L 客厅，北墙固定沙发、西窗、东侧走廊入口、中央奶油地垫；N 休息角，西窗、北墙婴儿床、床南侧照顾者座位、东侧门。白天西窗柔和漫射光为主要物理光源，暖色墙面反射；休息片可用同窗较弱的午后光，不能反打交换窗门。
- 婴儿车 S01：停放、轮刹锁定、雾蓝布座、低矮圆钝前沿、深灰固定框架。车座与前沿距离允许宝宝屈膝搭脚，躯干在座内有支撑；不通过悬空身体或腿穿框达到姿态。
- 道具：P01 珊瑚色大软布环；P02 芥末色软布球；P03 鼠尾草绿色大软积木；P04 奶油布巾；P05 蓝绿布书（其中一页缝入响纸）；P06 成对雾蓝短袜；P07 浅木色玩具盒。每条使用哪些及起始归属需写清。

## 每条必须实际写出的正文

1. 精确总时长、能力阶段、角色、场景、观察/戏剧任务、场次空间与光位、人物各自任务及入态。
2. 完整可读剧情正文，约 200—400 汉字为适宜尺度，可因故事调整；自然交代空间，再写全事件与结尾。不能只有一句梗概、提纲或“同上”。对白可以为零，有对白须逐字进入镜头声音。
3. 完整逐镜设计，通常 5—8 镜但按动作需要调整；每镜包含目的、景别/机位/构图/轴线、相机行为和理由、焦点、入态、分阶段动作及各阶段秒数、声音、出态、切点与连续性（画内可见/画外继承分清）。镜长与阶段相加准确，所有镜合计总时长。
4. 每镜两份实际可复制的完整母稿：单一“开始画面”正文；“视频变化”正文。引用共享风格时仍应写出本镜人物、姿态、物件、空间、动作、摄影、焦点与声音等必要信息。无需绑定供应商模式，不虚构生成回执。
5. 每镜构图示意布局对象 2—5 个（见结构）。这些将真实渲染成带箭头/标签的示意分镜，不当作生成关键帧。
6. 每条准确台词表（无则空数组）、声音设计、连续性硬锁、两项以上可否定的试片/试剪验收点，以及设计风险与待媒体项。

## 工作数据格式（仅本次排版源，非 CineWeave 正式契约）

各创作组写一个 JSON 文件，UTF-8，无代码围栏，形如 {"group":"B","stories":[...]}。每条字段：

```json
{
  "id":"B01","title":"脚就放这儿","duration":30,"stage":"R1",
  "characters":["澈澈","爸爸"],"scene":"L","intent":"...",
  "space":"方位、人物/道具区域、轴线、物理光源与可达机位...",
  "performance":"每个角色持续任务、可接收刺激与表演尺度...",
  "story":"完整场次正文...",
  "beats":[{"id":"B01-b1","text":"前态、刺激/行动、后态与观众所知...","shots":["B01-S01"]}],

    "id":"B01-S01","seconds":5,"beat":"B01-b1","purpose":"观众得到的新信息/观察任务...",
    "framing":"景别、机位高度/朝向、轴线侧、前中后景、画面左右与接触可读性...",
    "camera":"固定/运动路径、触发及这样拍的理由...","focus":"目标及保持/转移的时机...",
    "start":"具体起态...",
    "phases":[{"seconds":2,"action":"完整可表演过程与视线..."},{"seconds":3,"action":"..."}],
    "sound":"准确对白/咿呀/前景拟音/环境声及同步，必要音乐...",
    "end":"具体终态...","cut":"为何在此切、相邻动作/视线/声音如何承接...",
    "continuity":"画内实际可见的持物/接触/视线；画外继承哪些状态...",
```
