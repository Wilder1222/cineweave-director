# 小样、声音与剪辑交接

本次完成的是剧情、逐镜导演稿和构图示意。以下为待执行的媒体试验，不是生成记录、实际费用或成片审片结果。生成供应商、具体入口和账号权限尚未指定；不据文字母稿假定任何模型能完成婴儿角色或精确动作。

## 六组优先试验

| 试验 | 输入与镜组 | 要观察的实际结果 | 否定条件 |
| --- | --- | --- | --- |
| T01 换脚搭沿 | 共享 C01/S01 设计及 B01-S02—S04；先核实目标入口对婴儿参考的可用性 | 右脚接触后收回、双脚回座、左脚抬起搭沿，腿从髋到脚连续，车架不变 | 脚左右互换、从框架穿过、身体失去支撑、车沿高度无故变化 |
| T02 布环与两只成人手 | B02-S04—S07 的对应母稿，P01 一只 | 宝宝右手释放，爸爸右掌接住；成人左食指被宝宝右手握住，环仍留右掌 | 多环、缺手、多手、隔空粘附、未交接即换持有者，或必要接触一直被遮挡 |
| T03 连续翻身 | G03 的翻身主镜及相邻镜，具体镜号以 G 组当前稿为准 | 肩—躯干—骨盆的连续滚转，前臂有落点，翻完才抬脸 | 主动作靠切镜省略、手臂穿身、凭空换左右、母亲未入画却产生托力 |
| T04 支撑与迈步 | G09、G10 的准备/主动作/结果镜，具体镜号见当前稿 | 接触、重心与脚底次序可见，成人守候与最终接抱有实际路径 | 手未松就被称独立迈步、双脚漂浮、成人跨越不可能距离接抱或婴儿比例改变 |
| T05 三人注意与自拍 | F03、F04 的共享镜及反应覆盖 | 每人先收到可见/可听刺激再回应，手机视角能拍到三人，照片来自同一现场姿态 | 三人无由同步转头、手机朝向不成立、照片凭空多角色或重排空间 |
| T06 声音与等待 | F08/G08 对应发声镜、F05 音乐停止段；按逐镜实际文本制作声音 | 声源人物和反应次序清楚，音乐在设计结束处停止，咿呀/笑声/呼吸不压住关键动作声 | 声音提前泄露反应、对口型错人、音乐未停却称无声续舞、用罐头笑声替代角色表演 |

这些试验先验证最可能失败的依赖。每组可先限制为少量候选、一次针对根因的修订；同一错误重复出现时重新检查输入与路径，必要时改为可控三维制作。候选数量与费用上限在实际执行前按用户预算确定，本稿不授权付费生成。

## 输入选择与回流

1. 人物/服装/道具图按职责绑定：身份图不自动决定首帧姿态。若采用首帧入口，实际首图必须符合该镜开始画面中的左右位置、手脚、接触、视线、光向与裁切。
2. 只有当前平台确认支持的模式才可使用；文字/参考驱动、单首帧和三维直出可以逐镜选择。分镜示意板不是身份参考，也不能假定上传整板就能按格正确执行。
3. 返回时记录准确镜号、源稿定位、采用候选、返回规格、实际可用区间、问题与是否有可听音轨。不把 API 成功等同于导演采用。
4. 每镜实际采用区间应覆盖该镜全部必要动作，保留剪点所需余量；具体生成时长档位依目标入口核实，不把计划镜长当作模型精确切点保证。
5. 共享资产改变后，复查真正消费它的镜头。文字、示意板、实际图像、实际运动、实际声音与作者选用分别判断。

## 剪辑与声音

- 设计时间基准为 24 fps，镜头按整数秒累计成帧区间。每条总长 30—60 秒；实际声长尚未测量。
- 同一空间底声跨切镜自然延续；动作拟音发生在可见接触之后或当时。画外声与跨镜声音桥按实际声画归属处理，不泛称 J-cut/L-cut。
- 成人台词如果存在，以各条准确台词表为唯一文字；自然咿呀、呼气和笑声按声源与触发制作。没有台词不等于成片完全无声。中文台词默认自然普通话，先核对发声人、对象、逐字内容、实际语速及可见嘴部；台词、笑气与遮嘴动作按各镜具体先后执行，嘴部可见时随发音变化，不以闭唇静态图冒充口型同步。
- 不为了配乐节拍改掉抓稳—释放—接住等因果顺序。片尾可以保留持续呼吸、手上动作或安静对视，不机械定格或加总结字幕。
- 媒体到齐后逐条连续播放，检查相邻动作相位、物件数量/归属、世界门窗光位、听觉转场和关键声音；本次没有进行这项播放验收。
