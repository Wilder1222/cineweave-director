# Seedance 2.5 设计与输出优化 · 2026-11-08

本记录分两个阶段：原始创作与工程试跑使用原工作区含历史未提交内容的3.2.2草稿（55份参考、698个分发文件）；提交阶段仅移植本轮精确增量到远端3.3.0（49份参考、678个分发文件）。597项回归属于原始草稿快照，主线集成的实际检查另记于文末；两组数量不互相替代。

## 研究依据与范围

本轮依据用户指定的[官方提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)，主站读取超时后读取同一内容的[官方文档镜像](https://console.volcengine.com/ark/region%3Acn-beijing/docs/seedance-2-5-prompt-guide)，页面标注更新于 2026-11-03。结合[模型教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)及[任务 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)区分写作建议和接口约束。指南链接的[飞书模板](https://bytedance.larkoffice.com/docx/OsiUdR1OxoDqvnxsK8LczYx7nPd)需要登录，本轮未读取，不声称采用其内容。

事实：模型区分参考、编辑、延长及参数首尾帧；参考关键帧与参数首尾帧的约束不同。连续整数秒、素材职责、精准参考去重、分层声音控制和编辑范围是可改变输出的方法。主体数量、简洁分镜、MOV 和片长经验不能替代 API 硬限制。指南的可见示例不证明当前账号或本轮生成质量。

设计取舍：复用已有模型实践页及平台适配流程，按任务编译完整复制稿；不新增平台运行时、数据契约、供应商调用或常驻知识页。现行 `PromptProjectionPlan` 不覆盖一般视频和 50 项多模态输入，继续使用正文及旁路参考／设置表，不伪造规范覆盖。

## 实施顺序

1. 保留已有未提交修改，核对专业副本是否存在独立漂移，记录当前校验阻断。
2. 在现有模型实践页补齐任务分流、素材精简判断、时间／声音投射、编辑与延长的原创完整条件稿；不复制官方案例。
3. 用短路由接入导演入口与平台作者源，平台中立文档只补通用的职责去重方法；记录变更。
4. 同步受影响的专业副本，核对全部导出字节；运行技能格式、链接、回归、构建及包内检查。
5. 以独立请求评估实际输出，按观察到的问题修订；文字行为、工程检查和媒体验收分别报告。

## 正反验收

| 场景 | 应有结果 | 不接受 |
| --- | --- | --- |
| 无素材，只要一条新视频提示词 | 一条自包含正文、适度镜头与声音设计 | 虚构上传图号、强加整套项目 |
| 给定动作／运镜参考 | 具体职责与排除，精准已核参考减少复述，保留必要因果和硬锁 | 将参考演员身份混入角色，文字与精准参考互相冲突 |
| 严格首帧加视频／声音参考 | 就近指出方舟模式互斥，保留条件稿与控制损失 | 将参考图称作已锁定首帧或暗中改模式 |
| 宫格与独立关键帧 | 分别交接剧情参考与有序关键帧；后者首句明确顺序 | 承诺整板逐格严格复现，冒称图片已绑定 |
| 小数秒母稿与复杂动作 | 原稿精度保留；平台稿用镜号／相对节拍或提出待确认整秒安排 | 默默四舍五入改变剪辑长度，硬塞每秒动作频率 |
| 仅编辑源片某段衣服 | 指定源视频、时段、原状态到目标状态及保留范围；参数在正文外 | 重新生成全片，新增对白、改声音或固定编辑时长 |
| 源视频向后延长 | 明确方向、源片边界状态与新增内容，另核返回整片／增量及重叠 | 重新演源片、重复算长度、承诺无缝成功 |
| 无对白但保留环境音 | 保留声音生成意图，分别排除对白与 BGM | 关闭整个声轨 |
| 字幕／情绪／音频异常 | 有实际证据才选针对性的最小变量修复 | 默认删除所有水景、情绪和原始创作内容 |
