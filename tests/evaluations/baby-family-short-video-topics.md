# 婴儿生活动画账号：当前选题库

适用范围：原创三维婴儿生活短片，每条 30—60 秒；默认主要观看者为家长和泛家庭观众。宝宝名字由用户确定为“澈澈”。选题依据用户指定的三个方向：婴儿特殊有趣的行为、家庭亲子时刻、婴儿成长。下列41项已全部完成当前剧情、分镜与Seedance 2.5文字稿，共254镜、27分34秒；本轮新增九条，并根据家长亲述修订相关片目；实际图像、视频与声音尚未生成。

完整创作稿：[逐条浏览总览](baby-animation-production/index.html) · [全部剧情与分镜](baby-animation-production/all-stories.md) · [共享人物与空间](baby-animation-production/assets-and-space.md)。文字完成不等于用户已选定发布顺序或接受最终成片。

角色与风格沿用当前项目的方向：真实生活动作、可读的小表情、自然亲子回应；一条聚焦一件小事，可以好笑、温暖或惊喜。婴儿的兴趣、停顿和注意力变化参与情节，照顾者也有自己的事情与趣味。

本清单是原创情境草案，不是对所有婴儿行为或成长顺序的事实断言。成长题材以实际表现的能力为准，不设统一月龄进度。同一宝宝跨阶段出现时，应让造型、体态、活动能力和所处生活状态相互承接。

## A．婴儿特殊有趣的行为：14项

看点：婴儿对身体、声音、物件与大人反应的专注，常常落在成年人意料之外。

| 编号 | 选题 | 可见事件与小变化 | 建议时长 |

| B02 | 再捡一下 | 澈澈松开软环，认真追看下落，爸爸一次次捡回；第二次环从掌边滑回地垫，爸爸被逗笑，宝宝没有跟笑。第三次改由掌心接住，宝宝又握住来取环的另一只手的食指，两人留在新的观察里。 | 45 秒 |
| B03 | 袜子刚穿好 | 爸爸抚平刚穿好的袜尖，澈澈脚趾一蜷，布面又拱起细褶；爸爸顺着等脚松开。稍后宝宝摸袜尖、攥住拉长，再屈膝将右袜退下，拿着研究袜口；另一只仍穿着的袜子又吸引了他的目光。 | 36 秒 |
| B04 | 手心里有什么 | 宝宝举着自己的手，张开、握住、翻面看；大人把玩具放到旁边，他看一眼，又把自己的手举到眼前，继续专注研究。 | 30 秒 |
| B05 | 玩具背面比较好玩 | 大人认真展示玩具正面，宝宝却总把它翻过去，搓后面的大块缝合布标；大人终于跟着摸摸布标，两个人一起听布料发出的轻响。 | 30—40 秒 |

| B08 | 嘴巴里的小马达 | 宝宝抿嘴、鼓腮，试出一个含混的“噗”声，自己停住；安静片刻后再次尝试，听见差不多的声音才咧嘴笑。 | 30 秒 |
| B09 | 这个声音，再一下 | 宝宝捏一下布书里的响纸，停手听，安静后又捏一下；大人翻去另一页，宝宝把书拉回原页，整只手压上去，突然的响声把自己逗笑。 | 30—40 秒 |
| B10 | 什么都想敲一下 | 宝宝用大软积木轻敲托盘，停下来听；大人伸手接时，他又轻轻敲一下大人的手掌。声音变了，他看看手掌，再看看托盘，重新试一次。 | 40—45 秒 |
| B11 | 我还没松手呢 | 爸爸手里的软布环刚进入可达范围，澈澈突然伸右手抓稳，迅速往胸前收；爸爸顺势松开后，空手指还留着捏环的姿势，慢半拍才看向宝宝。澈澈已经低头研究软环，最后把它换到左手，爸爸的目光跟过去，笑着收回空手。 | 30 秒 |
| B12 | 拖鞋来电话 | 妈妈折布时，澈澈攥住一只干净软拖鞋的鞋跟，提到右耳边，含混地说一声“喂？”再咿呀。妈妈看清耳旁的拖鞋才停手笑问“谁呀？”。宝宝继续咿呀，随后降鞋研究，妈妈把停下的一折完成。 | 36 秒 |
| B13 | 亲一下，眼镜呢 | 妈妈凑右脸颊让澈澈亲，宝宝张嘴贴脸的同时右手抓到镜框，眼镜顺势离脸。妈妈眨眼，宝宝笑了；她没有拉扯，只托住镜框下缘。宝宝摸完眼镜，又用空左掌贴上妈妈脸颊，继续看她的眼睛。 | 36 秒 |
| B14 | 怎么喝不到 | 澈澈短吸杯中奶却喝不到，移开嘴，用杯底轻敲餐盘两次。爸爸听到后接杯查看，开盖发现漏了内吸管，才说“忘装了。”他在侧桌接好组件、旋紧盖再交回，宝宝握稳后自然短吸，敲杯声不再响。 | 42 秒 |

B01、B02 直接保留用户给定的两类生活素材。婴儿车的具体姿态、脚的支撑和抓握释放，后续以实际参考及试片确定。

## B．家庭亲子时刻：14项

看点：宝宝与家人共同改变眼前的活动。关系可以通过等待、模仿、靠近、邀请和一起玩体现，不强制每条解释道理。

| 编号 | 选题 | 可见事件与小变化 | 建议时长 |
| --- | --- | --- | --- |
| F01 | 这个才好笑 | 爸爸认真做鬼脸，宝宝只是专心看；爸爸停下来揉揉发酸的脸，无意挤出一个怪表情，宝宝突然笑了。爸爸想照着重做，自己也先笑起来。 | 40—45 秒 |
| F02 | 袖子借我一下 | 妈妈在地垫旁整理出门包，起身时袖口被宝宝抓住；她索性坐回去继续整理，宝宝握着袖口看她拿东西。等他转头研究玩具，自然松开袖子，妈妈反而稍停了一下。 | 30—40 秒 |
| F03 | 全家的静音比赛 | 宝宝眼睛刚闭上，父母收拾东西都改成轻手轻脚，用手势交流，姿态越来越别扭；宝宝睁眼，正好看见两人停在奇怪动作上，先笑了出来。 | 45—60 秒 |
| F04 | 全家福往哪看 | 父母想拍一张全家看镜头的照片，宝宝却总看向画外；最后两人顺着他的目光望过去，照片定格成全家方向一致的侧脸照。 | 40—45 秒 |
| F05 | 妈妈的舞伴 | 妈妈在客厅随音乐晃两步，宝宝扶着固定沙发跟着晃；音乐停下，妈妈也停，宝宝却还认真动着，妈妈笑着继续陪他跳完这一小段。 | 30—40 秒 |
| F06 | 收拾的方向不一样 | 爸爸往浅玩具盒里收大积木，宝宝把刚放进去的拿出来排好；爸爸发现他的排列，换成坐在旁边递积木，两人的“收拾”变成一起摆东西。 | 45—60 秒 |
| F07 | 爷爷的报纸后面 | 爷爷看报纸，脸被挡住时宝宝便探头找；爷爷从不同边露面，慢慢变成躲猫猫。报纸放下后，宝宝举起自己的布书，等爷爷来找。 | 40—45 秒 |
| F08 | 一家人的小合唱 | 妈妈哼歌，爸爸轻轻加入和声；宝宝突然“啊”了一声，两人停下来听。宝宝也安静，三个人等了片刻，终于又同时发声，互相看着笑。 | 40—45 秒 |
| F09 | 睡醒第一眼 | 澈澈醒后先自己玩手、轻声咿呀；短哼被爸爸听见，书页停住，爸爸抬眼靠近。宝宝确认对眼后才展笑，再主动抬右手；爸爸把右食指停在掌前，等小手轻握，安静留下。 | 30 秒 |

| F11 | 还没露面就笑了 | 妈妈双掌遮自己的脸，再完整打开说“在这儿！”，澈澈看见后才笑。等笑尾收住、吸气完成，妈妈问“再来？”再遮脸；宝宝先期待笑，妈妈听见后忍笑开掌，彼此笑完。 | 30 秒 |
| F12 | 先拍到一只手 | 妈妈左手举手机取景，澈澈右手却握住她空着的右食指，轻带到下巴前。妈妈发现指侧潮湿，等宝宝松指再撤手；宝宝把自己的右手送回嘴边，妈妈看明白后放低手机笑了。 | 36 秒 |

## C．婴幼儿成长的小变化：13项

看点：让观众亲眼看见宝宝的动作或互动出现变化，家人的回应落在眼前这一刻。这里的编号便于选题管理，不是医学发展顺序。

| 编号 | 选题 | 可见事件与小变化 | 建议时长 |
| --- | --- | --- | --- |
| G01 | 原来是我的脚 | 地垫上，宝宝偶然碰到自己的脚，低头盯住，再试着伸手抓；终于握住后，他松开，又看准位置重新抓一次。大人把准备递出的玩具停在旁边，陪他看。 | 30—40 秒 |
| G02 | 这次抓住了 | 软环就在面前，宝宝伸手碰偏；停下来重新看，再伸手，终于握住。大人原本准备帮忙的手停下，宝宝举着软环，先认真看一会儿。 | 40—45 秒 |
| G03 | 翻过去，世界换了一面 | 宝宝伸手够侧面的布球，肩转过去，身体还没跟上；再一次尝试后翻了过去。家人俯低身子与他对视，宝宝先愣住，再碰到布球。 | 45—60 秒 |
| G04 | 空出来的一只手 | 宝宝坐在地垫上，原本双手撑着；想拿布书时一抬手便晃，又撑回去。调整姿势后终于腾出一只手，轻轻捏住布书的一角。 | 40—45 秒 |
| G05 | 左手接班 | 右手拿着软环，左手摸过来，却先碰到自己的手；慢慢调整后，软环换到左手。宝宝看看空出的右掌，再看左手里的东西。 | 30—40 秒 |
| G06 | 回头才发现爬远了 | 宝宝盯着地垫上的布球，一点点靠近，终于碰到；回头看家人，发现已隔开一段距离。家人留在原处招招手，宝宝趴着把一只手搭在球上，回头笑起来。 | 45—60 秒 |
| G07 | 你也拿一下 | 宝宝玩着熟悉的软环，忽然伸向家人；对方轻轻接住，他松开手，盯着软环到了别人手里，随后又伸出空掌等它递回。 | 30—40 秒 |
| G08 | 原来可以轮流说 | 大人听见宝宝“啊”了一声，轻声回应后停下；宝宝也停一会儿，再发声。几次之后，大人等着，宝宝看着他，像在等下一句。 | 30—40 秒 |
| G09 | 站起来看见的新世界 | 宝宝扶着固定矮扶栏，从低处一点点撑起身体；终于看见原来被挡住的玩具。家人在旁边俯低身子，和他一起看刚露出的景象。 | 45—60 秒 |
| G10 | 这一小步 | 宝宝扶住一位家人，另一位就在一步外；看了看，伸手，短暂松开支撑，迈出那一步。落进熟悉怀里后，他转身又看向刚才的位置。 | 45—60 秒 |
| G11 | 这样叫，也是爸爸 | 妈妈先问“爸爸在哪儿”，澈澈指向西侧爸爸；等小手收回，再换熟悉的暂拟昵称“阿禾”问，他仍指同一人。爸爸始终原位不提示，妈妈会意笑，宝宝以指认回应。 | 36 秒 |
| G12 | 换个办法也能钓到 | 澈澈先用右手钓具碰鱼背，把大鱼提起；放回后，他让钓具停住，左手直接拿整鱼去碰大磁头。左掌松开鱼仍挂着，妈妈这才笑说“这样也行呀”，看见他换了一条路线。 | 42 秒 |

## 首轮试片建议

41条当前文字创作已经写齐。进入实际媒体试制时，可先取下列六条，覆盖三条内容线，同时获得不同观看情绪：

| 候选 | 开发价值 |
| --- | --- |
| B01 脚就放这儿 | 用户给定的典型趣事，姿态一眼可见，也能测试腿脚与车架 |
| B02 再捡一下 | 用户给定的互动行为，测试抓握、释放、递回与反应节奏 |
| F01 这个才好笑 | 喜剧主要依靠表演，便于检验角色是否有趣 |
| F09 睡醒第一眼 | 安静亲密的片段，检验宝宝与家人的关系是否可读 |
| G02 这次抓住了 | 一个具体动作的小成功，检验成长类是否有观看满足感 |
| G08 原来可以轮流说 | 声音与目光共同组织互动，扩展账号的表现范围 |

这些是试片优先建议，尚未由用户选定发布顺序。全部41条现均有完整剧情、分镜时长、动作阶段、机位与焦点、声音、连续性约束、首帧和视频制作母稿，以及构图示意板；实际角色图、动作样片与成片仍待制作。

## 开发与审阅口径

- 每条围绕一个主要事件，空间、身体和关键物件能被看懂。静音应能理解主要动作；声音可以提升节奏、亲密感和笑点。
- 保留看见、尝试、停住、改变关注点和回应等自然过程，不把每条都改成三次重复、强反转或教育总结。
- 同类素材可以复用角色与场景，但要改变互动关系或观众发现的细节。B01 的舒服姿态与 G01 的发现身体，以及 B02 的重复趣味与 G07 的主动交换，分别承担不同看点。
- 成长类按已经建立的能力与时间进展安排；同一时期的角色造型、运动和声音相互一致。不同婴儿会有差异，不从一段情节推导统一成长标准。
- 以上是可撤销的创作候选。文字完整、作者选用、实际动作质量和账号表现分别记录。
