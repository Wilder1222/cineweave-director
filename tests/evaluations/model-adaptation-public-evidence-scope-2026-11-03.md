# 公开证据的脱敏与验证范围

本目录的模型适配研究、十轮审阅、独立评语、输入、输出、终态与 Skill 哈希记录源自本机原始运行。公开副本为避免暴露个人环境：

- 所有 JSONL 事件仅保留事件类别、经允许的条目标识和类型、状态、退出码以及数字用量；命令、命令输出、消息、线程标识、查询与其他自由文本均替换为 `[REDACTED]`。公开文件仍按事件逐行排列，但不能据此独立验证命令执行内容、实际读取的文件、输出原文、失败原因或隔离性。原始事件保留在本机，未纳入本次公开仓库。
- 其他材料中的本机用户目录、临时目录和项目绝对路径改为通用占位，并移除包含本地记忆文件引用的行；仅有关公开可读证据的说明为便于理解另加提示。因此公开版可能与本机原件字节不同。
- 记录中的 SHA-256、输入哈希、快照比较及逐字节一致性表述，均指原始本地运行或当时冻结的 Skill 快照，而不证明公开脱敏副本的字节一致。未修改那些原始哈希以适配公开副本。
- 既有内容评审与运行终态仅支持其记录范围，不证明实际视频或音频质量、账号权限或输出在其他版本上成立。
