**方舟方案：先解决两项时长，再做参考生成新视频。**

目标模型为 `doubao-seedance-2-5-260628`。合规素材就绪后，分别绑定 `reference_video`、`reference_audio`，以 `omni_reference_task_type="reference"` 表达生成新片的意图，避免把方案写成编辑原片。该字段仍需与提示词意图一致。[Seedance 2.5 官方教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)

当前可供选择的条件方案是：

| 选择 | 需要你确认什么 | 代价或控制损失 |
|---|---|---|
| **保留原文件，另做合规副本** | 是否允许视频循环、尾帧停留或减速至至少 2 秒；音频是否允许补静音、循环或调整速度至至少 2 秒 | 循环会重复动作或声音；停帧会增加静止段；减速会改变节奏。补静音不增加有效声音信息。新副本须重新核验 |
| **补取或替换为更长素材** | 是否能提供至少 2 秒的视频和至少 2 秒的音频，以及哪些主体、动作、运镜和声音特征必须保留 | 需要新增素材；重录或替换可能改变表演、镜头或声音特征 |
| **坚持两个文件原样作为这两类参考输入** | 无需先处理文件 | 当前没有符合上述时长限制的方案；修改输出 `duration` 不能补足输入长度 |

若采用减速视频，仍须保持最终输入帧率在允许范围内，不能只降低播放帧率。

方舟还需确认两项文件条件：MP4 内的视频编码是否为 H.264／H.265；若带内嵌音轨，其编码是否为 AAC／MP3。另外，该 API 对直接上传含真人人脸的参考视频有限制，素材内容及适用渠道目前未知。[方舟编码与素材准入说明](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)
