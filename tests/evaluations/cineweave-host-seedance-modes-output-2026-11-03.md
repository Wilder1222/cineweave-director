**镜头策划**

暂拟室内斜侧中景：前景是检票玻璃与窗框，中景同时看见站务员侧脸、右手和擦拭区域，后景是站台手提灯。灯暂设放在站台长凳上，不增加持灯人物。

- **0–2 秒：**建立雾玻璃、站务员和模糊灯光的空间关系。
- **2–6 秒：**右手持布贴着玻璃内侧擦开一块水雾；外侧雨滴仍在。
- **6–9 秒：**清晰区域露出灯，站务员先改变眼线，再微微转头，擦拭停止。
- **9–12 秒：**保持望向灯的状态，留下安静的观察时间。

摄影机暂拟在擦开水雾后缓慢推进，始终留在室内，不穿过玻璃；先保证手与侧脸可读，再把注意力交给灯。**这是创作提案，尚未从未提供的视频中提取运镜。** 时标是节奏目标，不是逐帧执行保证。

`POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`

**参数与自动判定风险**

| 项目 | 本次交接要点 |
|---|---|
| 输出时长／分辨率 | Seedance 2.5 支持4–30秒或`-1`；输出480p、720p、1080p，本稿建议1080p。 |
| 参考视频 | 非编辑单段2–30秒，编辑单段4–30秒；最多10段、合计不超过30秒。 |
| 声音 | 要雨声就保留`generate_audio:true`；`false`会关闭整个声轨。只有雨声仍需听审确认。 |
| 素材准入 | 方舟不支持直接上传含真人人脸的参考图／视频；官方另有指定模型原始产物、虚拟人像和已授权真人素材渠道。未知素材不能预判是否符合。 |

这些约束限于方舟当前接口；素材到位后还要核对文件规格及实际可访问地址。[官方 API 参数与素材要求](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)

`omni_reference_task_type` 默认 `auto`，模型会结合素材和提示词判断参考生成、编辑或延长：

- **新生成：**明确写“生成全新视频、素材分别参考什么”，设置`reference`。
- **编辑原片：**明确写“编辑@video1、修改什么、保留什么”，设置`edit`并遵守源片锁定。
- **自动模式：**若携带视频、指定12秒和16:9，却被判成编辑，可能因参数冲突异步失败。改用`adaptive/-1`能兼容部分限制，但会失去自定画幅和时长，不能据此默认替你改选。

显式任务类型有助于校验；实际提示意图不一致，仍可能返回`InvalidParameter.TaskTypeMismatch`，参数冲突也可能返回`InvalidParameter.TaskTypeConstraint`。**收到任务ID不等于生成成功**，后续应查询终态，再测量真实时长、检查首帧、单镜连续性、运镜和完整音轨。[官方判定与报错机制](https://console.volcengine.com/ark/region:cn-beijing/docs/seedance-2-5)
