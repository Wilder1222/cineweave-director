Edit @Video1。仅删除桌上的目标杯子，补全杯子原本遮挡的桌面纹理；仅清理该杯子产生的阴影和倒影，使修补区域与周围桌面及光照自然衔接。

**C．Wan 首帧与运动稿冲突**

冲突在于：题设首帧规定**右手在身侧**，运动稿却要求**开场已经靠近玻璃**。应保留首帧，补上可达的伸手过程。Wan 官方将首帧生视频定义为以输入图为首帧生成后续画面。[Wan 官方指南](https://help.aliyun.com/zh/model-studio/wan3-video-generation-prompt-guide)

在题设成立，且“玻璃”是**可抓握、可移动的玻璃物件**、时长足以完成动作时，可将冲突动作段替换为：

```text
从首帧姿态开始，人物右手仍在身侧，尚未接触玻璃。人物自然抬起右臂，从身侧连续伸向玻璃，手指先接触可抓握部位，再合拢抓稳，随后平稳拿起玻璃。玻璃在被抓稳之前保持原位。完整呈现伸手、接触、抓稳和拿起的过程，右手不瞬移，玻璃不提前移动。
```

执行时须将实图绑定为**首帧输入**，并确认接触过程在画内可辨。无需为了原句而先修改首帧。

若“玻璃”指固定窗玻璃，“拿起”本身也不可行，需先明确动作目标，不能擅自改成擦拭。若坚持保留“开场已靠近玻璃”，则需要另换相符首帧，那将改变本场景的首帧约束。
