采用 **12秒、三镜：递出4秒 → 触柄3秒 → 察觉5秒**。暂拟现代雨天门厅、成年男女、16:9、无对白，人物外观可替换。戏眼是：**乙的指尖已经碰到伞，手却始终没有形成接握；甲等了一下，才抬眼看她。**

没有素材，建议从官网 **Kling 4.0 标准版的 Omni Reference 纯文本路径**开始，将下列三段按顺序放入同一任务，时长设为12秒。官方指南支持文字编排多镜；时码表达目标节奏，实际切点仍需看片调整。其他入口或API需另核设置。[官方用户指南](https://kling.ai/quickstart/kling-4-model-user-guide)

**镜1｜0–4秒：递出，建立重量关系**

固定双人全景，拍到头脚、伞柄和伞尖。前景留空，中景两人，后景玻璃门。保持两人连线同一侧机位，让观众看清谁拿着伞、伞是否落地。

```text
镜头1，0—4秒。16:9，写实真人表演。雨天的现代住宅门厅，浅灰墙、深灰石地，后景左侧是透入冷灰雨光的玻璃入口门，右侧墙灯提供柔和暖光。甲是约32岁的短黑发男子，方脸，穿深灰短外套；乙是约30岁的齐耳黑发女子，椭圆脸，穿米色针织开衫。甲在画左，乙在画右，相对站立，相距约一步。

摄影机在门厅内侧，固定双人全景，两人的脸、双手与地面均入画。甲右手牢握一把收拢黑伞的弯柄下方直杆，黑色弯柄开口朝画左；伞近乎竖直，伞尖悬在地面上方约十厘米。甲带着一点自然笑意，将右前臂平缓向乙伸出约二十厘米，把弯柄递到两人之间，右手继续稳稳承担伞的重量。乙低头看弯柄，抬起左手，食指与中指伸向弯柄外侧，掌心保持空着。甲的视线随乙的手落到伞柄。镜尾，乙指尖距离弯柄约一厘米，尚未接触，甲仍握牢直杆。

焦点保持两人与伞可辨，摄影机不移动。持续低声的门外雨声，递出时只有轻微衣料摩擦；两人保持沉默，无背景音乐，无字幕。
```

**镜2｜4–7秒：碰到了，却没有接**

固定手部特写，焦点覆盖甲的握位和乙的指尖。只放大交接失败的证据，不加拉焦或运镜。

```text
镜头2，4—7秒。16:9，写实真人表演。雨天现代住宅门厅，浅灰墙与玻璃入口门，左后方冷灰雨光、右侧柔和暖墙灯。画左是穿深灰短外套的甲，画右是穿米色针织开衫的乙。摄影机保持在两人连线的同一侧，切为固定手部特写，甲的右手、乙的左手、完整弯柄及甲握着的一小段直杆清晰入画；人物眼睛和伞尖均在画外。

开场，甲右手牢握收拢黑伞的弯柄下方直杆，弯柄开口朝画左，伞竖直稳定；乙左手食指与中指距离弯柄外侧约一厘米。乙的两枚指腹轻轻靠近，第一次触到弯柄外侧，随后停在那里。她的手指保持舒展，拇指与弯柄分开，掌心留空，没有形成包握或托举。甲的手指仍扣住直杆，腕部继续稳住整把伞。接触后留出约两秒等待，伞保持原来的高度和方向。

画外承接状态：两人仍低头看交接处；伞尖仍悬空，全部重量由甲承担。摄影机固定，焦点始终同时覆盖双方手指和握位。雨声连续，两人保持沉默，无背景音乐，无字幕。
```

**镜3｜7–12秒：甲看懂了，停止催促**

固定双人中景，从头至髋部，手和伞柄留在画面下部。两张脸与接触同时可读，使甲的反应有明确原因。

```text
镜头3，7—12秒。16:9，写实真人表演。雨天现代住宅门厅，浅灰墙、深灰石地，玻璃入口门位于左后景，冷灰雨光从门外透入，右侧暖墙灯照亮人物。甲是约32岁的短黑发方脸男子，穿深灰短外套，站画左；乙是约30岁的齐耳黑发椭圆脸女子，穿米色针织开衫，站画右，两人相对站立，相距约一步。

摄影机保持原轴线侧，固定双人中景，拍到两人的头至髋部，伞柄和双方的手保留在画面下部。开场，甲正低头看交接处，右手牢握收拢黑伞的弯柄下方直杆；弯柄开口朝画左。乙左手食指与中指的指腹已经轻触弯柄外侧，掌心仍空着，拇指分开，手指没有合拢。甲继续承担整把伞的重量，伞保持竖直。

乙的指尖停着，目光也停在弯柄上。甲等了半拍，看见乙迟迟没有接握，才将视线从两人的手抬到乙的脸上，头部随后微微抬起。乙仍垂着眼，嘴唇略微分开，又轻轻合上，保持沉默。甲原本的一点笑意缓缓收住，手臂停止继续递进，仍稳稳托着伞，安静看着乙，留出等待她决定的时间。镜尾，乙仍只触柄，甲仍承重。

焦点保持两张脸和下部接触关系可读，摄影机全程固定。伞尖在画外，承接此前悬空状态。门外雨声持续，两人保持沉默，无背景音乐，无字幕。
```

**衔接按连续时间硬切，两处都不重演动作。**

| 接点 | 必须承接的状态 |
|---|---|
| 镜1 → 镜2 | 从“指尖距柄约一厘米”继续靠近，在镜2首次接触；甲右手握位、弯柄方向和伞高度不变。 |
| 镜2 → 镜3 | 指腹已经贴着弯柄，直接延续等待。镜3开场甲仍看手，随后只抬眼一次。镜2眼睛在画外，没有提前展示这一反应。 |

伞尖离地由镜1直接展示，镜2、3属于画外继承。雨声贯穿剪点，作为连续环境声桥。

看片时重点检查：**乙有没有自动合拢手指、甲有没有提前松手、甲有没有在切镜后重复抬眼。** 这三项会直接改变这场戏的含义；当前交付为文字设计，接触与表演尚待真实视频验证。
